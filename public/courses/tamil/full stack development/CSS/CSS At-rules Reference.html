CSS At-rules Reference

CSS @-விதிகள் மற்றும் அவற்றின் பயன்பாடு

CSS @-விதிகள்

CSS @-விதிகள் CSS எவ்வாறு நடந்து கொள்ள வேண்டும் என்பதை அறிவுறுத்தும் அறிக்கைகள் ஆகும். ஒவ்வொரு @-விதியும் ஒரு @ உடன் தொடங்கி அதைத் தொடர்ந்து ஒரு பெயர் வருகிறது.

CSS @-விதிகள் அட்டவணை

கீழே உள்ள அட்டவணை CSS இல் உள்ள வெவ்வேறு @-விதிகளைக் காட்டுகிறது:

@-விதி விளக்கம்
@charset பாணி தாளில் பயன்படுத்தப்படும் எழுத்து குறியாக்கத்தை குறிப்பிடுகிறது
@container கொள்கலனின் அளவு அல்லது பாணியைப் பொறுத்து, கொள்கலனில் உள்ள உறுப்புகளுக்கான பாணிகளை வரையறுக்கவும்
@counter-style உங்கள் சொந்த கவுண்டர் பாணிகளை வரையறுக்க உங்களை அனுமதிக்கிறது
@font-face உரையைக் காட்ட தனிப்பயன் எழுத்துருவைப் பயன்படுத்த குறிப்பிடுகிறது
@font-palette-values எழுத்துரு-பேலட்டின் இயல்புநிலை மதிப்புகளைத் தனிப்பயனாக்க உங்களை அனுமதிக்கிறது
@import ஒரு பாணி தாளை மற்றொரு பாணி தாளில் இறக்குமதி செய்ய உங்களை அனுமதிக்கிறது
@keyframes அனிமேஷன் வரிசையில் உள்ள புள்ளிகளுக்கான பாணிகளை வரையறுப்பதன் மூலம் ஒரு அனிமேஷனில் உள்ள படிகளை கட்டுப்படுத்துகிறது
@layer CSS கேஸ்கேடு அடுக்குகள் பாணிகளின் வரிசையை எவ்வாறு மதிப்பிடுகின்றன என்பதைக் கட்டுப்படுத்த பயன்படுகிறது
@media ஒன்று அல்லது அதற்கு மேற்பட்ட மீடியா வினவல்களின் முடிவின் அடிப்படையில் ஒரு பாணி தாளின் பகுதிகளைப் பயன்படுத்துகிறது
@namespace பாணி தாளில் பயன்படுத்தப்பட வேண்டிய XML பெயர்வெளியை வரையறுக்கிறது
@page அச்சிடப்பட்ட பக்கங்களின் பரிமாணம், நோக்குநிலை மற்றும் விளிம்புகளை தனிப்பயனாக்குகிறது
@property எந்த JavaScript ஐயும் இயக்காமலே பாணித் தாளில் நேரடியாக தனிப்பயன் CSS பண்புகளை வரையறுக்க உங்களை அனுமதிக்கிறது. இந்த @-விதிக்கு தரவு வகை சரிபார்ப்பு மற்றும் கட்டுப்பாடு, இயல்புநிலை மதிப்புகளை அமைத்தல் மற்றும் பண்பு மதிப்புகளைப் பெற முடியுமா இல்லையா என்பதை வரையறுத்தல் உள்ளது
@scope குறிப்பிட்ட DOM உபவேர்களில் உறுப்புகளைத் தேர்ந்தெடுத்து, மிகவும் குறிப்பிட்ட தேர்ந்தெடுப்பாளர்களை எழுதாமல் உறுப்புகளைத் துல்லியமாக இலக்காக்க உங்களை அனுமதிக்கிறது
@starting-style உறுப்பு அதன் முதல் பாணி புதுப்பிப்பைப் பெறுவதற்கு முன் ஒரு உறுப்பின் தொடக்க பாணிகளை வரையறுக்கிறது
@supports ஒரு CSS அம்சத்தை பிரௌசர் ஆதரிக்கிறதா இல்லையா என்பதை சோதிக்க பயன்படுகிறது

CSS @-விதிகள் பயிற்சி

உங்கள் CSS @-விதிகள் அறிவை சோதிக்க இந்த பயிற்சியை முயற்சிக்கவும்.

❓ ஒரு அனிமேஷனில் உள்ள படிகளை கட்டுப்படுத்த பயன்படுத்தப்படும் சரியான CSS @-விதி எது?

@media
✗ தவறு! @media என்பது மீடியா வினவல்களின் அடிப்படையில் பாணிகளைப் பயன்படுத்த பயன்படுகிறது
@keyframes
✓ சரி! @keyframes என்பது அனிமேஷன் வரிசையில் உள்ள புள்ளிகளுக்கான பாணிகளை வரையறுப்பதன் மூலம் ஒரு அனிமேஷனில் உள்ள படிகளை கட்டுப்படுத்த பயன்படுகிறது
@import
✗ தவறு! @import என்பது ஒரு பாணி தாளை மற்றொரு பாணி தாளில் இறக்குமதி செய்ய பயன்படுகிறது
@font-face
✗ தவறு! @font-face என்பது தனிப்பயன் எழுத்துருக்களை வரையறுக்க பயன்படுகிறது
