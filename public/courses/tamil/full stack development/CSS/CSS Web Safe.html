வலைப் பாதுகாப்பான எழுத்துருக்கள் - அனைத்து உலாவிகளிலும் கிடைக்கும்

வலைப் பாதுகாப்பான எழுத்துருக்கள் என்றால் என்ன?

வலைப் பாதுகாப்பான எழுத்துருக்கள் என்பது அனைத்து உலாவிகள் மற்றும் சாதனங்களிலும் உலகளாவிய முறையில் நிறுவப்பட்ட எழுத்துருக்கள் ஆகும்.

மாற்று எழுத்துருக்கள்

இருப்பினும், 100% முழுமையாக வலைப் பாதுகாப்பான எழுத்துருக்கள் எதுவும் இல்லை. ஒரு எழுத்துரு கண்டுபிடிக்கப்படாமல் போக அல்லது சரியாக நிறுவப்படாமல் போகும் வாய்ப்பு எப்போதும் உள்ளது.

எனவே, எப்போதும் மாற்று எழுத்துருக்களைப் பயன்படுத்துவது மிகவும் முக்கியமானது.

இதன் பொருள் நீங்கள் font-family பண்பில் ஒத்த "காப்பு எழுத்துருக்களின்" பட்டியலைச் சேர்க்க வேண்டும். முதல் எழுத்துரு வேலை செய்யவில்லை என்றால், உலாவி அடுத்த எழுத்துருவை முயற்சிக்கும், பின்னர் அதற்கு அடுத்த எழுத்துருவை முயற்சிக்கும், மற்றும் பல. எப்போதும் பட்டியலை பொதுவான எழுத்துரு குடும்பப் பெயருடன் முடிக்கவும்.

எடுத்துக்காட்டு

இங்கே, நாங்கள் மூன்று எழுத்துருக்களை பட்டியலிடுகிறோம்: Tahoma, Verdana, மற்றும் sans-serif. முதல் எழுத்துரு கிடைக்கவில்லை என்றால், இரண்டாவது மற்றும் மூன்றாவது எழுத்துருக்கள் காப்பு எழுத்துருக்கள் ஆகும்:

p {
  font-family: Tahoma, Verdana, sans-serif;
}

HTML மற்றும் CSS க்கான வலைப் பாதுகாப்பான எழுத்துருக்கள்

HTML மற்றும் CSS க்கான சிறந்த வலைப் பாதுகாப்பான எழுத்துருக்களின் பட்டியல் பின்வருமாறு:

⚠️ குறிப்பு:

உங்கள் வலைத்தளத்தை வெளியிடுவதற்கு முன், எப்போதும் உங்கள் எழுத்துருக்கள் வெவ்வேறு உலாவிகள் மற்றும் சாதனங்களில் எவ்வாறு தோன்றுகின்றன என்பதைச் சரிபார்க்கவும், மற்றும் எப்போதும் மாற்று எழுத்துருக்களைப் பயன்படுத்தவும்!

Arial என்பது ஆன்லைன் மற்றும் அச்சிடப்பட்ட ஊடகங்கள் இரண்டிற்கும் மிகவும் பரவலாகப் பயன்படுத்தப்படும் எழுத்துரு ஆகும். Google ஆவணங்களில் Arial என்பது இயல்புநிலை எழுத்துருவாகும்.
