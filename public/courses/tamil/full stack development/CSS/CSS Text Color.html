CSS உரை வடிவமைப்பு

CSS-க்கு உரையை வடிவமைக்க மற்றும் வடிவமைக்க நிறைய பண்புகள் உள்ளன.

உரை வடிவமைப்பு

இந்த உரை சில உரை வடிவமைப்பு பண்புகளுடன் வடிவமைக்கப்பட்டுள்ளது. தலைப்பு text-align, text-transform, மற்றும் color பண்புகளைப் பயன்படுத்துகிறது. பத்தி உள்தள்ளப்பட்டு, சீரமைக்கப்பட்டு, எழுத்துக்களுக்கு இடையே உள்ள இடம் குறிப்பிடப்பட்டுள்ளது. இந்த வண்ணமயமான "Try it Yourself" இணைப்பிலிருந்து அடிக்கோடு நீக்கப்பட்டது.

CSS Text Color

color பண்பு உரையின் நிறத்தை அமைக்க பயன்படுகிறது. நிறம் பின்வருவனவற்றால் குறிப்பிடப்படுகிறது:

  • நிறப் பெயர் - "red" போன்றது
  • HEX மதிப்பு - "#ff0000" போன்றது
  • RGB மதிப்பு - "rgb(255,0,0)" போன்றது

சாத்தியமான அனைத்து நிற மதிப்புகளின் முழுமையான பட்டியலுக்கு CSS Color Values பார்க்கவும்.

ஒரு பக்கத்தின் இயல்புநிலை உரை நிறம் body தேர்ந்தெடுப்பாளரில் வரையறுக்கப்பட்டுள்ளது.

எடுத்துக்காட்டு

body {
  color: blue;
}

h1 {
  color: green;
}

h2 {
  color: red;
}

உரை நிறம் மற்றும் பின்னணி நிறம்

இந்த எடுத்துக்காட்டில், நாங்கள் background-color பண்பு மற்றும் color பண்பு இரண்டையும் வரையறுக்கிறோம்:

body {
  background-color: lightgrey;
  color: blue;
}

h1 {
  background-color: black;
  color: white;
}

div {
  background-color: blue;
  color: white;
}

⚠️ முக்கியமானது:

பார்வை பிரச்சனைகள் உள்ளவர்களுக்கு அதிக contrast மிகவும் முக்கியமானது. எனவே, உரை நிறத்திற்கும் பின்னணி நிறத்திற்கும் (அல்லது பின்னணி படத்திற்கும்) இடையே உள்ள contrast எப்போதும் நல்லதாக இருப்பதை உறுதி செய்யுங்கள்!
