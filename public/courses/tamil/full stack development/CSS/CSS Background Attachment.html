CSS Background Attachment

பின்னணி படத்தின் ஸ்க்ரோல் நடத்தையைக் கட்டுப்படுத்துகிறது

CSS background-attachment

background-attachment பண்பு பின்னணி படம் ஸ்க்ரோல் செய்ய வேண்டுமா அல்லது நிலையானதாக இருக்க வேண்டுமா என்பதை குறிப்பிடுகிறது (பக்கத்தின் மற்ற பகுதிகளுடன் ஸ்க்ரோல் செய்யாது):

Fixed Background Example

பின்னணி படம் நிலையானதாக இருக்க வேண்டும் என குறிப்பிடவும்:

Example

body {
  background-image: url("img_tree.png");
  background-repeat: no-repeat;
  background-position: right top;
  background-attachment: fixed;
}

இந்த எடுத்துக்காட்டில், பின்னணி படம் பக்கத்துடன் ஸ்க்ர�்ள் செய்யாது. பயனர் பக்கத்தை மேலே அல்லது கீழே ஸ்க்ரோல் செய்தாலும், படம் அதே இடத்தில் நிலையாக இருக்கும்.

Scroll Background Example

பின்னணி படம் பக்கத்தின் மற்ற பகுதிகளுடன் ஸ்க்ரோல் செய்ய வேண்டும் என குறிப்பிடவும்:

Example

body {
  background-image: url("img_tree.png");
  background-repeat: no-repeat;
  background-position: right top;
  background-attachment: scroll;
}

இந்த எடுத்துக்காட்டில், பின்னணி படம் சாதாரண உள்ளடக்கத்துடன் ஸ்க்ரோல் செய்யும். பயனர் பக்கத்தை மேலே அல்லது கீழே நகர்த்தும்போது, பின்னணி படமும் நகரும்.

💡 உதவிக்குறிப்பு:

scroll என்பது இயல்புநிலை மதிப்பாகும். background-attachment பண்பைக் குறிப்பிடாவிட்டால், பின்னணி படம் ஸ்க்ரோல் செய்யும்.

Exercise

❓ background-attachment பண்பு எதைக் கட்டுப்படுத்துகிறது?

பின்னணி படத்தின் அளவு
✗ தவறு! பின்னணி படத்தின் அளவைக் கட்டுப்படுத்துவது background-size பண்பு ஆகும்.
பின்னணி படம் பக்கத்துடன் ஸ்க்ரோல் செய்யுமா அல்லது நிலையானதாக இருக்குமா என்பது
✓ சரி! background-attachment பண்பு பின்னணி படத்தின் ஸ்க்ரோல் நடத்தையைக் கட்டுப்படுத்துகிறது.
பின்னணி படத்தின் நிறம்
✗ தவறு! பின்னணி படத்திற்கு நிறம் இல்லை - background-color பண்பு பின்னணி நிறத்தைக் கட்டுப்படுத்துகிறது.
பல பின்னணி படங்களின் நிறம்
✗ தவறு! பின்னணி படங்களுக்கு நிறம் இல்லை, மேலும் இது பல பின்னணி படங்களுடன் தொடர்புடையது அல்ல.

The CSS Background Attachment Property

Property Description
background-attachment ஒரு பின்னணி படம் நிலையானதாக இருக்க வேண்டுமா அல்லது பக்கத்தின் மற்ற பகுதிகளுடன் ஸ்க்ரோல் செய்ய வேண்டுமா என்பதை அமைக்கிறது

🎯 முக்கிய புள்ளிகள்:

fixed: பின்னணி படம் நிலையானது - பக்க உள்ளடக்கத்துடன் ஸ்க்ரோல் செய்யாது
scroll: பின்னணி படம் ஸ்க்ரோல் செய்யும் - பக்க உள்ளடக்கத்துடன் நகரும்
local: உள்ளடக்கத்துடன் மட்டும் ஸ்க்ரோல் செய்யும் (உருப்படிகளுக்குள்)
