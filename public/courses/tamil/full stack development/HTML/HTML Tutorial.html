HTML Tutorial

HTML ஐக் கற்றுக்கொள்ளுங்கள்

HTML டுடோரியல்

HTML என்பது வலைப்பக்கங்களுக்கான நிலையான மார்க்அப் மொழியாகும்.

HTML உடன் உங்கள் சொந்த வலைத்தளத்தை உருவாக்கலாம்.

HTML கற்றுக்கொள்வது எளிது - நீங்கள் அதை ரசிப்பீர்கள்!

HTML டுடோரியல்

எங்கள் HTML டுடோரியலை இலவசமாகப் படிக்கவும், பதிவு தேவையில்லை.

அல்லது

எங்கள் ஊடாடும் HTML பாடத்துடன் உங்கள் கற்றலை மேம்படுத்துங்கள் மற்றும் சான்றிதழ் பெறுங்கள்.

🏁 உதவிக்குறிப்பு:

உங்கள் முன்னேற்றத்தைக் கண்காணிக்க உள்நுழையவும் - இது இலவசம்.

எடுத்துக்காட்டுகள் மூலம் கற்றல்

எங்கள் "Try it Yourself" தொகுப்பியுடன், நீங்கள் HTML குறியீட்டைத் திருத்தலாம் மற்றும் முடிவை உலாவியில் காணலாம்:

எடுத்துக்காட்டு

<!DOCTYPE html>
<html>
<head>
<title>Page Title</title>
</head>
<body>

<h1>This is a Heading</h1>
<p>This is a paragraph.</p>

</body>
</html>

இது எவ்வாறு செயல்படுகிறது என்பதைப் பார்க்க "Try it Yourself" பொத்தானைக் கிளிக் செய்யவும்.

HTML எடுத்துக்காட்டுகள்

பயிற்சிகள் மூலம் கற்றல்
