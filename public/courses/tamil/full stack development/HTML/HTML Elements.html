HTML உறுப்புகள்

HTML உறுப்புகள்

ஒரு HTML உறுப்பு ஒரு தொடக்கக் குறி (start tag), சில உள்ளடக்கம், மற்றும் ஒரு முடிவுக் குறி (end tag) ஆகியவற்றால் வரையறுக்கப்படுகிறது.

HTML உறுப்புகள்

HTML உறுப்பு என்பது தொடக்கக் குறியிலிருந்து முடிவுக் குறி வரை உள்ள அனைத்தும்:

<tagname>Content goes here...</tagname>

சில HTML உறுப்புகளின் எடுத்துக்காட்டுகள்:

<h1>My First Heading</h1>
<p>My first paragraph.</p>
தொடக்கக் குறி உறுப்பு உள்ளடக்கம் முடிவுக் குறி
<h1> My First Heading </h1>
<p> My first paragraph. </p>
<br> உள்ளடக்கம் இல்லை முடிவுக் குறி இல்லை

⚠️ கவனிக்க:

சில HTML உறுப்புகளுக்கு உள்ளடக்கம் இல்லை (உதாரணமாக <br> உறுப்பு). இந்த உறுப்புகள் "காலியான உறுப்புகள்" (empty elements) என்று அழைக்கப்படுகின்றன. காலியான உறுப்புகளுக்கு முடிவுக் குறி இல்லை!

பின்னல் HTML உறுப்புகள்

HTML உறுப்புகள் பின்னலாக இருக்கலாம் (இதன் பொருள் உறுப்புகள் மற்ற உறுப்புகளைக் கொண்டிருக்கலாம்).

அனைத்து HTML ஆவணங்களும் பின்னல் HTML உறுப்புகளைக் கொண்டிருக்கின்றன.

பின்வரும் எடுத்துக்காட்டு நான்கு HTML உறுப்புகளைக் கொண்டுள்ளது (<html>, <body>, <h1> மற்றும் <p>):

எடுத்துக்காட்டு

<!DOCTYPE html>
<html>
<body>

<h1>My First Heading</h1>
<p>My first paragraph.</p>

</body>
</html>

எடுத்துக்காட்டு விளக்கம்

<html> உறுப்பு

<html> உறுப்பு மூல உறுப்பு (root element) மற்றும் இது முழு HTML ஆவணத்தையும் வரையறுக்கிறது.

இது ஒரு தொடக்கக் குறி <html> மற்றும் ஒரு முடிவுக் குறி </html> ஐக் கொண்டுள்ளது.

<body> உறுப்பு

<body> உறுப்பு ஆவணத்தின் உடலை வரையறுக்கிறது.

இது ஒரு தொடக்கக் குறி <body> மற்றும் ஒரு முடிவுக் குறி </body> ஐக் கொண்டுள்ளது.

<h1> உறுப்பு

<h1> உறுப்பு ஒரு தலைப்பை வரையறுக்கிறது.

இது ஒரு தொடக்கக் குறி <h1> மற்றும் ஒரு முடிவுக் குறி </h1> ஐக் கொண்டுள்ளது:

<h1>My First Heading</h1>

<p> உறுப்பு

<p> உறுப்பு ஒரு பத்தியை வரையறுக்கிறது.

இது ஒரு தொடக்கக் குறி <p> மற்றும் ஒரு முடிவுக் குறி </p> ஐக் கொண்டுள்ளது:

<p>My first paragraph.</p>

முடிவுக் குறியை ஒருபோதும் தவிர்க்காதீர்கள்

சில HTML உறுப்புகள் சரியாகக் காட்சிப்படுத்தப்படும், நீங்கள் முடிவுக் குறியை மறந்தாலும் கூட:

எடுத்துக்காட்டு

<html>
<body>

<p>This is a paragraph
<p>This is a paragraph

</body>
</html>

🚫 கவனிக்க:

இருப்பினும், இதை ஒருபோதும் நம்பாதீர்கள்! நீங்கள் முடிவுக் குறியை மறந்தால் எதிர்பாராத முடிவுகள் மற்றும் பிழைகள் ஏற்படலாம்!

💡 சிறந்த நடைமுறை:

எப்போதும் உங்கள் HTML உறுப்புகளுக்கு முடிவுக் குறிகளைச் சேர்க்கவும். இது குறியீட்டைத் தெளிவாகவும் பராமரிப்பதற்கு எளிதாகவும் ஆக்குகிறது.

காலியான HTML உறுப்புகள்

உள்ளடக்கம் இல்லாத HTML உறுப்புகள் காலியான உறுப்புகள் (empty elements) என்று அழைக்கப்படுகின்றன.

<br> குறிச்சொல் ஒரு வரி முறிப்பை வரையறுக்கிறது, மேலும் இது முடிக்கும் குறிச்சொல் இல்லாத ஒரு காலியான உறுப்பாகும்:

எடுத்துக்காட்டு

<p>This is a <br> paragraph with a line break.</p>

<br>

வரி முறிப்பு

<img>

படங்களைச் சேர்க்கிறது

<hr>

கிடைமட்ட வரி

HTML வழக்கு-உணர்திறன் அற்றது

HTML குறிச்சொற்கள் வழக்கு-உணர்திறன் அற்றவை (case sensitive அல்ல): <P> என்பது <p> போலவே அர்த்தம்.

HTML தரநிலை சிறிய எழுத்துக் குறிச்சொற்களைத் தேவைப்படுத்தாது, ஆனால் W3C HTML இல் சிறிய எழுத்துகளைப் பரிந்துரைக்கிறது, மேலும் XHTML போன்ற கடுமையான ஆவண வகைகளுக்கு சிறிய எழுத்துகளைக் கோருகிறது.
