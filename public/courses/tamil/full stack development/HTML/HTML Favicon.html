HTML பேவிகான்

பேவிகான் என்பது உலாவி தத்தில் பக்கத் தலைப்பின் அடுத்தில் காட்டப்படும் ஒரு சிறிய படமாகும்.

HTML இல் பேவிகானை எவ்வாறு சேர்க்கலாம்

நீங்கள் விரும்பும் எந்த படத்தையும் உங்கள் பேவிகானாகப் பயன்படுத்தலாம். https://www.favicon.cc போன்ற தளங்களில் உங்கள் சொந்த பேவிகானை உருவாக்கலாம்.

💡 உதவிக்குறிப்பு:

பேவிகான் ஒரு சிறிய படம், எனவே இது அதிக கான்ட்ராஸ்ட் கொண்ட எளிய படமாக இருக்க வேண்டும்.

ஒரு பேவிகான் படம் உலாவி தத்தில் பக்கத் தலைப்பின் இடதுபுறத்தில் காட்டப்படுகிறது:

பேவிகான் எடுத்துக்காட்டு

<!DOCTYPE html>
<html>
<head>
  <title>My Page Title</title>
  <link rel="icon" type="image/x-icon" href="/images/favicon.ico">
</head>
<body>

<h1>This is a Heading</h1>
<p>This is a paragraph.</p>

</body>
</html>

உங்கள் வலைத்தளத்தில் பேவிகானைச் சேர்க்க, உங்கள் பேவிகான் படத்தை உங்கள் வலைச் சேவையகத்தின் ரூட் கோப்பகத்தில் சேமிக்கவும், அல்லது ரூட் கோப்பகத்தில் images என்ற கோப்பகத்தை உருவாக்கி, உங்கள் பேவிகான் படத்தை இந்த கோப்பகத்தில் சேமிக்கவும். பேவிகான் படத்தின் பொதுவான பெயர் "favicon.ico" ஆகும்.

அடுத்து, உங்கள் "index.html" கோப்பில் <title> உறுப்புக்குப் பிறகு ஒரு <link> உறுப்பைச் சேர்க்கவும்:

இப்போது, "index.html" கோப்பைச் சேமித்து உங்கள் உலாவியில் மீண்டும் ஏற்றவும். உங்கள் உலாவி தத்தில் பக்கத் தலைப்பின் இடதுபுறத்தில் உங்கள் பேவிகான் படம் காட்டப்படும்.
