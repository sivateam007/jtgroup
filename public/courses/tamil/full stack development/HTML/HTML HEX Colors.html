sk விளக்கம்:

#ff0000 சிவப்பாகக் காட்டப்படுகிறது, ஏனெனில் சிவப்பு அதன் அதிகபட்ச மதிப்பாக அமைக்கப்பட்டுள்ளது (ff), மற்ற இரண்டும் (பச்சை மற்றும் நீலம்) 00 ஆக அமைக்கப்பட்டுள்ளன.

#00ff00 பச்சையாகக் காட்டப்படுகிறது, ஏனெனில் பச்சை அதன் அதிகபட்ச மதிப்பாக அமைக்கப்பட்டுள்ளது (ff), மற்ற இரண்டும் (சிவப்பு மற்றும் நீலம்) 00 ஆக அமைக்கப்பட்டுள்ளன.

sk சோதனை:

சிலிண்டர்களை நகர்த்துவதன் மூலம் வெவ்வேறு HEX வண்ணங்களை உருவாக்க முயற்சிக்கவும். 00 முதல் ff வரையிலான மதிப்புகள் ஒவ்வொரு வண்ணத்தின் செறிவையும் கட்டுப்படுத்துகின்றன.

HEX இல் சாம்பல் நிறத்தின் நிழல்கள்

சாம்பல் நிறத்தின் நிழல்கள் பெரும்பாலும் மூன்று அளவுருக்களுக்கும் சமமான மதிப்புகளைப் பயன்படுத்தி வரையறுக்கப்படுகின்றன:

#404040
#686868
#a0a0a0
#bebebe
#dcdcdc
#f8f8f8

sk விதி:

HEX சாம்பல் நிறங்களுக்கு சிவப்பு, பச்சை மற்றும் நீலம் அனைத்தும் ஒரே HEX மதிப்பைக் கொண்டிருக்க வேண்டும். மதிப்பு 00 க்கு அருகில் இருந்தால் கருப்பு நிறத்திற்கு அருகில், ff க்கு அருகில் இருந்தால் வெள்ளை நிறத்திற்கு அருகில்.

HEX vs RGB ஒப்பீடு

அம்சம் HEX RGB
முழுப் பெயர் Hexadecimal Red Green Blue
சூத்திரம் #rrggbb rgb(r, g, b)
மதிப்பு வரம்பு 00-ff (அறுபதின்மம்) 0-255 (தசமம்)
பயன்பாடு வலைத் தரநிலை, CSS பொது நோக்கம்
சுருக்கம் #fff, #000 (3-digit) இல்லை
எடுத்துக்காட்டு #ff6347 rgb(255, 99, 71)

sk மாற்று சூத்திரம்:

HEX → RGB: ஒவ்வொரு HEX ஜோடியையும் தசமமாக மாற்றவும்
RGB → HEX: ஒவ்வொரு தசம மதிப்பையும் அறுபதின்மமாக மாற்றவும்
எ.கா: #ff6347 = rgb(255, 99, 71)

பயிற்சி

🔢 பின்வருவனவற்றில் எது அதிகபட்ச HEX எண்?

#44

தசமம்: 68

#AA

தசமம்: 170

#BB

தசமம்: 187

#44 (தசமம்: 68)
✗ தவறு! 44 என்பது குறைந்த HEX மதிப்பு
#AA (தசமம்: 170)
✗ தவறு! AA என்பது BB ஐ விட குறைவானது
#BB (தசமம்: 187)
✓ சரி! BB என்பது அதிகபட்ச HEX மதிப்பு (தசமம் 187)
#FF (தசமம்: 255)
✗ தவறு! FF சரியான பதில் அல்ல, அது விருப்பங்களில் இல்லை

sk HEX வரிசை:

HEX எண்களின் வரிசை: 0-9 (குறைந்தது), A-F (அதிகம்)
A=10, B=11, C=12, D=13, E=14, F=15 (தசமம்)
எனவே: #44 (68) < #AA (170) < #BB (187) < #FF (255)
