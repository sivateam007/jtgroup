HTML Paragraphs

ஒரு பத்தி எப்போதும் ஒரு புதிய வரியில் தொடங்கும், மேலும் இது பொதுவாக உரைப் பகுதியாக இருக்கும்.

📝 HTML பத்திகள்:

HTML <p> உறுப்பு ஒரு பத்தியை வரையறுக்கிறது.

ஒரு பத்தி எப்போதும் ஒரு புதிய வரியில் தொடங்குகிறது, மேலும் உலாவிகள் தானாகவே பத்திக்கு முன்னும் பின்னும் சில வெள்ளை இடைவெளியை (ஒரு விளிம்பு) சேர்க்கின்றன.

Example

<p>This is a paragraph.</p>
<p>This is another paragraph.</p>

HTML Display

HTML எவ்வாறு காட்சிப்படுத்தப்படும் என்பதை நீங்கள் உறுதியாக சொல்ல முடியாது.

பெரிய அல்லது சிறிய திரைகள், மற்றும் அளவு மாற்றப்பட்ட சாளரங்கள் வெவ்வேறு முடிவுகளை உருவாக்கும்.

⚠️ முக்கியமானது:

HTML உடன், உங்கள் HTML குறியீட்டில் கூடுதல் இடைவெளிகள் அல்லது கூடுதல் வரிகளைச் சேர்ப்பதன் மூலம் காட்சியை மாற்ற முடியாது.

பக்கத்தைக் காண்பிக்கும்போது உலாவி தானாகவே எந்த கூடுதல் இடைவெளிகளையும் வரிகளையும் நீக்கிவிடும்:

Example

<p>
This paragraph
contains a lot of lines
in the source code,
but the browser
ignores it.
</p>

<p>
This paragraph
contains         a lot of spaces
in the source         code,
but the        browser
ignores it.
</p>

HTML Horizontal Rules

<hr> குறிச்சொல் ஒரு HTML பக்கத்தில் ஒரு கருப்பொருள் முறிவை வரையறுக்கிறது, மேலும் பெரும்பாலும் கிடைமட்ட விதியாகக் காட்டப்படுகிறது.

<hr> உறுப்பு HTML பக்கத்தில் உள்ளடக்கத்தைப் பிரிக்க (அல்லது மாற்றத்தை வரையறுக்க) பயன்படுகிறது:

Example

<h1>This is heading 1</h1>
<p>This is some text.</p>
<hr>
<h2>This is heading 2</h2>
<p>This is some other text.</p>
<hr>

💡 குறிப்பு:

<hr> குறிச்சொல் ஒரு காலி குறிச்சொல், அதாவது அதற்கு முடிவு குறிச்சொல் இல்லை.

HTML Line Breaks

HTML <br> உறுப்பு ஒரு வரி முறிவை வரையறுக்கிறது.

புதிய பத்தியைத் தொடங்காமல் வரி முறிவு (புதிய வரி) வேண்டுமென்றால் <br> ஐப் பயன்படுத்தவும்:

Example

<p>This is<br>a paragraph<br>with line breaks.</p>

💡 குறிப்பு:

<br> குறிச்சொல் ஒரு காலி குறிச்சொல், அதாவது அதற்கு முடிவு குறிச்சொல் இல்லை.

The Poem Problem

இந்த கவிதை ஒரு ஒற்றை வரியில் காட்சிப்படுத்தப்படும்:

Example

<p>
  My Bonnie lies over the ocean.

  My Bonnie lies over the sea.

  My Bonnie lies over the ocean.

  Oh, bring back my Bonnie to me.
</p>

❌ பிரச்சனை:

மேலே உள்ள குறியீடு கவிதையை ஒற்றை வரியில் மட்டுமே காட்டும். வரி முறிவுகள் மற்றும் இடைவெளிகள் பாதுகாக்கப்படாது.

Solution - The HTML <pre> Element

HTML <pre> உறுப்பு முன்பே வடிவமைக்கப்பட்ட உரையை வரையறுக்கிறது.

<pre> உறுப்புக்குள் உள்ள உரை நிலையான-அகலமுள்ள எழுத்துருவில் (பொதுவாக Courier) காட்சிப்படுத்தப்படுகிறது, மேலும் இது இடைவெளிகள் மற்றும் வரி முறிவுகள் இரண்டையும் பாதுகாக்கிறது:

Example

<pre>
  My Bonnie lies over the ocean.

  My Bonnie lies over the sea.

  My Bonnie lies over the ocean.

  Oh, bring back my Bonnie to me.
</pre>

✅ தீர்வு:

<pre> குறிச்சொல் பயன்படுத்துவதன் மூலம் கவிதையின் அசல் வடிவமைப்பு முழுமையாகப் பாதுகாக்கப்படுகிறது.

Exercise

❓ சரி அல்லது தவறு. HTML பத்திகள் எப்போதும் புதிய வரியில் தொடங்கும்.

True
✓ சரி! HTML பத்திகள் எப்போதும் புதிய வரியில் தொடங்குகின்றன.
False
✗ தவறு! HTML இல், <p> குறிச்சொல் எப்போதும் புதிய வரியில் தொடங்கும்.
