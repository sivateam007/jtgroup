AngularJS Tutorial

AngularJS ஐக் கற்றுக்கொள்ளுங்கள்

AngularJS பற்றி

AngularJS புதிய பண்புக்கூறுகளுடன் HTML ஐ விரிவுபடுத்துகிறது.

AngularJS ஒற்றை பக்க பயன்பாடுகளுக்கு (SPAs) சிறந்தது.

AngularJS கற்க எளிதானது.

உதவிக்குறிப்பு:

உங்கள் முன்னேற்றத்தைக் கண்காணிக்க உள்நுழையவும் - இது இலவசம்.

இந்த டுடோரியல்

AngularJS ஐ முடிந்தவரை விரைவாகவும் திறம்படவும் கற்றுக்கொள்ள உங்களுக்கு உதவ இந்த டுடோரியல் சிறப்பாக வடிவமைக்கப்பட்டுள்ளது.

முதலில், AngularJS இன் அடிப்படைகளை நீங்கள் கற்றுக்கொள்வீர்கள்: directives, expressions, filters, modules, and controllers.

பின்னர் AngularJS பற்றி நீங்கள் தெரிந்து கொள்ள வேண்டிய மற்ற அனைத்தையும் நீங்கள் கற்றுக்கொள்வீர்கள்:

  • Events
  • DOM
  • Forms
  • Input
  • Validation
  • Http
  • மற்றும் பல

ஒவ்வொரு அத்தியாயத்திலும் உதாரணங்களை நீங்களே முயற்சிக்கவும்

ஒவ்வொரு அத்தியாயத்திலும், உதாரணங்களை ஆன்லைனில் திருத்தலாம், முடிவைப் பார்க்க ஒரு பொத்தானைக் கிளிக் செய்யலாம்.

AngularJS உதாரணம்

<!DOCTYPE html>
<html lang="en-US">
<script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.6.9/angular.min.js"></script>
<body>

<div ng-app="">
  <p>Name : <input type="text" ng-model="name"></p>
  <h1>Hello {{name}}</h1>
</div>

</body>
</html>

உங்களுக்கு முன்னரே தெரிந்திருக்க வேண்டியவை

நீங்கள் AngularJS ஐப் படிப்பதற்கு முன், நீங்கள் அடிப்படை புரிதலைக் கொண்டிருக்க வேண்டும்:

  • HTML
  • CSS
  • JavaScript

AngularJS வரலாறு

AngularJS பதிப்பு 1.0 2012 இல் வெளியிடப்பட்டது.

கூகிள் ஊழியரான மிஷ்கோ ஹெவெரி, 2009 இல் AngularJS உடன் பணியாற்றத் தொடங்கினார்.

இந்த யோசனை நன்றாக மாறியது, மேலும் இந்த திட்டம் இப்போது கூகிள் மூலம் அதிகாரப்பூர்வமாக ஆதரிக்கப்படுகிறது.

உங்கள் முன்னேற்றத்தைக் கண்காணிக்கவும்

ஒரு jassif team கணக்கை உருவாக்கி மேலும் அம்சங்கள் மற்றும் கற்றல் பொருட்களுக்கு அணுகலைப் பெறவும்:

  • ✔️ உங்கள் முடிக்கப்பட்ட டுடோரியல்கள், பயிற்சிகள் மற்றும் வினாடி வினாக்களைப் பார்க்கவும்
  • ✔️ உங்கள் முன்னேற்றம் மற்றும் தினசரி தொடர்ச்சிகளைக் கண்காணிக்கவும்
  • ✔️ லீடர்போர்டில் சேர்ந்து மற்றவர்களுடன் போட்டியிடவும்
  • ✔️ உங்கள் சொந்த அவதாரத்தைப் பெற்று புதிய தோல்களைத் திறக்கவும்
  • ✔️ உங்கள் சொந்த தனிப்பட்ட வலைத்தளத்தை உருவாக்கவும்
