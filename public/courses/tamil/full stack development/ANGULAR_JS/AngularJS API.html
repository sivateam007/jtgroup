AngularJS உலகளாவிய API

AngularJS உலகளாவிய API என்பது பொதுவான பணிகளைச் செய்வதற்கான உலகளாவிய JavaScript செயல்பாடுகளின் தொகுப்பாகும், எடுத்துக்காட்டாக:

  • பொருள்களை ஒப்பிடுதல்
  • பொருள்களை மீண்டும் மீண்டும் செய்தல்
  • தரவை மாற்றுதல்

உலகளாவிய API செயல்பாடுகள் angular பொருளைப் பயன்படுத்தி அணுகப்படுகின்றன.

சில பொதுவான API செயல்பாடுகளின் பட்டியல் கீழே உள்ளது:

API விளக்கம்
angular.lowercase() ஒரு சரத்தை சிறிய எழுத்துக்களாக மாற்றுகிறது
angular.uppercase() ஒரு சரத்தை பெரிய எழுத்துக்களாக மாற்றுகிறது
angular.isString() குறிப்பு ஒரு சரம் என்றால் true மதிப்பை திருப்பி அனுப்புகிறது
angular.isNumber() குறிப்பு ஒரு எண்ணாக இருந்தால் true மதிப்பை திருப்பி அனுப்புகிறது

angular.lowercase()

உதாரணம்

<div ng-app="myApp" ng-controller="myCtrl">
  <p>{{ x1 }}</p>
  <p>{{ x2 }}</p>
</div>

<script>
var app = angular.module('myApp', []);
app.controller('myCtrl', function($scope) {
  $scope.x1 = "JOHN";
  $scope.x2 = angular.lowercase($scope.x1);
});
</script>

விளக்கம்:

இந்த உதாரணத்தில், "JOHN" என்ற சரம் angular.lowercase() செயல்பாட்டைப் பயன்படுத்தி சிறிய எழுத்துக்களாக மாற்றப்படுகிறது. இதன் விளைவாக "john" கிடைக்கும்.

angular.uppercase()

உதாரணம்

<div ng-app="myApp" ng-controller="myCtrl">
  <p>{{ x1 }}</p>
  <p>{{ x2 }}</p>
</div>

<script>
var app = angular.module('myApp', []);
app.controller('myCtrl', function($scope) {
  $scope.x1 = "John";
  $scope.x2 = angular.uppercase($scope.x1);
});
</script>

விளக்கம்:

இந்த உதாரணத்தில், "John" என்ற சரம் angular.uppercase() செயல்பாட்டைப் பயன்படுத்தி பெரிய எழுத்துக்களாக மாற்றப்படுகிறது. இதன் விளைவாக "JOHN" கிடைக்கும்.

angular.isString()

உதாரணம்

<div ng-app="myApp" ng-controller="myCtrl">
  <p>{{ x1 }}</p>
  <p>{{ x2 }}</p>
</div>

<script>
var app = angular.module('myApp', []);
app.controller('myCtrl', function($scope) {
  $scope.x1 = "JOHN";
  $scope.x2 = angular.isString($scope.x1);
});
</script>

விளக்கம்:

இந்த உதாரணத்தில், angular.isString() செயல்பாடு $scope.x1 ஒரு சரமா என சோதிக்கிறது. "JOHN" ஒரு சரம் என்பதால், இது true மதிப்பை திருப்பி அனுப்பும்.

angular.isNumber()

உதாரணம்

<div ng-app="myApp" ng-controller="myCtrl">
  <p>{{ x1 }}</p>
  <p>{{ x2 }}</p>
</div>

<script>
var app = angular.module('myApp', []);
app.controller('myCtrl', function($scope) {
  $scope.x1 = "JOHN";
  $scope.x2 = angular.isNumber($scope.x1);
});
</script>

விளக்கம்:

இந்த உதாரணத்தில், angular.isNumber() செயல்பாடு $scope.x1 ஒரு எண்ணா என சோதிக்கிறது. "JOHN" ஒரு சரம் மற்றும் எண் அல்ல என்பதால், இது false மதிப்பை திருப்பி அனுப்பும்.

மேலதிக API செயல்பாடுகள்

AngularJS மேலும் பல பயனுள்ள உலகளாவிய API செயல்பாடுகளை வழங்குகிறது:

angular.equals()

இரண்டு மதிப்புகள் சமமானதா என சோதிக்கிறது

angular.copy()

ஒரு பொருளின் ஆழமான நகலை உருவாக்குகிறது

angular.isObject()

குறிப்பு ஒரு பொருளா என சோதிக்கிறது

angular.isArray()

குறிப்பு ஒரு அணியா என சோதிக்கிறது

பயிற்சி

கீழே உள்ள பயிற்சியில் AngularJS API செயல்பாடுகள் பற்றிய உங்கள் புரிதலை சோதிக்கவும்:

AngularJS API பயிற்சி

angular.lowercase() ஒரு சரத்தை சிறிய எழுத்துக்களாக மாற்றுகிறது
✓ சரி! இந்த செயல்பாடு சரத்தை சிறிய எழுத்துக்களாக மாற்றும்
angular.isString() எப்போதும் false திருப்பி அனுப்பும்
✗ தவறு! angular.isString() சரம் இருந்தால் true, இல்லையெனில் false திருப்பி அனுப்பும்
angular.isNumber("123") இன் மதிப்பு true ஆகும்
✓ சரி! "123" ஒரு சரம் எண் அல்ல, எனவே false திருப்பி அனுப்பும்
API செயல்பாடுகளை $scope பொருளைப் பயன்படுத்தி அணுக வேண்டும்
✗ தவறு! API செயல்பாடுகளை angular பொருளைப் பயன்படுத்தி அணுக வேண்டும்
