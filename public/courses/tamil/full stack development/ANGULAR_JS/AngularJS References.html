AngularJS References

AngularJS இன் அனைத்து உத்தரவுகள், வடிகட்டிகள் மற்றும் API செயல்பாடுகளின் முழுமையான குறிப்பு.

குறிப்பு:

இந்த பக்கத்தை AngularJS டெவலப்பர்களுக்கான கையேடாகப் பயன்படுத்தலாம். வேகமான குறிப்பிற்காக Ctrl+F பயன்படுத்தவும்.

மாற்றுதல்

API விளக்கம்
angular.lowercase() ஒரு சரத்தை சிறிய எழுத்துக்களாக மாற்றுகிறது
angular.uppercase() ஒரு சரத்தை பெரிய எழுத்துக்களாக மாற்றுகிறது
angular.copy() ஒரு பொருள் அல்லது அணியின் ஆழமான நகலை உருவாக்குகிறது
angular.forEach() ஒரு பொருள் அல்லது அணியில் உள்ள ஒவ்வொரு உறுப்புக்கும் ஒரு செயல்பாட்டை இயக்குகிறது

angular.isDate() குறிப்பு ஒரு தேதி என்றால் true திருப்பி அனுப்புகிறது

angular.isElement() குறிப்பு ஒரு DOM உறுப்பு என்றால் true திருப்பி அனுப்புகிறது
angular.isFunction() குறிப்பு ஒரு செயல்பாடு என்றால் true திருப்பி அனுப்புகிறது
angular.isNumber() குறிப்பு ஒரு எண் என்றால் true திருப்பி அனுப்புகிறது

angular.isString() குறிப்பு ஒரு சரம் என்றால் true திருப்பி அனுப்புகிறது
angular.isUndefined() குறிப்பு வரையறுக்கப்படாதது என்றால் true திருப்பி அனுப்புகிறது
angular.equals() இரண்டு குறிப்புகள் சமமானவை என்றால் true திருப்பி அனுப்புகிறது

angular.module() AngularJS தொகுதியை உருவாக்குகிறது, பதிவு செய்கிறது அல்லது பெறுகிறது

பயிற்சி

கீழே உள்ள பயிற்சியில் AngularJS குறிப்புகள் பற்றிய உங்கள் புரிதலை சோதிக்கவும்:

AngularJS குறிப்புகள் பயிற்சி

ng-app பயன்பாட்டின் வேர் உறுப்பை வரையறுக்கிறது
✓ சரி! ng-app AngularJS பயன்பாட்டின் தொடக்கப் புள்ளியாகும்
ng-repeat வடிகட்டி ஒரு வகையாகும்
✗ தவறு! ng-repeat ஒரு உத்தரவு, வடிகட்டி அல்ல
angular.isString() சரம் இருந்தால் true திருப்பி அனுப்புகிறது
✓ சரி! இந்த API சரம் வகையை சோதிக்கிறது
$dirty மதிப்பு செல்லாததா என்பதைக் குறிக்கிறது
✗ தவறு! $dirty பயனர் மாற்றியதா என்பதைக் குறிக்கிறது, $invalid செல்லாததைக் குறிக்கிறது
