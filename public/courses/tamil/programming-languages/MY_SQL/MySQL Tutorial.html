MySQL Tutorial

MySQL என்பது பரவலாகப் பயன்படுத்தப்படும் ஒரு தொடர்புடைய தரவுத்தள மேலாண்மை அமைப்பு (RDBMS) ஆகும்.

MySQL இலவசமானது மற்றும் திறந்த மூலமாகும்.

MySQL சிறிய மற்றும் பெரிய பயன்பாடுகள் இரண்டிற்கும் ஏற்றதாகும்.

🏁 உதவிக்குறிப்பு:

உங்கள் முன்னேற்றத்தைக் கண்காணிக்க உள்நுழையவும் - இது இலவசம்.

ஒவ்வொரு அத்தியாயத்திலும் எடுத்துக்காட்டுகள்

எங்கள் ஆன்லைன் MySQL எடிட்டருடன், நீங்கள் SQL அறிக்கைகளைத் திருத்தலாம், மற்றும் முடிவைக் காண ஒரு பொத்தானைக் கிளிக் செய்யலாம்.

எடுத்துக்காட்டு: உங்கள் சொந்த SQL சர்வரைப் பெறுங்கள்

SELECT * FROM Customers;

அது எவ்வாறு செயல்படுகிறது என்பதைப் பார்க்க "Try it Yourself" பொத்தானைக் கிளிக் செய்யவும்.

MySQL பயிற்சிகள்

இந்த டுடோரியலில் உள்ள பல அத்தியாயங்கள் உங்கள் அறிவு நிலையைச் சரிபார்க்கக்கூடிய ஒரு பயிற்சியுடன் முடிகின்றன.

❓ பயிற்சி:

சட்டபூர்வமான SQL அறிக்கையை உருவாக்க சரியான பகுதிகளை தேர்வு செய்யவும்:

INSERT
✗ தவறு! இது சரியான தொடக்கமல்ல
SELECT
✓ சரி! SELECT என்பது சரியான தொடக்கம்
*
✓ சரி! * அனைத்து நெடுவரிசைகளையும் தேர்ந்தெடுக்கிறது
FROM
✓ சரி! FROM அட்டவணையைக் குறிப்பிடுகிறது
Customers
✓ சரி! Customers என்பது அட்டவணைப் பெயர்
UPDATE
✗ தவறு! இது SELECT அறிக்கையின் பகுதியல்ல
