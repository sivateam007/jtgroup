MySQL ALTER TABLE Statement

MySQL இல் ALTER TABLE அறிக்கையைப் பயன்படுத்தி இருக்கும் அட்டவணையில் நெடுவரிசைகளைச் சேர்த்தல், நீக்குதல் அல்லது மாற்றுதல் கற்றுக்கொள்ளுங்கள்

MySQL ALTER TABLE அறிக்கை

ALTER TABLE அறிக்கை இருக்கும் அட்டவணையில் நெடுவரிசைகளைச் சேர்த்தல், நீக்குதல் அல்லது மாற்றப் பயன்படுகிறது.

ALTER TABLE அறிக்கை இருக்கும் அட்டவணையில் பல்வேறு கட்டுப்பாடுகளைச் சேர்த்தல் மற்றும் நீக்கவும் பயன்படுகிறது.

ALTER TABLE - ADD நெடுவரிசை

ஒரு அட்டவணையில் ஒரு நெடுவரிசையைச் சேர்க்க, பின்வரும் தொடரியலைப் பயன்படுத்தவும்:

ALTER TABLE table_name
ADD column_name datatype;

பின்வரும் SQL "Customers" அட்டவணையில் "Email" நெடுவரிசையைச் சேர்க்கிறது:

ALTER TABLE Customers
ADD Email varchar(255);

ALTER TABLE - DROP COLUMN

ஒரு அட்டவணையில் ஒரு நெடுவரிசையை நீக்க, பின்வரும் தொடரியலைப் பயன்படுத்தவும் (சில தரவுத்தள அமைப்புகள் ஒரு நெடுவரிசையை நீக்குவதை அனுமதிக்காது என்பதைக் கவனிக்கவும்):

ALTER TABLE table_name
DROP COLUMN column_name;

பின்வரும் SQL "Customers" அட்டவணையிலிருந்து "Email" நெடுவரிசையை நீக்குகிறது:

ALTER TABLE Customers
DROP COLUMN Email;

ALTER TABLE - MODIFY COLUMN

ஒரு அட்டவணையில் ஒரு நெடுவரிசையின் தரவு வகையை மாற்ற, பின்வரும் தொடரியலைப் பயன்படுத்தவும்:

ALTER TABLE table_name
MODIFY COLUMN column_name datatype;

MySQL ALTER TABLE எடுத்துக்காட்டு

இப்போது "Persons" அட்டவணையில் "DateOfBirth" என்ற நெடுவரிசையைச் சேர்க்க விரும்புகிறோம்.

நாம் பின்வரும் SQL கூற்றைப் பயன்படுத்துகிறோம்:

ALTER TABLE Persons
ADD DateOfBirth date;

💡 குறிப்பு:

புதிய நெடுவரிசை "DateOfBirth" date வகையைச் சேர்ந்தது மற்றும் ஒரு தேதியை வைத்திருக்கும். தரவு வகை நெடுவரிசை எந்த வகை தரவை வைத்திருக்க முடியும் என்பதைக் குறிப்பிடுகிறது. MySQL இல் கிடைக்கும் அனைத்து தரவு வகைகளின் முழுமையான குறிப்பிற்கு, எங்கள் முழுமையான Data Types குறிப்பிற்குச் செல்லவும்.

இப்போது "Persons" அட்டவணையில் "DateOfBirth" என்ற நெடுவரிசையின் தரவு வகையை மாற்ற விரும்புகிறோம்.

நாம் பின்வரும் SQL கூற்றைப் பயன்படுத்துகிறோம்:

ALTER TABLE Persons
MODIFY COLUMN DateOfBirth year;

"DateOfBirth" நெடுவரிசை இப்போது year வகையைச் சேர்ந்தது மற்றும் இரண்டு- அல்லது நான்கு-இலக்க வடிவத்தில் ஒரு ஆண்டை வைத்திருக்கும்.
