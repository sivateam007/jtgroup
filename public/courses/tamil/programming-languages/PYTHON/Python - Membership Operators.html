Python - உறுப்பினர் செயலிகள்

உறுப்பினர் செயலிகள் ஒரு வரிசை ஒரு பொருளில் உள்ளதா என்று சோதிக்கப் பயன்படுத்தப்படுகின்றன.

உறுப்பினர் செயலிகள்

செயலி விளக்கம் எடுத்துக்காட்டு
in குறிப்பிட்ட மதிப்பு கொண்ட வரிசை பொருளில் இருந்தால் True தரும் x in y
not in குறிப்பிட்ட மதிப்பு கொண்ட வரிசை பொருளில் இல்லையென்றால் True தரும் x not in y

எடுத்துக்காட்டுகள்

பட்டியலில் உள்ளதா என்று சோதிக்கவும்

"banana" பட்டியலில் உள்ளதா என்று சோதிக்கவும்:

fruits = ["apple", "banana", "cherry"]

print("banana" in fruits)

வெளியீடு: True

பட்டியலில் இல்லை என்று சோதிக்கவும்

"pineapple" பட்டியலில் இல்லை என்று சோதிக்கவும்:

fruits = ["apple", "banana", "cherry"]

print("pineapple" not in fruits)

வெளியீடு: True

சரங்களில் உறுப்பினர் சோதனை

உறுப்பினர் செயலிகள் சரங்களிலும் வேலை செய்கின்றன:

🏁 உதவிக்குறிப்பு:

சரங்களில் உறுப்பினர் செயலிகள் எழுத்துக்கள் அல்லது சரத் துண்டுகளை சோதிக்க பயன்படுகின்றன.

எடுத்துக்காட்டு

text = "Hello World"

print("H" in text)     # True
print("hello" in text) # False (case-sensitive)
print("z" not in text) # True

⚠️ கவனிக்க:

பைத்தானில் உறுப்பினர் சோதனைகள் வழக்கு உணர்திறன் கொண்டவை. "H" மற்றும் "h" வெவ்வேறு எழுத்துகளாகக் கருதப்படுகின்றன.

இரண்டு உறுப்பினர் செயலிகளின் ஒப்பீடு

in செயலி

பயன்பாடு: ஒரு மதிப்பு வரிசையில் உள்ளதா என்று சோதிக்க

திரும்பும் மதிப்பு: உள்ளது என்றால் True, இல்லையென்றால் False

எடுத்துக்காட்டு:

numbers = [1, 2, 3]
print(2 in numbers)  # True
print(5 in numbers)  # False

not in செயலி

பயன்பாடு: ஒரு மதிப்பு வரிசையில் இல்லை என்று சோதிக்க

திரும்பும் மதிப்பு: இல்லையென்றால் True, உள்ளது என்றால் False

எடுத்துக்காட்டு:

colors = ["red", "green", "blue"]
print("yellow" not in colors)  # True
print("red" not in colors)     # False

மேலும் எடுத்துக்காட்டுகள்

டப்பிள்களில் உறுப்பினர் சோதனை

டப்பிள்களிலும் உறுப்பினர் செயலிகள் வேலை செய்கின்றன:

coordinates = (10, 20, 30)
print(20 in coordinates)  # True
print(40 in coordinates)  # False

சொற்களஞ்சியத்தில் உறுப்பினர் சோதனை

சொற்களஞ்சியத்தில் விசைகளைச் சோதிக்க:

person = {"name": "John", "age": 30}
print("name" in person)   # True (checks keys)
print("John" in person)   # False (doesn't check values)

💡 முக்கிய குறிப்பு:

சொற்களஞ்சியங்களில் in செயலி விசைகளை மட்டுமே சோதிக்கிறது, மதிப்புகளை அல்ல. மதிப்புகளைச் சோதிக்க values() முறையைப் பயன்படுத்தவும்.

பயிற்சி

in செயலி என்ன செய்கிறது?

❓ பயிற்சி கேள்வி:

ஒரு மதிப்பு வரிசையில் உள்ளதா என்று சோதிக்கிறது
✓ சரி! in செயலி ஒரு மதிப்பு வரிசை, சரம், டப்பிள் அல்லது சொற்களஞ்சியத்தில் உள்ளதா என்று சோதிக்கிறது
ஒரு மதிப்பை பட்டியலில் சேர்க்கிறது
✗ தவறு! மதிப்புகளை பட்டியலில் சேர்க்க append() அல்லது insert() முறைகளைப் பயன்படுத்துகிறோம்
இரண்டு மதிப்புகளை ஒப்பிடுகிறது
✗ தவறு! மதிப்புகளை ஒப்பிட ==, !=, <, > போன்ற ஒப்பீட்டு செயலிகளைப் பயன்படுத்துகிறோம்

சிறந்த நடைமுறைகள்

வழக்கு உணர்திறனை நினைவில் கொள்ளுங்கள்: சரங்களில் உறுப்பினர் சோதனைகள் வழக்கு உணர்திறன் கொண்டவை.
சொற்களஞ்சிய விசைகளை சோதிக்க: சொற்களஞ்சியங்களில் in செயலி விசைகளை மட்டுமே சோதிக்கிறது.
நேர்த்தியான குறியீட்டிற்காகப் பயன்படுத்தவும்: பட்டியல் மீது லூப் அடிப்பதை விட in செயலி நேர்த்தியானது.
