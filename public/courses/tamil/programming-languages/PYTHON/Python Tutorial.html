Python பயிற்சிகள்

இந்த டுடோரியலில் உள்ள பல அத்தியாயங்கள் உங்கள் அறிவு நிலையைச் சரிபார்க்கக்கூடிய பயிற்சியுடன் முடிகின்றன.

❓ Python மாறியை அறிவிக்க சரியான வழி எது?

var x = 5
✗ தவறு! var என்பது Python இல் பயன்படுத்தப்படுவதில்லை
#x = 5
✗ தவறு! # என்பது கருத்துரைக்கானது, மாறி அறிவிப்புக்கு அல்ல
$x = 5
✗ தவறு! $ என்பது Python இல் மாறி பெயர்களில் அனுமதிக்கப்படாது
x = 5
✓ சரி! Python இல் மாறிகள் எந்த வகை அறிவிப்பும் இல்லாமல் நேரடியாக ஒதுக்கப்படுகின்றன

Python எடுத்துக்காட்டுகள்
