Python PIP

Python பேக்கேஜ் மேலாளர் பற்றி கற்றுக்கொள்ளுங்கள்

What is PIP?

PIP என்பது Python பேக்கேஜ்களுக்கான ஒரு பேக்கேஜ் மேலாளர், அல்லது நீங்கள் விரும்பினால் தொகுதிகள்.

💡 குறிப்பு:

உங்களிடம் Python பதிப்பு 3.4 அல்லது அதற்கு மேல் இருந்தால், PIP இயல்பாக சேர்க்கப்பட்டுள்ளது.

What is a Package?

ஒரு பேக்கேஜ் ஒரு தொகுதிக்கு தேவையான அனைத்து கோப்புகளையும் கொண்டுள்ளது.

தொகுதிகள் என்பது உங்கள் திட்டத்தில் சேர்க்கக்கூடிய Python குறியீட்டு நூலகங்கள் ஆகும்.

Check if PIP is Installed

Python இன் ஸ்கிரிப்ட் கோப்பக இடத்திற்கு உங்கள் கட்டளை வரியை செலுத்தி, பின்வருவனவற்றைத் தட்டச்சு செய்யவும்:

எடுத்துக்காட்டு

உங்கள் சொந்த Python சேவையகத்தைப் பெறவும்:

PIP பதிப்பை சரிபார்க்கவும்:

C:\Users\Your Name\AppData\Local\Programs\Python\Python36-32\Scripts>pip --version

Install PIP

உங்களிடம் PIP நிறுவப்பட்டிருக்கவில்லை என்றால், இந்தப் பக்கத்திலிருந்து நீங்கள் அதைப் பதிவிறக்கம் செய்து நிறுவலாம்: https://pypi.org/project/pip/

Download a Package

ஒரு பேக்கேஜை பதிவிறக்கம் செய்வது மிகவும் எளிதானது.

கட்டளை வரி இடைமுகத்தைத் திறந்து, நீங்கள் விரும்பும் பேக்கேஜைப் பதிவிறக்கம் செய்ய PIP க்குச் சொல்லவும்.

Python இன் ஸ்கிரிப்ட் கோப்பக இடத்திற்கு உங்கள் கட்டளை வரியை செலுத்தி, பின்வருவனவற்றைத் தட்டச்சு செய்யவும்:

எடுத்துக்காட்டு

"camelcase" என்ற பேக்கேஜைப் பதிவிறக்கவும்:

C:\Users\Your Name\AppData\Local\Programs\Python\Python36-32\Scripts>pip install camelcase

இப்போது நீங்கள் உங்கள் முதல் பேக்கேஜைப் பதிவிறக்கம் செய்து நிறுவியுள்ளீர்கள்!

Using a Package

பேக்கேஜ் நிறுவப்பட்டதும், அதைப் பயன்படுத்த தயாராக உள்ளது.

"camelcase" பேக்கேஜை உங்கள் திட்டத்தில் இறக்குமதி செய்யவும்.

எடுத்துக்காட்டு

"camelcase" ஐ இறக்குமதி செய்து பயன்படுத்தவும்:

import camelcase

c = camelcase.CamelCase()

txt = "hello world"

print(c.hump(txt))

இந்த குறியீடு "hello world" ஐ "Hello World" ஆக மாற்றி அச்சிடும்.

Find Packages

https://pypi.org/ இல் கூடுதல் பேக்கேஜ்களைக் கண்டறியவும்.

Remove a Package

ஒரு பேக்கேஜை அகற்ற uninstall கட்டளையைப் பயன்படுத்தவும்:

எடுத்துக்காட்டு

"camelcase" என்ற பேக்கேஜை நிறுவல் நீக்கவும்:

C:\Users\Your Name\AppData\Local\Programs\Python\Python36-32\Scripts>pip uninstall camelcase

PIP பேக்கேஜ் மேலாளர் camelcase பேக்கேஜை அகற்ற விரும்புகிறீர்களா என உங்களிடம் உறுதிப்படுத்தக் கேட்கும்:

Uninstalling camelcase-02.1:
  Would remove:
    c:\users\Your Name\appdata\local\programs\python\python36-32\lib\site-packages\camelcase-0.2-py3.6.egg-info
    c:\users\Your Name\appdata\local\programs\python\python36-32\lib\site-packages\camelcase\*
Proceed (y/n)?

y ஐ அழுத்தவும், பேக்கேஜ் அகற்றப்படும்.

List Packages

உங்கள் கணினியில் நிறுவப்பட்ட அனைத்து பேக்கேஜ்களையும் பட்டியலிட list கட்டளையைப் பயன்படுத்தவும்:

எடுத்துக்காட்டு

நிறுவப்பட்ட பேக்கேஜ்களை பட்டியலிடவும்:

C:\Users\Your Name\AppData\Local\Programs\Python\Python36-32\Scripts>pip list

பயிற்சி

❓ Python உலகில், PIP ஐ சிறப்பாக விவரிப்பது எது?

PIP என்பது வரைதலுக்குப் பயன்படுத்தப்படும் ஒரு தொகுதி
✗ தவறு! PIP வரைதல் தொகுதியல்ல, அது ஒரு பேக்கேஜ் மேலாளர்
PIP என்பது பெரிய அளவிலான தரவைக் கையாளப் பயன்படும் ஒரு தொகுதி
✗ தவறு! PIP பெரிய தரவைக் கையாளப் பயன்படுவதில்லை, அது Python தொகுதிகளை நிர்வகிக்கிறது
PIP என்பது Python தொகுதிகளுக்கான ஒரு பேக்கேஜ் மேலாளர்
✓ சரி! PIP (PIP Installs Packages) என்பது Python தொகுதிகள் மற்றும் பேக்கேஜ்களை நிறுவுவதற்கும் நிர்வகிப்பதற்கும் பயன்படுத்தப்படும் பேக்கேஜ் மேலாளர் ஆகும்
