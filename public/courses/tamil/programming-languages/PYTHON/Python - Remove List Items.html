Python - Remove List Items

பைத்தான் - பட்டியல் உருப்படிகளை நீக்குதல்

Remove Specified Item

remove() முறை குறிப்பிடப்பட்ட உருப்படியை நீக்குகிறது.

Example

thislist = ["apple", "banana", "cherry"]
thislist.remove("banana")
print(thislist)

குறிப்பிட்ட மதிப்புடன் ஒன்றுக்கு மேற்பட்ட உருப்படிகள் இருந்தால், remove() முறை முதல் நிகழ்வை நீக்குகிறது:

Example

thislist = ["apple", "banana", "cherry", "banana", "kiwi"]
thislist.remove("banana")
print(thislist)

Remove Specified Index

pop() முறை குறிப்பிடப்பட்ட குறியீட்டை நீக்குகிறது.

Example

thislist = ["apple", "banana", "cherry"]
thislist.pop(1)
print(thislist)

நீங்கள் குறியீட்டைக் குறிப்பிடவில்லை என்றால், pop() முறை கடைசி உருப்படியை நீக்கும்.

Example

thislist = ["apple", "banana", "cherry"]
thislist.pop()
print(thislist)

The del Keyword

del விசேஷ சொல் குறிப்பிடப்பட்ட குறியீட்டையும் நீக்குகிறது:

Example

thislist = ["apple", "banana", "cherry"]
del thislist[0]
print(thislist)

del விசேஷ சொல் பட்டியலை முழுவதுமாக நீக்கவும் முடியும்.

Example

thislist = ["apple", "banana", "cherry"]
del thislist

Clear the List

clear() முறை பட்டியலை காலியாக்குகிறது.

பட்டியல் இன்னும் இருக்கும், ஆனால் அதற்கு உள்ளடக்கம் இல்லை.

Example

thislist = ["apple", "banana", "cherry"]
thislist.clear()
print(thislist)

Remove Methods Comparison

Method Description Example
remove() மதிப்பின் அடிப்படையில் உருப்படியை நீக்குகிறது list.remove("item")
pop() குறியீட்டின் அடிப்படையில் உருப்படியை நீக்குகிறது (இல்லையெனில் கடைசி உருப்படி) list.pop(1) or list.pop()
del குறியீட்டின் அடிப்படையில் உருப்படியை நீக்குகிறது அல்லது முழு பட்டியலையும் நீக்குகிறது del list[0] or del list
clear() பட்டியலை காலியாக்குகிறது ஆனால் பட்டியலை நீக்காது list.clear()

List Removal Methods

❌
remove()
list.remove(value)

மதிப்பின் மூலம் உருப்படியை நீக்குகிறது

📌
pop()
list.pop(index)

குறியீட்டின் மூலம் உருப்படியை நீக்குகிறது, திரும்பப் பெறுகிறது

🗑️
del
del list[index]

குறியீட்டின் மூலம் உருப்படியை நீக்குகிறது, திரும்பப் பெறாது

🧹
clear()
list.clear()

பட்டியலை காலியாக்குகிறது, ஆனால் நீக்காது
