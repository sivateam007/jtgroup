String Concatenation

இரண்டு சரங்களை இணைக்க அல்லது ஒருங்கிணைக்க, நீங்கள் + ஆபரேட்டரைப் பயன்படுத்தலாம்.

Example

a = "Hello"
b = "World"
c = a + b
print(c)

Adding Space

அவற்றுக்கிடையே ஒரு இடைவெளியைச் சேர்க்க, " " ஐச் சேர்க்கவும்:

Example

a = "Hello"
b = "World"
c = a + " " + b
print(c)

Concatenation Examples

➕
Basic Concatenation
a = "Hello"
b = "World"
c = a + b
# Result: "HelloWorld"
␣➕
With Space
a = "Hello"
b = "World"
c = a + " " + b
# Result: "Hello World"
🔤➕
Multiple Strings
a = "I"
b = "love"
c = "Python"
result = a + " " + b + " " + c
⚠️
String + Number Error
name = "John"
age = 25
# This will cause error:
# info = name + age
# Use: info = name + " " + str(age)

💡 முக்கியமான குறிப்பு:

சரங்கள் மற்றும் எண்களை + ஆபரேட்டருடன் நேரடியாக இணைக்க முடியாது. எண்களை சரங்களாக மாற்ற str() செயல்பாட்டைப் பயன்படுத்தவும்.

Exercise

❓ x மற்றும் y மாறிகளை z மாறியில் இணைக்க சரியான தொடரியல் எது?

z = x, y
✗ தவறு! காற்புள்ளி மாறிகளைப் பிரிக்கிறது, ஆனால் சரங்களை இணைக்காது
z = x = y
✗ தவறு! இது மாறிகளுக்கு மதிப்பை ஒதுக்குகிறது, சரங்களை இணைக்காது
z = x + y
✓ சரி! + ஆபரேட்டர் பைத்தானில் சரங்களை இணைக்கப் பயன்படுகிறது
