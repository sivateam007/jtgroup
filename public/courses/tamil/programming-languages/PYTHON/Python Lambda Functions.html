Python Lambda Functions

Python லாம்ப்டா செயல்பாடுகளைக் கற்றுக்கொள்ளுங்கள்

Python Lambda Functions

லாம்ப்டா செயல்பாடு என்பது ஒரு சிறிய அநாமதேய செயல்பாடு ஆகும்.

லாம்ப்டா செயல்பாடு எத்தனை வாதங்களையும் எடுத்துக்கொள்ள முடியும், ஆனால் ஒரே ஒரு வெளிப்பாடு மட்டுமே இருக்க முடியும்.

💡 முக்கிய குறிப்பு:

லாம்ப்டா செயல்பாடுகள் குறுகிய நேரத்திற்கு அநாமதேய செயல்பாடு தேவைப்படும் போது பயன்படுத்தப்படுகின்றன.

லாம்ப்டா தொடரியல்

Syntax

lambda arguments : expression

வெளிப்பாடு செயல்படுத்தப்பட்டு, முடிவு திரும்பப் பெறப்படுகிறது:

Example

வாதத்துடன் 10ஐ கூட்டி, முடிவைத் திருப்பி அனுப்பவும்:

x = lambda a : a + 10
print(x(5))
Output: 15

பல வாதங்களுடன் லாம்ப்டா

லாம்ப்டா செயல்பாடுகள் எத்தனை வாதங்களையும் எடுத்துக்கொள்ள முடியும்:

Example

வாதம் aயை வாதம் b உடன் பெருக்கி, முடிவைத் திருப்பி அனுப்பவும்:

x = lambda a, b : a * b
print(x(5, 6))
Output: 30

Example

வாதங்கள் a, b, மற்றும் cயை சுருக்கி, முடிவைத் திருப்பி அனுப்பவும்:

x = lambda a, b, c : a + b + c
print(x(5, 6, 2))
Output: 13

ஏன் லாம்ப்டா செயல்பாடுகளைப் பயன்படுத்த வேண்டும்?

லாம்ப்டாவின் சக்தி மற்றொரு செயல்பாட்டின் உள்ளே அநாமதேய செயல்பாடாக அவற்றைப் பயன்படுத்தும் போது சிறப்பாகக் காட்டப்படுகிறது.

ஒரு வாதத்தை எடுத்துக்கொள்ளும் ஒரு செயல்பாடு வரையறை உங்களிடம் உள்ளது என்று சொல்லுங்கள், மேலும் அந்த வாதம் தெரியாத எண்ணால் பெருக்கப்படும்:

def myfunc(n):
    return lambda a : a * n

Example - Doubler Function

நீங்கள் அனுப்பும் எண்ணை எப்போதும் இரட்டிப்பாக்கும் ஒரு செயல்பாட்டை உருவாக்க அந்த செயல்பாடு வரையறையைப் பயன்படுத்தவும்:

def myfunc(n):
    return lambda a : a * n

mydoubler = myfunc(2)
print(mydoubler(11))
Output: 22

Example - Tripler Function

அல்லது, நீங்கள் அனுப்பும் எண்ணை எப்போதும் மூன்று மடங்காக்கும் ஒரு செயல்பாட்டை உருவாக்க அதே செயல்பாடு வரையறையைப் பயன்படுத்தவும்:

def myfunc(n):
    return lambda a : a * n

mytripler = myfunc(3)
print(mytripler(11))
Output: 33

Example - Both Functions

அல்லது, அதே நிரலில் இரண்டு செயல்பாடுகளையும் உருவாக்க அதே செயல்பாடு வரையறையைப் பயன்படுத்தவும்:

def myfunc(n):
    return lambda a : a * n

mydoubler = myfunc(2)
mytripler = myfunc(3)

print(mydoubler(11))
print(mytripler(11))
Output: 22
33

உள்ளமைக்கப்பட்ட செயல்பாடுகளுடன் லாம்ப்டா

லாம்ப்டா செயல்பாடுகள் பொதுவாக map(), filter(), மற்றும் sorted() போன்ற உள்ளமைக்கப்பட்ட செயல்பாடுகளுடன் பயன்படுத்தப்படுகின்றன.

map() உடன் லாம்ப்டாவைப் பயன்படுத்துதல்

map() செயல்பாடு ஒரு தொகுப்பில் உள்ள ஒவ்வொரு உருப்படிக்கும் ஒரு செயல்பாட்டைப் பயன்படுத்துகிறது:

# பட்டியலில் உள்ள அனைத்து எண்களையும் இரட்டிப்பாக்கவும்
numbers = [1, 2, 3, 4, 5]
doubled = list(map(lambda x: x * 2, numbers))
print(doubled)
Output: [2, 4, 6, 8, 10]

filter() உடன் லாம்ப்டாவைப் பயன்படுத்துதல்

filter() செயல்பாடு ஒரு செயல்பாடு True ஐ திருப்பி அனுப்பும் உருப்படிகளின் பட்டியலை உருவாக்குகிறது:

# பட்டியலில் இருந்து இரட்டை எண்களை வடிகட்டவும்
numbers = [1, 2, 3, 4, 5, 6, 7, 8]
odd_numbers = list(filter(lambda x: x % 2 != 0, numbers))
print(odd_numbers)
Output: [1, 3, 5, 7]

sorted() உடன் லாம்ப்டாவைப் பயன்படுத்துதல்

sorted() செயல்பாடு தனிப்பயன் வரிசைப்படுத்தலுக்கான விசையாக லாம்ப்டாவைப் பயன்படுத்தலாம்:

# இரண்டாவது உறுப்பின்படி டுபில்களின் பட்டியலை வரிசைப்படுத்தவும்
students = [("Emil", 25), ("Tobias", 22), ("Linus", 28)]
sorted_students = sorted(students, key=lambda x: x[1])
print(sorted_students)
Output: [('Tobias', 22), ('Emil', 25), ('Linus', 28)]
# நீளத்தின் அடிப்படையில் சரங்களை வரிசைப்படுத்தவும்
words = ["apple", "pie", "banana", "cherry"]
sorted_words = sorted(words, key=lambda x: len(x))
print(sorted_words)
Output: ['pie', 'apple', 'cherry', 'banana']

பின்வரும் குறியீட்டின் முடிவு என்னவாக இருக்கும்:

❓ பின்வரும் குறியீட்டின் வெளியீடு என்னவாக இருக்கும்?

x = lambda a, b : a - b
print(x(5, 3))
15
✗ தவறு! இது பெருக்கல் அல்ல, கழித்தல் ஆகும்
8
✗ தவறு! இது கூட்டல் அல்ல, கழித்தல் ஆகும்
3
✗ தவறு! இது 5 - 3 = 2 ஆகும், 3 அல்ல
2
✓ சரி! லாம்ப்டா செயல்பாடு 5 - 3 = 2 ஐ கணக்கிடுகிறது

💡 விளக்கம்:

லாம்ப்டா செயல்பாடு lambda a, b : a - b இரண்டு எண்களை எடுத்து முதல் எண்ணிலிருந்து இரண்டாவது எண்ணைக் கழிக்கிறது. x(5, 3) என்பது 5 - 3 = 2 ஐ திருப்பி அனுப்பும்.
