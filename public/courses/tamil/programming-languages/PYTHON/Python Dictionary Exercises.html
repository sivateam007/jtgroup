ஒவ்வொரு வகையிலும் 3 முதல் 9 வரை கேள்விகள் உள்ளன.

பதிலை தொடர்புடைய டுடோரியல் அத்தியாயத்தில் காணலாம்.

நீங்கள் மாட்டிக்கொண்டால் அல்லது தவறாக பதிலளித்தால், மீண்டும் முயற்சிக்கலாம் அல்லது சரியான பதிலைக் காண "Show Answer" பொத்தானை அழுத்தலாம்.

🎯 பயிற்சி எடுத்துக்காட்டு:

student = {"name": "ராம்", "age": 20, "grade": "A"}

மேலே உள்ள டிக்ஷனரியில் "age" விசையின் மதிப்பை அணுகுவதற்கான சரியான தொடரியல் எது?

student("age")
✗ தவறு! டிக்ஷனரிகள் சதுர அடைப்புக்குறிகளைப் பயன்படுத்துகின்றன, சுழல் அடைப்புக்குறிகளை அல்ல.
student["age"]
✓ சரி! டிக்ஷனரி உருப்படிகளை அணுக சதுர அடைப்புக்குறிகளைப் பயன்படுத்தவும்.
student.get["age"]
✗ தவறு! get() முறை சுழல் அடைப்புக்குறிகளைப் பயன்படுத்துகிறது, சதுர அடைப்புக்குறிகளை அல்ல.
