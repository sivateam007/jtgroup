MS Access Functions

MS Access-இல் உள்ள உள்ளமைக்கப்பட்ட செயல்பாடுகள் மற்றும் அவற்றின் பயன்பாடுகள்

MS Access செயல்பாடுகள்

MS Access பல உள்ளமைக்கப்பட்ட செயல்பாடுகளைக் கொண்டுள்ளது.

இந்த குறிப்பு MS Access-இல் உள்ள சரம், எண், தேதி மற்றும் சில பிற செயல்பாடுகளைக் கொண்டுள்ளது.

💡 குறிப்பு:

MS Access செயல்பாடுகள் தரவை கையாளவும், கணக்கீடுகளைச் செய்யவும், மதிப்புகளை மாற்றவும் பயன்படுகின்றன.

MS Access சரம் செயல்பாடுகள்

செயல்பாடு விளக்கம் எடுத்துக்காட்டு
Asc() குறிப்பிட்ட எழுத்துக்கான ASCII மதிப்பைத் தரும் SELECT Asc("A");
Chr() குறிப்பிட்ட ASCII எண் குறியீட்டிற்கான எழுத்தைத் தரும் SELECT Chr(65);
& இரண்டு அல்லது அதற்கு மேற்பட்ட சரங்களை ஒன்றாகச் சேர்க்கிறது SELECT "Hello" & " " & "World";
LCase() ஒரு சரத்தை சிறிய எழுத்துக்கு மாற்றுகிறது SELECT LCase("HELLO");
UCase() ஒரு சரத்தை பெரிய எழுத்துக்கு மாற்றுகிறது SELECT UCase("hello");
Left() இடதுபுறத்தில் இருந்து தொடங்கி ஒரு சரத்திலிருந்து எழுத்துகளைப் பிரித்தெடுக்கிறது SELECT Left("Hello World", 5);
Right() வலதுபுறத்தில் இருந்து தொடங்கி ஒரு சரத்திலிருந்து எழுத்துகளைப் பிரித்தெடுக்கிறது SELECT Right("Hello World", 5);
Mid() ஒரு சரத்திலிருந்து சில எழுத்துகளைப் பிரித்தெடுக்கிறது (எந்த நிலையில் இருந்தும் தொடங்கும்) SELECT Mid("Hello World", 7, 5);
Len() ஒரு சரத்தின் நீளத்தைத் தரும் SELECT Len("Hello World");
Replace() ஒரு சரத்தில் உள்ள உபசரத்தை மற்றொரு உபசரத்துடன் மாற்றுகிறது SELECT Replace("Hello World", "World", "Access");
Trim() ஒரு சரத்திலிருந்து முன்னணி மற்றும் பின்னணி இடைவெளிகளை நீக்குகிறது SELECT Trim(" Hello ");
LTrim() ஒரு சரத்திலிருந்து முன்னணி இடைவெளிகளை நீக்குகிறது SELECT LTrim(" Hello");
RTrim() ஒரு சரத்திலிருந்து பின்னணி இடைவெளிகளை நீக்குகிறது SELECT RTrim("Hello ");
InStr() ஒரு சரத்தில் மற்றொரு சரத்தின் முதல் நிகழ்வின் நிலையைப் பெறுகிறது SELECT InStr("Hello World", "World");
StrReverse() ஒரு சரத்தை தலைகீழாக மாற்றி முடிவைத் தரும் SELECT StrReverse("Hello");

MS Access எண் செயல்பாடுகள்

செயல்பாடு விளக்கம் எடுத்துக்காட்டு
Abs() ஒரு எண்ணின் முழுமையான மதிப்பைத் தரும் SELECT Abs(-123.45);
Round() ஒரு எண்ணை குறிப்பிட்ட தசம இலக்கங்களுக்கு வட்டமிடுகிறது SELECT Round(123.4567, 2);
Int() ஒரு எண்ணின் முழு எண் பகுதியைத் தரும் SELECT Int(123.45);
Fix() ஒரு எண்ணின் முழு எண் பகுதியைத் தரும் SELECT Fix(123.45);
Sqr() ஒரு எண்ணின் வர்க்க மூலத்தைத் தரும் SELECT Sqr(25);
Rnd() ஒரு சீரற்ற எண்ணைத் தரும் SELECT Rnd();
Sgn() ஒரு எண்ணின் அடையாளத்தைத் தரும் SELECT Sgn(-15);
Val() ஒரு சரத்தைப் படித்து அதில் காணப்படும் எண்களைத் தரும் SELECT Val("123 ABC");
Avg() ஒரு வெளிப்பாட்டின் சராசரி மதிப்பைத் தரும் SELECT Avg(Price) FROM Products;
Sum() மதிப்புகளின் தொகுப்பின் கூட்டுத்தொகையைக் கணக்கிடுகிறது SELECT Sum(Quantity) FROM Orders;
Count() தேர்ந்தெடுக்கப்பட்ட வினாவத்தால் திரும்பப் பெறப்பட்ட பதிவுகளின் எண்ணிக்கையைத் தரும் SELECT Count(*) FROM Customers;
Max() மதிப்புகளின் தொகுப்பில் அதிகபட்ச மதிப்பைத் தரும் SELECT Max(Price) FROM Products;
Min() மதிப்புகளின் தொகுப்பில் குறைந்தபட்ச மதிப்பைத் தரும் SELECT Min(Price) FROM Products;

MS Access தேதி செயல்பாடுகள்

செயல்பாடு விளக்கம் எடுத்துக்காட்டு
Date() தற்போதைய அமைப்பு தேதியைத் தரும் SELECT Date();
Now() கணினியின் அமைப்பு தேதி மற்றும் நேரத்தின் அடிப்படையில் தற்போதைய தேதி மற்றும் நேரத்தைத் தரும் SELECT Now();
Time() தற்போதைய அமைப்பு நேரத்தைத் தரும் SELECT Time();
DateAdd() ஒரு தேதியில் நேர/தேதி இடைவெளியைச் சேர்த்து பின்னர் தேதியைத் தரும் SELECT DateAdd("d", 7, Date());
DateDiff() இரண்டு தேதிகளுக்கு இடையே உள்ள வேறுபாட்டைத் தரும் SELECT DateDiff("d", #2023-01-01#, #2023-12-31#);
DatePart() ஒரு தேதியின் குறிப்பிட்ட பகுதியை (முழு எண்ணாக) தரும் SELECT DatePart("yyyy", Date());
Day() கொடுக்கப்பட்ட தேதிக்கான மாதத்தின் நாளைத் தரும் SELECT Day(#2023-12-25#);
Month() கொடுக்கப்பட்ட தேதிக்கான மாத பகுதியைத் தரும் SELECT Month(#2023-12-25#);
Year() கொடுக்கப்பட்ட தேதிக்கான ஆண்டு பகுதியைத் தரும் SELECT Year(#2023-12-25#);
Hour() ஒரு நேரம்/தேதிநேரத்தின் மணி பகுதியைத் தரும் SELECT Hour(Time());
Minute() ஒரு நேரம்/தேதிநேரத்தின் நிமிட பகுதியைத் தரும் SELECT Minute(Time());
Second() ஒரு நேரம்/தேதிநேரத்தின் வினாடி பகுதியைத் தரும் SELECT Second(Time());
MonthName() ஒரு எண்ணின் அடிப்படையில் மாதத்தின் பெயரைத் தரும் SELECT MonthName(12);
WeekdayName() ஒரு எண்ணின் அடிப்படையில் வாரத்தின் நாளின் பெயரைத் தரும் SELECT WeekdayName(1);

MS Access பிற செயல்பாடுகள்

செயல்பாடு விளக்கம் எடுத்துக்காட்டு
CurrentUser() தற்போதைய தரவுத்தள பயனரின் பெயரைத் தரும் SELECT CurrentUser();
IsDate() ஒரு வெளிப்பாடு தேதியாக மாற்றப்பட முடியுமா என சோதிக்கிறது SELECT IsDate("2023-12-25");
IsNull() ஒரு வெளிப்பாடு Null (தரவு இல்லை) உள்ளதா என சோதிக்கிறது SELECT IsNull(FieldName);
IsNumeric() ஒரு வெளிப்பாடு சரியான எண்ணாக உள்ளதா என சோதிக்கிறது SELECT IsNumeric("123");
Format() குறிப்பிட்ட வடிவத்துடன் ஒரு மதிப்பை வடிவமைக்கிறது SELECT Format(Date(), "yyyy-mm-dd");
Environ() ஒரு இயக்க முறைமை சூழல் மாறியின் மதிப்பைக் கொண்ட சரத்தைத் தரும் SELECT Environ("TEMP");
