ஒரு நெடுவரிசையின் தரவு வகை, அந்த நெடுவரிசை எந்த வகையான மதிப்புகளை வைத்திருக்க முடியும் என்பதை வரையறுக்கிறது: முழு எண், எழுத்து, பணம், தேதி மற்றும் நேரம், பைனரி போன்றவை.

தரவு வகைகள் வெவ்வேறு தரவுத்தளங்களில் வெவ்வேறு பெயர்களைக் கொண்டிருக்கலாம். பெயர் ஒன்றாக இருந்தாலும், அளவு மற்றும் பிற விவரங்கள் வேறுபடலாம்! எப்போதும் ஆவணங்களைச் சரிபார்க்கவும்!

SQL தரவு வகைகள்

தரவுத்தள அட்டவணையில் உள்ள ஒவ்வொரு நெடுவரிசையும் ஒரு பெயர் மற்றும் தரவு வகையைக் கொண்டிருக்க வேண்டும்.

ஒரு அட்டவணையை உருவாக்கும் போது, ஒவ்வொரு நெடுவரிசைக்குள்ளும் என்ன வகையான தரவு சேமிக்கப்படும் என்பதை ஒரு SQL உருவாக்குநர் முடிவு செய்ய வேண்டும். தரவு வகை என்பது ஒவ்வொரு நெடுவரிசைக்குள்ளும் எந்த வகையான தரவு எதிர்பார்க்கப்படுகிறது என்பதை SQL புரிந்துகொள்ள ஒரு வழிகாட்டியாகும், மேலும் இது சேமிக்கப்பட்ட தரவுடன் SQL எவ்வாறு தொடர்பு கொள்ளும் என்பதையும் கண்டறியும்.

DATE ஒரு தேதி. வடிவம்: YYYY-MM-DD. ஆதரிக்கப்படும் வரம்பு '1000-01-01' முதல் '9999-12-31' வரை
DATETIME(fsp) ஒரு தேதி மற்றும் நேர கலவை. வடிவம்: YYYY-MM-DD hh:mm:ss. ஆதரிக்கப்படும் வரம்பு '1000-01-01 00:00:00' முதல் '9999-12-31 23:59:59' வரை. தற்போதைய தேதி மற்றும் நேரத்திற்கான தானியங்கி துவக்கம் மற்றும் புதுப்பித்தலைப் பெற நெடுவரிசை வரையறையில் DEFAULT மற்றும் ON UPDATE-ஐச் சேர்த்தல்
TIMESTAMP(fsp) ஒரு நேர முத்திரை. TIMESTAMP மதிப்புகள் யூனிக்ஸ் காலத்திலிருந்து ('1970-01-01 00:00:00' UTC) வினாடிகளின் எண்ணிக்கையாக சேமிக்கப்படுகின்றன. வடிவம்: YYYY-MM-DD hh:mm:ss. ஆதரிக்கப்படும் வரம்பு '1970-01-01 00:00:01' UTC முதல் '2038-01-09 03:14:07' UTC வரை. தற்போதைய தேதி மற்றும் நேரத்திற்கான தானியங்கி துவக்கம் மற்றும் புதுப்பித்தலை நெடுவரிசை வரையறையில் DEFAULT CURRENT_TIMESTAMP மற்றும் ON UPDATE CURRENT_TIMESTAMP பயன்படுத்தி குறிப்பிடலாம்
TIME(fsp) ஒரு நேரம். வடிவம்: hh:mm:ss. ஆதரிக்கப்படும் வரம்பு '-838:59:59' முதல் '838:59:59' வரை
