SQL SELECT அறிக்கை

SELECT அறிக்கை தரவுத்தளத்திலிருந்து தரவுகளைத் தேர்ந்தெடுக்கப் பயன்படுகிறது.

உதாரணம்: Customers அட்டவணையிலிருந்து தரவுகளைத் திரும்பப் பெறவும்

SELECT CustomerName, City FROM Customers;

தொடரியல்

SELECT column1, column2, ...
FROM table_name;

இங்கே, column1, column2, ... என்பது நீங்கள் தரவுகளைத் தேர்ந்தெடுக்க விரும்பும் அட்டவணையின் புலப் பெயர்களாகும்.

table_name என்பது நீங்கள் தரவுகளைத் தேர்ந்தெடுக்க விரும்பும் அட்டவணையின் பெயரைக் குறிக்கிறது.

அனைத்து நெடுவரிசைகளையும் தேர்ந்தெடுக்கவும்

ஒவ்வொரு நெடுவரிசைப் பெயரையும் குறிப்பிடாமல் அனைத்து நெடுவரிசைகளையும் திரும்பப் பெற விரும்பினால், நீங்கள் SELECT * தொடரியலைப் பயன்படுத்தலாம்:

உதாரணம்: Customers அட்டவணையிலிருந்து அனைத்து நெடுவரிசைகளையும் திரும்பப் பெறவும்

SELECT * FROM Customers;

💡 குறிப்பு:

SELECT * அனைத்து நெடுவரிசைகளையும் திருப்பித் தரும். இது விரைவான சோதனைகளுக்கு பயனுள்ளதாக இருக்கும், ஆனால் உற்பத்தி குறியீட்டில் குறிப்பிட்ட நெடுவரிசைகளை மட்டுமே தேர்ந்தெடுப்பது நல்லது.
