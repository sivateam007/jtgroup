SQL CREATE DATABASE Statement

புதிய SQL தரவுத்தளத்தை உருவாக்க CREATE DATABASE அறிக்கையைப் பற்றி அறிக

SQL CREATE DATABASE அறிக்கை

CREATE DATABASE அறிக்கை புதிய SQL தரவுத்தளத்தை உருவாக்க பயன்படுகிறது.

தரவுத்தள உருவாக்கம் பணிப்பாய்வு

1

நிர்வாக அனுமதி உறுதி

→
2

CREATE DATABASE அறிக்கையை இயக்கு

→
3

தரவுத்தளம் உருவாக்கப்படுகிறது

→
4

தரவுத்தளங்கள் பட்டியலைச் சரிபார்

CREATE DATABASE தொடரியல்

CREATE DATABASE databasename;

💡 உதவிக்குறிப்பு:

எந்த தரவுத்தளத்தையும் உருவாக்குவதற்கு முன்பு உங்களுக்கு நிர்வாக அனுமதி உள்ளது என்பதை உறுதிப்படுத்திக் கொள்ளுங்கள். ஒரு தரவுத்தளம் உருவாக்கப்பட்ட பிறகு, பின்வரும் SQL கட்டளையுடன் தரவுத்தளங்களின் பட்டியலில் அதைச் சரிபார்க்கலாம்: SHOW DATABASES;

CREATE DATABASE எடுத்துக்காட்டு

பின்வரும் SQL அறிக்கை "testDB" என்ற தரவுத்தளத்தை உருவாக்குகிறது:

எடுத்துக்காட்டு

CREATE DATABASE testDB;

இ-காமர்ஸ் தளம்

ஆன்லைன் கடைக்கான தரவுத்தளம்

CREATE DATABASE EcommerceStore;

பள்ளி மேலாண்மை

கல்வி நிறுவனத்திற்கான தரவுத்தளம்

CREATE DATABASE SchoolManagement;

மருத்துவமனை

சுகாதாரப் பராமரிப்பு தரவுத்தளம்

CREATE DATABASE HospitalDB;

வெவ்வேறு தரவுத்தள அமைப்புகள்

CREATE DATABASE database_name;

SQL Server

CREATE DATABASE CompanyDB;

CREATE DATABASE database_name;

PostgreSQL

CREATE DATABASE companydb;

CREATE DATABASE database_name;

Oracle

⚠️ முக்கியமான குறிப்பு:

தரவுத்தளப் பெயர்கள் தனித்துவமாக இருக்க வேண்டும். ஏற்கனவே இருக்கும் தரவுத்தளத்தின் பெயரைப் பயன்படுத்த முயற்சிக்கும் போது பிழை ஏற்படும். தரவுத்தளப் பெயர்கள் பொதுவாக எழுத்துகள், எண்கள் மற்றும் அடிக்கோடிடுதல்களை மட்டுமே கொண்டிருக்கும்.

சிறந்த பயிற்சிகள்

பெயரிடும் மரபு

தெளிவான மற்றும் அர்த்தமுள்ள பெயர்களைப் பயன்படுத்துங்கள்

-- Good
CREATE DATABASE CustomerOrders;

-- Avoid
CREATE DATABASE db1;

முன் சோதனை

தரவுத்தளம் ஏற்கனவே உள்ளதா என சரிபார்க்கவும்

-- MySQL example
CREATE DATABASE IF NOT EXISTS CompanyDB;

மேம்பட்ட விருப்பங்கள்

குறியாக்கம் மற்றும் வரிசைப்படுத்துதல் அமைக்கவும்

-- MySQL with options
CREATE DATABASE CompanyDB
CHARACTER SET utf8mb4
COLLATE utf8mb4_unicode_ci;

பயிற்சி

❓ SQL CREATE DATABASE அறிக்கையின் நோக்கம் என்ன?

ஏற்கனவே உள்ள தரவுத்தளத்தில் புதிய அட்டவணையை உருவாக்க
✗ தவறு! இது CREATE TABLE அறிக்கைக்கானது
ஏற்கனவே உள்ள தரவுத்தளத்தை நீக்க
✗ தவறு! இது DROP DATABASE அறிக்கைக்கானது
புதிய SQL தரவுத்தளத்தை உருவாக்க
✓ சரி! CREATE DATABASE அறிக்கையின் முதன்மை நோக்கம் புதிய SQL தரவுத்தளத்தை உருவாக்குவதாகும்
ஏற்கனவே உள்ள தரவுத்தளத்தை மாற்றியமைக்க
✗ தவறு! இது ALTER DATABASE அறிக்கைக்கானது
