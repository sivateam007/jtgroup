RGB மதிப்பு

ஒரு RGB வண்ண மதிப்பு RED, GREEN மற்றும் BLUE ஒளி மூலங்களைக் குறிக்கிறது.

CSS இல், ஒரு வண்ணம் பின்வரும் சூத்திரத்தைப் பயன்படுத்தி RGB மதிப்பாகக் குறிப்பிடப்படலாம்:

rgb(red, green, blue)

ஒவ்வொரு அளவுருவும் (red, green, மற்றும் blue) 0 மற்றும் 255 க்கு இடையே வண்ணத்தின் தீவிரத்தை வரையறுக்கிறது.

எடுத்துக்காட்டாக, rgb(255, 0, 0) சிவப்பாக காட்டப்படும், ஏனெனில் சிவப்பு அதன் அதிகபட்ச மதிப்பாக அமைக்கப்பட்டுள்ளது (255) மற்றும் மற்றவை 0 ஆக அமைக்கப்பட்டுள்ளன.

கருப்பு காட்ட, அனைத்து வண்ண அளவுருக்களையும் 0 ஆக அமைக்கவும், இப்படி: rgb(0, 0, 0).

வெள்ளை காட்ட, அனைத்து வண்ண அளவுருக்களையும் 255 ஆக அமைக்கவும், இப்படி: rgb(255, 255, 255).

கீழே உள்ள RGB மதிப்புகளை கலந்து பரிசோதிக்கவும்:

RGBA மதிப்பு

RGBA வண்ண மதிப்புகள் ஒரு ஆல்பா சேனலுடன் RGB வண்ண மதிப்புகளின் நீட்டிப்பாகும் - இது ஒரு வண்ணத்திற்கான ஒளிபுகா தன்மையைக் குறிக்கிறது.

ஒரு RGBA வண்ண மதிப்பு பின்வருமாறு குறிப்பிடப்படுகிறது:

rgba(red, green, blue, alpha)

ஆல்பா அளவுருவானது 0.0 (முழுமையாக வெளிப்படையான) மற்றும் 1.0 (வெளிப்படையானது அல்ல) க்கு இடையே உள்ள எண்ணாகும்:

கீழே உள்ள RGBA மதிப்புகளை கலந்து பரிசோதிக்கவும்:
