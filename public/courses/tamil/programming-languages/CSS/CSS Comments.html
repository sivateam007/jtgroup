CSS கருத்துரைகள்

கருத்துரைகள் CSS குறியீட்டை விளக்க பயன்படுகின்றன, மேலும் பிற்காலத்தில் நீங்கள் மூல குறியீட்டைத் திருத்தும்போது உதவக்கூடும்.

கருத்துரைகள் ஸ்டைல்ஷீட்டில் CSS குறியீட்டின் பகுதிகளை தற்காலிகமாக முடக்கவும் பயன்படுத்தப்படுகின்றன.

கருத்துரைகள் பிரௌசர்களால் புறக்கணிக்கப்படுகின்றன!

ஒரு CSS கருத்துரை HTML <style> உறுப்புக்குள் வைக்கப்படுகிறது, மற்றும் /* உடன் தொடங்கி */ உடன் முடிகிறது:

எடுத்துக்காட்டு

/* This is a single-line comment */
p {
  color: red;
}

நீங்கள் குறியீட்டில் எங்கு வேண்டுமானாலும் கருத்துரைகளைச் சேர்க்கலாம்:

எடுத்துக்காட்டு

p {
  color: red;  /* Set text color to red */
}

ஒரு குறியீடு வரியின் நடுவில் கூட:

எடுத்துக்காட்டு

p {
  color: /*red*/blue; 
}

கருத்துரைகள் பல வரிகளைக் கொண்டிருக்கலாம்:

எடுத்துக்காட்டு

/* This is
a multi-line
comment */

p {
  color: red;
}

HTML மற்றும் CSS கருத்துரைகள்

HTML டுடோரியலில் இருந்து, நீங்கள் தொடரியலைப் பயன்படுத்தி உங்கள் HTML மூலத்தில் கருத்துரைகளைச் சேர்க்கலாம் என்பதைக் கற்றுக்கொண்டீர்கள்.

பின்வரும் எடுத்துக்காட்டில், HTML மற்றும் CSS கருத்துரைகளின் கலவையைப் பயன்படுத்துகிறோம்:

எடுத்துக்காட்டு

<!DOCTYPE html>
<html>
<head>
<style>
p {
  color: red; /* Set text color to red */
}
</style>
</head>
<body>

<h2>My Heading</h2>

<!-- These paragraphs will be red -->
<p>Hello World!</p>
<p>This paragraph is styled with CSS.</p>
<p>HTML and CSS comments are not shown in the output.</p>

</body>
</html>

CSS கருத்துரைக்கான சரியான தொடரியல் எது?

<!-- This is a comment -->
✗ தவறு! இது HTML கருத்துரைக்கான தொடரியல்
// This is a comment
✗ தவறு! // என்பது JavaScript கருத்துரைகளுக்கு பயன்படுகிறது, CSS க்கு அல்ல
/* This is a comment */
✓ சரி! /* */ என்பது CSS கருத்துரைகளுக்கான சரியான தொடரியல்
# This is a comment
✗ தவறு! # என்பது CSS இல் கருத்துரைகளுக்குப் பயன்படுத்தப்படுவதில்லை
