CSS எல்லைகள்

CSS எல்லை பண்புகள் உங்களை ஒரு உறுப்பின் எல்லையின் பாணி, அகலம் மற்றும் நிறத்தை குறிப்பிட அனுமதிக்கின்றன.

எல்லா பக்கங்களிலும் எனக்கு எல்லைகள் உள்ளன.

எனக்கு ஒரு சிவப்பு, கீழ் எல்லை உள்ளது.

எனக்கு வட்டமான எல்லைகள் உள்ளன.

எனக்கு ஒரு நீல, இடது எல்லை உள்ளது.

CSS எல்லை பாணி

border-style பண்பு எந்த வகையான எல்லையைக் காட்ட வேண்டும் என்பதைக் குறிப்பிடுகிறது.

பின்வரும் மதிப்புகள் அனுமதிக்கப்படுகின்றன:

dotted - புள்ளி புள்ளியான எல்லையை வரையறுக்கிறது
dashed - கோடிட்ட எல்லையை வரையறுக்கிறது
solid - திடமான எல்லையை வரையறுக்கிறது
double - இரட்டை எல்லையை வரையறுக்கிறது
groove - 3D பள்ளமான எல்லையை வரையறுக்கிறது. விளைவு எல்லை-நிற மதிப்பைப் பொறுத்தது
ridge - 3D மேடையான எல்லையை வரையறுக்கிறது. விளைவு எல்லை-நிற மதிப்பைப் பொறுத்தது
inset - 3D உள்ளீட்டு எல்லையை வரையறுக்கிறது. விளைவு எல்லை-நிற மதிப்பைப் பொறுத்தது
outset - 3D வெளியீட்டு எல்லையை வரையறுக்கிறது. விளைவு எல்லை-நிற மதிப்பைப் பொறுத்தது
none - எல்லையை வரையறுக்காது
hidden - மறைக்கப்பட்ட எல்லையை வரையறுக்கிறது

💡 முக்கியமான குறிப்பு:

border-style பண்பு ஒன்று முதல் நான்கு வரை மதிப்புகளைக் கொண்டிருக்கலாம் (மேல் எல்லை, வலது எல்லை, கீழ் எல்லை மற்றும் இடது எல்லைக்கு).

எடுத்துக்காட்டு

வெவ்வேறு எல்லை பாணிகளின் ஆர்ப்பாட்டம்:

p.dotted {border-style: dotted;}
p.dashed {border-style: dashed;}
p.solid {border-style: solid;}
p.double {border-style: double;}
p.groove {border-style: groove;}
p.ridge {border-style: ridge;}
p.inset {border-style: inset;}
p.outset {border-style: outset;}
p.none {border-style: none;}
p.hidden {border-style: hidden;}
p.mix {border-style: dotted dashed solid double;}

⚠️ கவனம்:

border-style பண்பு அமைக்கப்படாத வரை மற்ற எந்த CSS எல்லை பண்புகளுக்கும் (அடுத்த அத்தியாயங்களில் நீங்கள் மேலும் அறிவீர்கள்) எந்த விளைவும் இருக்காது!

பயிற்சி

❓ எந்த CSS பண்பு காண்பிக்க வேண்டிய எல்லையின் வகையைக் குறிப்பிடுகிறது?

border-width
✗ தவறு! border-width பண்பு எல்லையின் தடிமனை மட்டுமே குறிப்பிடுகிறது, வகையை அல்ல
border-color
✗ தவறு! border-color பண்பு எல்லையின் நிறத்தை மட்டுமே குறிப்பிடுகிறது
border-style
✓ சரி! border-style பண்பு எல்லையின் வகையைக் குறிப்பிடுகிறது (dotted, dashed, solid, போன்றவை)
border-radius
✗ தவறு! border-radius பண்பு எல்லையின் மூலைகளை வட்டமாக்க மட்டுமே பயன்படுகிறது
