CSS Table Width and Height

அட்டவணையின் அகலமும் உயரமும் width மற்றும் height பண்புகளால் வரையறுக்கப்படுகின்றன.

CSS Table Width

அட்டவணையின் அகலத்தை அமைக்க CSS width பண்பு பயன்படுத்தப்படுகிறது.

அகலத்தை பின்வரும் முறைகளில் அமைக்கலாம்:

  • சதவீதத்தில் (%)
  • நிலையான நீளமாக (px)
  • auto முக்கிய சொல்லின் மூலம்

CSS Table Width in Percent

Example

முழு-அகல அட்டவணை:

  height: 70px;

Example

50% அகல அட்டவணை:

table {
  width: 50%;
}

width: auto பயன்படுத்துதல்:

CSS Table Height

அட்டவணையின் உயரத்தை அமைக்க CSS height பண்பு பயன்படுத்தப்படுகிறது.

உயரத்தை பின்வரும் முறைகளில் அமைக்கலாம்:

  • சதவீதத்தில் (%)
  • நிலையான நீளமாக (px)
  • auto முக்கிய சொல்லின் மூலம்

கீழே உள்ள எடுத்துக்காட்டு அட்டவணை தலைப்புகளின் (<th>) உயரத்தை 70px ஆக அமைக்கிறது:

Firstname Lastname Savings
Peter Griffin $100
Lois Griffin $150
Joe Swanson $300

Example

அட்டவணை தலைப்புகளின் உயரத்தை நிலையான உயரமாக அமைக்கவும்:

th {
  height: 70px;
}

Exercise

அட்டவணையின் அகலத்தை அமைக்க எந்த CSS பண்பு பயன்படுத்தப்படுகிறது?

❓ அட்டவணையின் அகலத்தை அமைக்க எந்த CSS பண்பு பயன்படுத்தப்படுகிறது?

height
✗ தவறு! height பண்பு உயரத்தை அமைக்க பயன்படுகிறது, அகலத்தை அல்ல
width
✓ சரி! width பண்பு அட்டவணையின் அகலத்தை அமைக்க பயன்படுகிறது
border-width
✗ தவறு! border-width எல்லையின் அகலத்தை மட்டுமே கட்டுப்படுத்துகிறது
table-layout
✗ தவறு! table-layout அட்டவணை சட்டகத்தை கட்டுப்படுத்துகிறது, அகலத்தை அமைக்காது
