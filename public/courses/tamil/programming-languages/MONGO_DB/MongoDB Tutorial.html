MongoDB Tutorial

MongoDB ஐக் கற்றுக்கொள்ளுங்கள்

MongoDB பற்றி

MongoDB ஒரு ஆவண தரவுத்தளமாகும். இது BSON என்று அழைக்கப்படும் JSON வடிவத்தில் தரவைச் சேமிக்கிறது.

நீங்கள் JSON உடன் பழக்கமில்லாதவராக இருந்தால், எங்கள் JSON டுடோரியலைப் பார்க்கவும்.

MongoDB இல் உள்ள ஒரு பதிவேடு ஒரு ஆவணமாகும், இது JSON பொருள்களின் கட்டமைப்பைப் போன்ற விசை மதிப்பு ஜோடிகளால் உருவாக்கப்பட்ட ஒரு தரவு கட்டமைப்பாகும்.

🏁 உதவிக்குறிப்பு:

உங்கள் முன்னேற்றத்தைக் கண்காணிக்க உள்நுழையவும் - இது இலவசம்.

MongoDB ஆவணம்

MongoDB தரவுத்தளத்தில் உள்ள பதிவுகள் ஆவணங்கள் என்று அழைக்கப்படுகின்றன, மேலும் புல மதிப்புகளில் எண்கள், சரங்கள், பூலியன்கள், வரிசைகள் அல்லது கூட nested ஆவணங்கள் உள்ளடக்கப்படலாம்.

ஆவண எடுத்துக்காட்டு

{
    title: "Post Title 1",
    body: "Body of post.",
    category: "News",
    likes: 1,
    tags: ["news", "events"],
    date: Date()
}

எடுத்துக்காட்டுகள் மூலம் கற்றல்

எங்கள் "MongoDB காட்டு" கருவி MongoDB ஐ நிரூபிப்பதை எளிதாக்குகிறது. இது குறியீடு மற்றும் முடிவு இரண்டையும் காட்டுகிறது.

எடுத்துக்காட்டு

"news" என்ற வகையைக் கொண்ட அனைத்து ஆவணங்களையும் கண்டறியவும்.

db.posts.find( {category: "News"} )
