மேலும் அறிய:

முழுமையான HTML எமோஜி குறிப்பு

HTML charset பண்புக்கூறு

ஒரு HTML பக்கத்தை சரியாகக் காட்ட, வலை உலாவி அந்தப் பக்கத்தில் பயன்படுத்தப்படும் எழுத்துத் தொகுப்பை அறிந்திருக்க வேண்டும்.

இது <meta> குறிச்சொல்லில் குறிப்பிடப்பட்டுள்ளது:

<meta charset="UTF-8">

குறிப்பிடப்படாவிட்டால், UTF-8 என்பது HTML இல் இயல்புநிலை எழுத்துத் தொகுப்பாகும்.

UTF-8 எழுத்துக்கள்

பல UTF-8 எழுத்துக்களை விசைப்பலகையில் தட்டச்சு செய்ய முடியாது, ஆனால் அவற்றை எப்போதும் எண்களைப் பயன்படுத்தி காண்பிக்கலாம் (நிறுவன எண்கள் என்று அழைக்கப்படுகின்றன):

A என்பது 65

B என்பது 66

C என்பது 67

எடுத்துக்காட்டு

<!DOCTYPE html>
<html>
<meta charset="UTF-8">
<body>

<p>நான் A B C ஐக் காண்பிப்பேன்</p>
<p>நான் &#65; &#66; &#67; ஐக் காண்பிப்பேன்</p>

</body>
</html>

எடுத்துக்காட்டு விளக்கம்

<meta charset="UTF-8"> உறுப்பு எழுத்துத் தொகுப்பை வரையறுக்கிறது.

A, B, மற்றும் C எழுத்துக்கள் 65, 66, மற்றும் 67 எண்களால் காட்டப்படுகின்றன.

நீங்கள் ஒரு எழுத்தைக் காண்பிக்கிறீர்கள் என்பதை உலாவி புரிந்துகொள்ள, நிறுவன எண்ணை &# உடன் தொடங்கி ; (அரைப்புள்ளி) உடன் முடிக்க வேண்டும்.

எமோஜி எழுத்துக்கள்

எமோஜிகளும் UTF-8 எழுத்துக்களிலிருந்து வரும் எழுத்துக்களே:

😄 என்பது 128516

😍 என்பது 128525

💗 என்பது 128151

எடுத்துக்காட்டு

<!DOCTYPE html>
<html>
<meta charset="UTF-8">
<body>

<h1>எனது முதல் எமோஜி</h1>

<p>&#128512;</p>

</body>
</html>

எமோஜிகள் எழுத்துக்கள் என்பதால், அவற்றை HTML இல் மற்ற எழுத்துக்களைப் போலவே நகலெடுக்கலாம், காட்டலாம் மற்றும் அளவை மாற்றலாம்.

எடுத்துக்காட்டு

<!DOCTYPE html>
<html>
<meta charset="UTF-8">
<body>

<h1>அளவு மாற்றப்பட்ட எமோஜிகள்</h1>

<p style="font-size:48px">
&#128512; &#128516; &#128525; &#128151;
</p>

</body>
</html>

பயிற்சி பகுதி

❓ பின்வருவனவற்றில் எது சரியான HTML இல் எமோஜி பயன்பாடு?

<p>😊</p>
✓ சரி! எமோஜிகளை நேரடியாக HTML இல் ஒட்டலாம்
<p>&#128522;</p>
✓ சரி! எமோஜிகளை எண் மூலமாகவும் காண்பிக்கலாம்
<emoji>😊</emoji>
✗ தவறு! <emoji> என்பது செல்லுபடியாகும் HTML குறிச்சொல் அல்ல
