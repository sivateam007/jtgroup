HTML id Attribute

HTML id பண்புக்கூறு ஒரு HTML உறுப்புக்கான தனித்த id ஐக் குறிப்பிடப் பயன்படுகிறது.

ஒரே HTML ஆவணத்தில் ஒன்றுக்கு மேற்பட்ட உறுப்புகளை ஒரே id உடன் கொண்டிருக்க முடியாது.

The id Attribute

id பண்புக்கூறு ஒரு HTML உறுப்புக்கான தனித்த id ஐக் குறிப்பிடுகிறது. id பண்புக்கூறின் மதிப்பு HTML ஆவணத்திற்குள் தனித்ததாக இருக்க வேண்டும்.

id பண்புக்கூறு ஒரு ஸ்டைல் ஷீட்டில் ஒரு குறிப்பிட்ட ஸ்டைல் அறிவிப்பைச் சுட்டிக்காட்டப் பயன்படுகிறது. குறிப்பிட்ட id உடன் உறுப்பை அணுகவும் கையாளவும் JavaScript மூலமும் பயன்படுத்தப்படுகிறது.

id க்கான தொடரியல்: ஒரு hash எழுத்தை (#) எழுதவும், அதைத் தொடர்ந்து ஒரு id பெயர். பின்னர், சுருள் பிரேஸ்கள் {} உள்ளே CSS பண்புக்கூறுகளை வரையறுக்கவும்.

Example

பின்வரும் எடுத்துக்காட்டில் "myHeader" id பெயரைச் சுட்டிக்காட்டும் ஒரு <h1> உறுப்பு உள்ளது. இந்த <h1> உறுப்பு head பிரிவில் உள்ள #myHeader ஸ்டைல் வரையறைக்கு ஏற்ப ஸ்டைல் செய்யப்படும்:

<!DOCTYPE html>
<html>
<head>
<style>
#myHeader {
  background-color: lightblue;
  color: black;
  padding: 40px;
  text-align: center;
}
</style>
</head>
<body>

<h1 id="myHeader">My Header</h1>

</body>
</html>

குறிப்பு:

id பெயர் case sensitive ஆகும்!

குறிப்பு:

id பெயர் குறைந்தபட்சம் ஒரு எழுத்தைக் கொண்டிருக்க வேண்டும், எண்ணுடன் தொடங்கக்கூடாது மற்றும் வெள்ளை இடைவெளிகளை (spaces, tabs, etc.) கொண்டிருக்கக்கூடாது.

Difference Between Class and ID

ஒரு வகுப்புப் பெயரை பல HTML உறுப்புகள் பயன்படுத்தலாம், ஆனால் ஒரு id பெயரைப் பக்கத்தில் ஒரு HTML உறுப்பு மட்டுமே பயன்படுத்த வேண்டும்:

<style>
/* Style the element with the id "myHeader" */
#myHeader {
  background-color: lightblue;
  color: black;
  padding: 40px;
  text-align: center;
}

/* Style all elements with the class name "city" */
.city {
  background-color: tomato;
  color: white;
  padding: 10px;
}
</style>

<!-- An element with a unique id -->
<h1 id="myHeader">My Cities</h1>

<!-- Multiple elements with same class -->
<h2 class="city">London</h2>
<p>London is the capital of England.</p>

<h2 class="city">Paris</h2>
<p>Paris is the capital of France.</p>

<h2 class="city">Tokyo</h2>
<p>Tokyo is the capital of Japan.</p>

உதவிக்குறிப்பு:

CSS பற்றி எங்கள் CSS டுடோரியலில் இருந்து மேலும் அறியலாம்.

HTML Bookmarks with ID and Links

HTML புத்தகக்குறிகள் வாசகர்கள் வலைப்பக்கத்தின் குறிப்பிட்ட பகுதிகளுக்கு செல்ல அனுமதிக்க பயன்படுகின்றன.

உங்கள் பக்கம் மிக நீளமாக இருந்தால் புத்தகக்குறிகள் பயனுள்ளதாக இருக்கும்.

புத்தகக்குறியைப் பயன்படுத்த, முதலில் அதை உருவாக்க வேண்டும், பின்னர் அதற்கு ஒரு இணைப்பைச் சேர்க்க வேண்டும்.

பின்னர், இணைப்பு கிளிக் செய்யப்பட்டால், புத்தகக்குறி உள்ள இடத்திற்கு பக்கம் உருளும்.

Example

First, create a bookmark with the id attribute:

<h2 id="C4">Chapter 4</h2>

Then, add a link to the bookmark ("Jump to Chapter 4"), from within the same page:

Example

<a href="#C4">Jump to Chapter 4</a>

Or, add a link to the bookmark ("Jump to Chapter 4"), from another page:

<a href="html_demo.html#C4">Jump to Chapter 4</a>

Using the id Attribute in JavaScript

id பண்புக்கூறு அந்த குறிப்பிட்ட உறுப்புக்கு சில பணிகளைச் செய்ய JavaScript மூலமும் பயன்படுத்தப்படலாம்.

JavaScript getElementById() முறையுடன் ஒரு குறிப்பிட்ட id உடன் ஒரு உறுப்பை அணுகலாம்:

Example

Use the id attribute to manipulate text with JavaScript:

<script>
function displayResult() {
  document.getElementById("myHeader").innerHTML = "Have a nice day!";
}
</script>
