Path Description

வெளி கோப்புகளுடன் இணைக்கும் போது கோப்புப் பாதைகள் பயன்படுத்தப்படுகின்றன, எடுத்துக்காட்டாக:

  • வலைப்பக்கங்கள்
  • படங்கள்
  • ஸ்டைல் ஷீட்கள்
  • JavaScripts

Absolute File Paths

ஒரு முழுமையான கோப்புப் பாதை ஒரு கோப்பிற்கான முழு URL ஆகும்:

Example

<img src="https://www.jassifteam.com/images/picture.jpg" alt="Mountain">

The <img> tag is explained in the chapter: HTML Images.

Relative File Paths

Best Practice

உறவின கோப்புப் பாதைகளைப் பயன்படுத்துவது சிறந்த பயிற்சியாகும் (முடிந்தால்).

உறவின கோப்புப் பாதைகளைப் பயன்படுத்தும் போது, உங்கள் வலைப்பக்கங்கள் உங்கள் தற்போதைய அடிப்படை URL உடன் கட்டப்படாது. அனைத்து இணைப்புகளும் உங்கள் சொந்த கணினியில் (localhost) மற்றும் உங்கள் தற்போதைய பொது டொமைனிலும் உங்கள் எதிர்கால பொது டொமைன்களிலும் செயல்படும்.
