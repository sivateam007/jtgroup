வண்ண மதிப்புகள்

HTML இல், வண்ணங்களை RGB மதிப்புகள், HEX மதிப்புகள், HSL மதிப்புகள், RGBA மதிப்புகள் மற்றும் HSLA மதிப்புகளைப் பயன்படுத்தியும் குறிப்பிடலாம்.

Jassif Team விளக்கம்:

பின்வரும் மூன்று உறுப்புகளுக்கு அவற்றின் பின்னணி வண்ணம் RGB, HEX மற்றும் HSL மதிப்புகளுடன் அமைக்கப்பட்டுள்ளது:

HEX

Jassif Team விளக்கம்:

பின்வரும் இரண்டு உறுப்புகளுக்கு அவற்றின் பின்னணி வண்ணம் RGBA மற்றும் HSLA மதிப்புகளுடன் அமைக்கப்பட்டுள்ளது, இது வண்ணத்தில் ஒரு ஆல்பா சேனலைச் சேர்க்கிறது (இங்கே நமக்கு 50% வெளிப்படைத்தன்மை உள்ளது):

HSLA
hsla(9, 100%, 64%, 0.5)

வண்ண முறைகளின் ஒப்பீடு

முறை விளக்கம் எடுத்துக்காட்டு பயன்பாடு
வண்ணப் பெயர்கள் முன்னரே வரையறுக்கப்பட்ட பெயர்கள் Tomato வேகமாகவும் எளிதாகவும்
RGB சிவப்பு, பச்சை, நீலம் மதிப்புகள் (0-255) rgb(255, 99, 71) துல்லியமான வண்ணக் கட்டுப்பாடு

RGBA/HSLA ஆல்பா சேனலுடன் (வெளிப்படைத்தன்மை) rgba(255, 99, 71, 0.5) வெளிப்படையான வண்ணங்கள்
