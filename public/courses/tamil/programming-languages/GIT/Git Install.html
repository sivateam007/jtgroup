முந்தைய அடுத்தது

Git நிறுவுதல் வழிகாட்டி

வெவ்வேறு இயக்க முறைமைகளில் Git ஐ எவ்வாறு நிறுவுவது என்பதைக் கற்றுக்கொள்ளுங்கள்

Git நிறுவுதல் - அறிமுகம்

Git என்பது குறுக்கு-தளம் (cross-platform) ஆகும், அதாவது இது பல்வேறு இயக்க முறைமைகளில் வேலை செய்யும்.

💡 முக்கிய குறிப்பு:

Git ஐ நிறுவுவதற்கு முன், உங்கள் கணினியில் எந்த இயக்க முறைமை உள்ளது என்பதை சரிபார்க்கவும்.

Windows-ல் Git நிறுவுதல்

1

Git for Windows ஐ பதிவிறக்கவும்

அதிகாரப்பூர்வ Git வலைத்தளத்தில் இருந்து Git for Windows ஐ பதிவிறக்கவும்: https://git-scm.com/download/win

2

நிறுவி கோப்பை இயக்கவும்

பதிவிறக்கிய .exe கோப்பை திறந்து, நிறுவல் செயல்முறையை தொடரவும்

3

கட்டமைப்பு விருப்பங்கள்

இயல்புநிலை அமைப்புகளை தேர்ந்தெடுப்பது நல்லது, குறிப்பாக தொடக்கநிலை பயனர்களுக்கு

4

நிறுவல் முடிந்தது

நிறுவல் முடிந்த பிறகு, Command Prompt அல்லது Git Bash-ஐ திறக்கவும்

5

சரிபார்ப்பு

கீழ்கண்ட கட்டளையை இயக்கி Git நிறுவலை சரிபார்க்கவும்:

git --version

குறிப்பு:

Windows-ல் Git Bash உங்களுக்கு Unix-style command line சூழலை வழங்கும், இது Git கட்டளைகளை இயக்க உதவும்.

macOS-ல் Git நிறுவுதல்

முறை 1: Homebrew-ஐ பயன்படுத்தி

1

Homebrew-ஐ நிறுவவும்

Terminal-ஐ திறந்து கீழ்கண்ட கட்டளையை இயக்கவும்:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
2

Git-ஐ நிறுவவும்

brew install git

முறை 2: Xcode Command Line Tools

1

Terminal-ஐ திறக்கவும்

Applications → Utilities → Terminal

2

Git கட்டளையை இயக்கவும்

git --version

இது தானாகவே Xcode Command Line Tools-ஐ நிறுவும்

Linux-ல் Git நிறுவுதல்

Ubuntu/Debian:

sudo apt update
sudo apt install git

CentOS/Fedora/RHEL:

sudo yum install git

அல்லது (புதிய பதிப்புகளில்):

sudo dnf install git

Arch Linux:

sudo pacman -S git

நிறுவல் சரிபார்ப்பு

Git வெற்றிகரமாக நிறுவப்பட்டதா என சரிபார்க்க, terminal/command prompt-ஐ திறந்து கீழ்கண்ட கட்டளையை இயக்கவும்:

git --version

எதிர்பார்க்கப்படும் வெளியீடு (பதிப்பு எண் மாறுபடலாம்):

git version 2.39.1

✅ வெற்றி!

பதிப்பு எண் காட்டப்பட்டால், Git வெற்றிகரமாக நிறுவப்பட்டுள்ளது!

ஆரம்ப Git அமைப்பு

Git-ஐ நிறுவிய பிறகு, உங்கள் பெயர் மற்றும் மின்னஞ்சலை கட்டமைக்க வேண்டும்:

1

பயனர் பெயர் அமைப்பு

git config --global user.name "உங்கள் பெயர்"
2

மின்னஞ்சல் அமைப்பு

git config --global user.email "your.email@example.com"
3

சரிபார்ப்பு

கட்டமைப்பு அமைப்புகளை சரிபார்க்க:

git config --list

குறிப்பு:

--global flag உங்கள் கணினியில் உள்ள அனைத்து Git களஞ்சியங்களுக்கும் இந்த அமைப்புகளைப் பயன்படுத்தும். ஒரு குறிப்பிட்ட களஞ்சியத்திற்கு மட்டும் வேறுபட்ட அமைப்புகள் வைக்க --global-ஐ நீக்கிவிட்டு கட்டளையை இயக்கவும்.

பொதுவான நிறுவல் சிக்கல்கள்

'git' அங்கீகரிக்கப்படவில்லை

Windows: கணினி PATH-ல் Git சேர்க்கப்படவில்லை. நிறுவலை மீண்டும் இயக்கி "Add to PATH" விருப்பத்தை தேர்வு செய்யவும்.

அனுமதி மறுக்கப்பட்டது

Linux/macOS: sudo-ஐ பயன்படுத்தவும் அல்லது நிர்வாகி அனுமதிகளுடன் terminal-ஐ திறக்கவும்.

பழைய பதிப்பு

கணினி தொகுப்பு மேலாளர்கள் சில நேரங்களில் பழைய Git பதிப்புகளை வழங்கும். அதிகாரப்பூர்வ வலைத்தளத்தில் இருந்து நேரடியாக பதிவிறக்கவும்.

அடுத்து என்ன?

Git வெற்றிகரமாக நிறுவப்பட்ட பிறகு, நீங்கள்:

  • உங்கள் முதல் Git களஞ்சியத்தை உருவாக்கலாம்
  • கோப்புகளை stage மற்றும் commit செய்யலாம்
  • GitHub-ல் கணக்கு உருவாக்கலாம்
  • தொலை களஞ்சியங்களுடன் வேலை செய்யலாம்

🚀 தயாரா?

Git நிறுவப்பட்டுவிட்டது! அடுத்த பாடத்தில் Git அடிப்படை கட்டளைகளை கற்றுக்கொள்ளத் தயாராகுங்கள்.
