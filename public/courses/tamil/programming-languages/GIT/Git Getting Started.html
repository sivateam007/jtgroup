Git Getting Started

Start your journey with Git by creating your first repository

Git-உடன் தொடங்குங்கள்

இப்போது Git நிறுவப்பட்டுள்ளது, மேலும் அது நீங்கள் யார் என்பதை அறிந்துள்ளது, நீங்கள் Git-ஐப் பயன்படுத்தத் தொடங்கலாம்.

நமது முதல் களஞ்சியத்தை உருவாக்குவோம்

🚀 தொடங்குவதற்கான முக்கிய படிகள்:

  • ஒரு திட்ட கோப்புறையை உருவாக்கவும்
  • கோப்புறைக்குச் செல்லவும்
  • ஒரு Git களஞ்சியத்தைத் தொடக்கவும்

Git கோப்புறையை உருவாக்குதல்

எங்கள் திட்டத்திற்கான புதிய கோப்புறையை உருவாக்குவதன் மூலம் தொடங்கவும்:

எடுத்துக்காட்டு

mkdir myproject
cd myproject

mkdir

ஒரு புதிய கோப்பகத்தை உருவாக்குகிறது

cd

எங்கள் பணி கோப்பகத்தை மாற்றுகிறது

இப்போது நாம் சரியான கோப்பகத்தில் இருக்கிறோம் மேலும் Git-ஐத் தொடங்கலாம்!

குறிப்பு: Git Bash-ஐ இங்கே திறக்கவும் (Windows)

நீங்கள் Windows-ஐப் பயன்படுத்தினால், உங்கள் திட்ட கோப்புறையில் நேரடியாக Git Bash-ஐத் திறக்கலாம்:

  • File Explorer-ல் கோப்புறையில் வலது-கிளிக் செய்யவும்
  • Git Bash Here-ஐத் தேர்ந்தெடுக்கவும்

இது சரியான இடத்தில் ஒரு டெர்மினல் சாளரத்தைத் திறக்கும்.

Git-ஐத் தொடக்கவும்

இப்போது நாம் சரியான கோப்புறையில் இருக்கிறோம், அந்த கோப்புறையில் Git-ஐத் தொடங்கலாம்:

எடுத்துக்காட்டு

git init
Initialized empty Git repository in /Users/user/myproject/.git/

🎉 வாழ்த்துக்கள்!

நீங்கள் உங்கள் முதல் Git களஞ்சியத்தை உருவாக்கியுள்ளீர்கள்!

களஞ்சியம் என்றால் என்ன?

Git களஞ்சியம்

Git மாற்றங்களைக் கண்காணிக்கும் ஒரு கோப்புறை

வரலாறு & பதிப்புகள்

களஞ்சியம் உங்கள் திட்டத்தின் அனைத்து வரலாற்றையும் பதிப்புகளையும் சேமிக்கிறது

git init இயக்கும்போது என்ன நடக்கும்?

Git உங்கள் திட்டத்தின் உள்ளே .git என்ற மறைக்கப்பட்ட கோப்புறையை உருவாக்குகிறது.

இது Git உங்கள் கோப்புகள் மற்றும் வரலாற்றைக் கண்காணிக்கத் தேவையான அனைத்து தகவல்களையும் சேமிக்கும் இடமாகும்.

எடுத்துக்காட்டு: மறைக்கப்பட்ட .git கோப்புறையைக் காட்டு (Linux/macOS)

ls -a
.  ..  .git

குறிப்பு:

Windows-ல், .git கோப்புறையைப் பார்க்க File Explorer-ல் "Show hidden files" ஐ இயக்க வேண்டியிருக்கலாம்.

சிக்கல் தீர்வு

git: command not found

தீர்வு: Git நிறுவப்பட்டுள்ளதா மற்றும் PATH-ல் சேர்க்கப்பட்டுள்ளதா என்பதை சரிபார்க்கவும். தேவைப்பட்டால் உங்கள் டெர்மினலை மீண்டும் தொடங்கவும்.

Permission denied

தீர்வு: உங்கள் டெர்மினலை நிர்வாகியாக இயக்க முயற்சிக்கவும் (Windows) அல்லது தேவைப்பட்டால் sudo (macOS/Linux) பயன்படுத்தவும்.

சுருக்கம்

1

கோப்புறையை உருவாக்கவும்

உங்கள் திட்டத்திற்கான புதிய கோப்புறையை உருவாக்கவும்

2

கோப்புறைக்குச் செல்லவும்

cd கட்டளையைப் பயன்படுத்தி கோப்புறைக்குச் செல்லவும்

3

Git-ஐத் தொடக்கவும்

git init கட்டளையை இயக்கி Git களஞ்சியத்தை உருவாக்கவும்

4

சரிபார்க்கவும்

.git கோப்புறை உருவாக்கப்பட்டதை சரிபார்க்கவும்

✅ வெற்றி!

இப்போது உங்களுக்கு ஒரு செயல்பாட்டு Git களஞ்சியம் உள்ளது! அடுத்த படிகளுக்குத் தயாராகுங்கள்.
