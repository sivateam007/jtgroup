Get Started with GitHub

வரவேற்கிறோம்! பதிப்புக் கட்டுப்பாடு மற்றும் கூட்டுழைப்பிற்கான GitHub-ஐப் பயன்படுத்துவதற்கான முதல் படிகளில் இந்தப் பக்கம் உங்களை வழிநடத்தும்.

1

Sign Up for GitHub

GitHub-க்குச் சென்று இலவச கணக்கை உருவாக்கவும்:

GitHub பதிவுப் பக்கம்

குறிப்பு:

உங்கள் Git கட்டமைப்பிற்குப் பயன்படுத்த திட்டமிட்டுள்ள அதே மின்னஞ்சல் முகவரியைப் பயன்படுத்தவும்.

GitHub-ல் பதிவு செய்யுங்கள்
2

Create a Repository

உள்நுழைந்த பிறகு, புதிய களஞ்சியத்தை உருவாக்க New பொத்தானைக் கிளிக் செய்யவும்:

GitHub-ல் புதிய களஞ்சியத்தை உருவாக்குவது

களஞ்சிய விவரங்களை நிரப்பவும் (பெயர், விளக்கம், பொது/தனிப்பட்ட, போன்றவை) மற்றும் Create repository-ஐக் கிளிக் செய்யவும்:

GitHub களஞ்சிய உருவாக்கும் படிவம்

💡 களஞ்சிய உருவாக்கும் உதவிக்குறிப்புகள்:

  • களஞ்சியப் பெயர்: உங்கள் திட்டத்தை விவரிக்கும் தெளிவான பெயரைத் தேர்ந்தெடுக்கவும்
  • விளக்கம்: உங்கள் திட்டம் என்னவென்று விளக்கும் சிறிய விளக்கத்தைச் சேர்க்கவும்
  • பொது/தனிப்பட்ட: கற்றுக்கொள்ளும் நோக்கங்களுக்காக பொது களஞ்சியங்களைப் பயன்படுத்தவும்
  • README: உங்கள் திட்டத்திற்கான README கோப்பைச் சேர்க்கவும்
  • .gitignore: உங்கள் நிரலாக்க மொழிக்கான .gitignore டெம்ப்ளேட்டைத் தேர்ந்தெடுக்கவும்
  • உரிமை: மற்றவர்கள் உங்கள் குறியீட்டைப் பயன்படுத்துவதை அனுமதிக்க உரிமையைச் சேர்க்கவும்

What is a Remote Repository?

ஒரு தொலை களஞ்சியம் என்பது இணையத்தில் ஹோஸ்ட் செய்யப்பட்ட உங்கள் திட்டத்தின் ஒரு பதிப்பாகும். GitHub என்பது தொலை களஞ்சியங்களை ஹோஸ்ட் செய்வதற்கான ஒரு பிரபலமான தளமாகும், இது மற்றவர்களுடன் கூட்டுழைப்பதற்கும் உங்கள் குறியீட்டை காப்புப் பிரதி எடுப்பதற்கும் உங்களை இயலுமைப்படுத்துகிறது.
