GitHub பேஜஸ்

GitHub பேஜஸ் உங்கள் களஞ்சியத்தில் இருந்து நேரடியாக ஒரு வலைத்தளத்தை வெளியிட உங்களை அனுமதிக்கிறது.

1

GitHub பேஜஸை இயக்கவும்

GitHub பேஜஸை இயக்க:

  1. your-username.github.io என்ற பெயரில் ஒரு புதிய களஞ்சியத்தை உருவாக்கவும்.
  2. உங்கள் வலைத்தள கோப்புகளை (index.html போன்றவை) களஞ்சியத்தில் சேர்க்கவும்.
  3. உங்கள் மாற்றங்களை GitHub-க்கு push செய்யவும்.

GitHub-ல் புதிய களஞ்சியத்தை உருவாக்குதல்

குறிப்பு:

களஞ்சியப் பெயர் சரியாக இருக்க வேண்டும்: your-username.github.io

கட்டளை: களஞ்சியத்தை GitHub-க்கு Push செய்யவும் 
git remote add origin https://github.com/your-username/your-username.github.io.git
git push -u origin master
2

மூல கிளை/கோப்புறையை அமைக்கவும்

எந்த கிளை மற்றும் கோப்புறையை வெளியிட வேண்டும் என நீங்கள் தேர்வு செய்யலாம். இயல்பாக, GitHub main (அல்லது master) மற்றும் root கோப்புறையைப் பயன்படுத்துகிறது. இதை மாற்ற:

  1. GitHub-ல் உங்கள் களஞ்சியத்திற்குச் செல்லவும்.
  2. Settings > Pages என்பதைக் கிளிக் செய்யவும்.
  3. Source-க்கு கீழே, கிளை மற்றும் கோப்புறையைத் தேர்ந்தெடுக்கவும் (எ.கா., main மற்றும் docs).
  4. Save என்பதைக் கிளிக் செய்யவும்.

GitHub பேஜஸ் அமைப்புகள்

💡 GitHub பேஜஸ் பெயரிடும் விதிகள்:

  • பயனர் தளம்: username.github.io
  • திட்ட தளம்: username.github.io/repository-name
  • கிளை விருப்பங்கள்: main, master, gh-pages
  • கோப்புறை விருப்பங்கள்: / (root), /docs
3

உங்கள் தளத்தைக் காணவும்

GitHub பேஜஸை இயக்கிய பிறகு, உங்கள் தளம் https://your-username.github.io/ (அல்லது உங்கள் தனிப்பயன் டொமைன்) இல் கிடைக்கும்.

GitHub பேஜஸ் URL

Pages தாவலுக்குச் சென்று, உங்கள் URL-ஐக் காணவும்

உங்கள் நேரடி தளத்தைக் காண இணைப்பைக் கிளிக் செய்யவும்!

🎉 வெற்றி!

உங்கள் வலைத்தளம் இப்போது இணையத்தில் வாழ்கிறது! உங்கள் தோழர்களை URL-ஐப் பகிர அழைக்கவும்.

4

GitHub பேஜஸை முடக்கவும்

உங்கள் பேஜஸ் தளத்தை அணைக்க:

  1. Settings > Pages என்பதிற்குச் செல்லவும்.
  2. Delete என்பதைக் கிளிக் செய்யவும் அல்லது மூல கிளை/கோப்புறையை அகற்றவும்.
  3. விருப்பமாக, உங்களுக்கு இனி தேவையில்லை என்றால் களஞ்சியத்தை நீக்கவும்.
கட்டளை: தொலை கிளையை நீக்கவும் 
git push origin --delete gh-pages
