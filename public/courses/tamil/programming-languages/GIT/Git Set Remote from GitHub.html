உங்கள் உள்ளூர் களஞ்சியத்தை GitHub-க்கு பாதுகாப்பாக இணைக்க SSH பயன்படுத்துவது எப்படி

GitHub தொலை மூலத்தை அமைத்தல்

இப்போது உங்கள் SSH விசை GitHub-ல் சேர்க்கப்பட்டுள்ளது, நீங்கள் உங்கள் உள்ளூர் களஞ்சியத்தை GitHub-க்கு SSH பயன்படுத்தி பாதுகாப்பாக இணைக்கலாம்.

1

உங்கள் SSH இணைப்பைச் சோதிக்கவும்

முதலில், உங்கள் SSH இணைப்பு GitHub-க்கு செயல்படுகிறதா என சோதிக்கவும்:

கட்டளை: SSH இணைப்பை சோதிக்கவும் 
ssh -T git@github.com

முதல் முறையாக இணையும் போது, இது போன்ற ஒரு செய்தியைக் காணலாம்:

முதல் முறை SSH இணைப்பு 
The authenticity of host 'github.com (140.82.121.3)' can't be established.
RSA key fingerprint is SHA256:nThbg6kXUpJWGl7E1IGOCspRomTxdCARLviKw6E5SY8.
Are you sure you want to continue connecting (yes/no/[fingerprint])? yes

yes என தட்டச்சு செய்து, இறுதியில் இது போன்ற ஒரு செய்தியைக் காண வேண்டும்:

வெற்றிகரமான இணைப்பு 
Warning: Permanently added 'github.com,140.82.121.3' (RSA) to the list of known hosts.
Hi your-username! You've successfully authenticated, but GitHub does not provide shell access.

✅ வெற்றி!

கடைசி வரியில் உங்கள் GitHub பயனர்பெயர் இருந்தால், நீங்கள் வெற்றிகரமாக அங்கீகரிக்கப்பட்டுள்ளீர்கள்!

2

உங்கள் களஞ்சியத்தின் SSH முகவரியைப் பெறவும்

GitHub-ல், உங்கள் களஞ்சியத்திற்குச் சென்று Code பொத்தானைக் கிளிக் செய்யவும். SSH தேர்ந்தெடுக்கப்பட்டுள்ளதா என்பதை உறுதிப்படுத்தவும், பின்னர் SSH URL-ஐ நகலெடுக்கவும் (இது git@github.com: உடன் தொடங்கும்):

GitHub-ல் இருந்து SSH களஞ்சிய முகவரியைப் பெறுதல்

குறிப்பு:

SSH URL பொதுவாக இந்த வடிவத்தில் இருக்கும்: git@github.com:your-username/your-repository.git

3

தொலை மூலத்தைச் சேர்க்கவும் அல்லது புதுப்பிக்கவும்

தொலை மூலத்தைச் சேர்க்க (முதல் முறையாக):

கட்டளை: தொலை மூலத்தைச் சேர்க்கவும் 
git remote add origin git@github.com:your-username/your-repo.git

ஏற்கனவே உள்ள தொலை மூலத்தை SSH பயன்படுத்த புதுப்பிக்க:

கட்டளை: தொலை மூல URL-ஐ புதுப்பிக்கவும் 
git remote set-url origin git@github.com:your-username/your-repo.git

💡 உதவிக்குறிப்பு:

உங்கள் தொலை மூலம் சரியாக அமைக்கப்பட்டுள்ளதா என சரிபார்க்க:

git remote -v

இது உங்கள் தொலை களஞ்சிய URL-களைக் காண்பிக்க வேண்டும்.

சரிபார்ப்பு மற்றும் அடுத்த படிகள்

🎉 வாழ்த்துக்கள்!

நீங்கள் இப்போது SSH உடன் GitHub ஐப் பயன்படுத்த தயாராக உள்ளீர்கள்.

Push செய்யவும்

உங்கள் மாற்றங்களை GitHub-க்கு அனுப்பவும்

git push -u origin main

Pull செய்யவும்

மாற்றங்களை GitHub-ல் இருந்து பதிவிறக்கவும்

git pull origin main

Clone செய்யவும்

புதிய களஞ்சியங்களை பதிவிறக்கவும்

git clone git@github.com:user/repo.git

விரைவு குறிப்பு

SSH சோதனை

இணைப்பு செயல்படுகிறதா என சோதிக்கவும்

URL பெறவும்

களஞ்சிய SSH URL-ஐ நகலெடுக்கவும்

தொலை மூலம்

தொலை மூலத்தை அமைக்கவும்

சரிபார்க்கவும்

அமைப்பை உறுதிப்படுத்தவும்
