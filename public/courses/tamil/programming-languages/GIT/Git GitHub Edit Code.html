GitHub-ல் குறியீட்டைத் திருத்துதல்

GitHub உங்கள் உலாவியில் நேரடியாக கோப்புகளைத் திருத்த உங்களை அனுமதிக்கிறது.

இது உங்கள் கணினியில் Git பயன்படுத்த வேண்டியதில்லாமல் விரைவான மாற்றங்களைச் செய்வதற்கு பயனுள்ளதாக இருக்கும்.

1

எந்த கோப்பையும் திருத்தவும்

ஒரு கோப்பைத் திருத்த (README.md போன்ற), உங்கள் களஞ்சியத்தில் கோப்புப் பெயரைக் கிளிக் செய்யவும், பின்னர் Edit பொத்தானைக் கிளிக் செய்யவும் (பென்சில் ஐகான்):

GitHub கோப்பு திருத்தும் இடைமுகம்

💡 உதவிக்குறிப்பு:

இப்போது நீங்கள் எடிட்டரில் கோப்பில் மாற்றங்களைச் செய்யலாம். README.md மட்டுமல்ல, எந்த கோப்பையும் நீங்கள் திருத்தலாம்.

2

கமிட் செய்தியை எழுதவும்

திருத்திய பிறகு, Commit changes (மாற்றங்களைக் கமிட் செய்ய) பகுதிக்குக் கீழே உருட்டவும்.

நீங்கள் என்ன மாற்றியமைத்தீர்கள் என்பதற்கான ஒரு குறுகிய, தெளிவான விளக்கத்தை Commit message (கமிட் செய்தி) பெட்டியில் சேர்க்கவும்.

இது மற்றவர்கள் உங்கள் புதுப்பிப்பைப் புரிந்துகொள்ள உதவுகிறது. கமிட்கள் பற்றி மேலும் அறிக

GitHub கமிட் மாற்றங்கள் பகுதி

3

மாற்றங்களை முன்னோட்டமிடவும்

சேமிப்பதற்கு முன், கோப்பில் என்ன மாறும் என்பதைக் காண Preview changes (மாற்றங்களை முன்னோட்டமிடு) என்பதைக் கிளிக் செய்யலாம்.

கமிட் செய்வதற்கு முன் உங்கள் திருத்தங்களைச் சரிபார்க்க இது உதவுகிறது.

4

ஒரு கிளையில் கமிட் செய்யவும்

இயல்பாக, நீங்கள் நேரடியாக main (அல்லது master) கிளையில் கமிட் செய்யலாம்.

குறிப்பு:

பெரிய மாற்றங்களுக்கு, ஒரு புதிய கிளையை உருவாக்குவது சிறந்தது.

பாதுகாப்பாக வேலை செய்ய Create a new branch for this commit and start a pull request (இந்த கமிட்டிற்கு ஒரு புதிய கிளையை உருவாக்கவும் மற்றும் ஒரு pull request-ஐத் தொடங்கவும்) என்பதைத் தேர்ந்தெடுக்கவும். கிளைகள் பற்றி மேலும் அறிக

5

எடிட்டரில் இருந்து ஒரு புதிய கிளையை உருவாக்கவும்

நீங்கள் ஒரு புதிய கிளையை உருவாக்க தேர்வு செய்யும் போது, GitHub தானாகவே ஒரு கிளைப் பெயரைப் பரிந்துரைக்கும்.

கமிட் செய்த பிறகு, உங்கள் மாற்றங்களைப் பரிந்துரைக்க ஒரு pull request-ஐத் திறக்கலாம். Pull requests பற்றி மேலும் அறிக
