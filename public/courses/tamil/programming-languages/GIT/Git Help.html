Git Help

Learn how to get help and documentation for Git commands

ஏன் மற்றும் எப்போது Git உதவியைப் பயன்படுத்த வேண்டும்?

Git-க்கு பல கட்டளைகள் மற்றும் விருப்பங்கள் உள்ளன.

ஒரு கட்டளை எவ்வாறு வேலை செய்கிறது என்பதை நீங்கள் மறந்துவிட்டால் அல்லது அதன் விருப்பங்களைப் பற்றி அறிய விரும்பினால், Git-ன் உள்ளமைக்கப்பட்ட உதவியைப் பயன்படுத்தலாம்.

உங்கள் terminal-விட்டு வெளியேறாமல் பதில்களைப் பெற இது வேகமான வழியாகும்.

உதவி பெற முக்கிய கட்டளைகள்

git help <command>

ஒரு கட்டளையின் கையேட்டுப் பக்கத்தைப் பார்

git <command> --help

ஒரு கட்டளையின் உதவியைப் பார் (மேலே உள்ளதைப் போலவே)

git <command> -h

விருப்பங்களின் விரைவான சுருக்கத்தைப் பார்

git help --all

அனைத்து சாத்தியமான Git கட்டளைகளை பட்டியலிடு

git help -g

வழிகாட்டிகள் மற்றும் கருத்துக்களை பட்டியலிடு

குறிப்பிட்ட கட்டளையின் உதவியைப் பார்க்கவும் (git help <command>)

குறிப்பிட்ட கட்டளையின் முழு கையேட்டுப் பக்கத்தைக் காட்டுகிறது, அனைத்து விருப்பங்கள் மற்றும் எடுத்துக்காட்டுகள் உட்பட:

எடுத்துக்காட்டு: Commit-க்கான உதவியைப் பார்க்கவும்

git help commit
GIT-COMMIT(1)
NAME
    git-commit - Record changes to the repository
SYNOPSIS
    git commit [options] [--] ...
DESCRIPTION
    Stores the current contents of the index in a new commit
    together with a log message from the user describing the changes.
...

இந்த கட்டளை உங்கள் terminal-ல் git commit-க்கான முழு ஆவணங்களைத் திறக்கிறது.

💡 உதவிப் பக்கங்களைப் பார்க்கும் போது:

  • கீழே உருட்ட அம்பு விசைகள் அல்லது Space பயன்படுத்தவும், மேலே உருட்ட b பயன்படுத்தவும்
  • தேட / உடன் ஒரு வார்த்தையைத் தட்டச்சு செய்யவும் (எ.க., /option), பின்னர் அடுத்த பொருத்தத்திற்கு n
  • எந்த நேரத்திலும் உதவிக் காட்சியிலிருந்து வெளியேற q அழுத்தவும்

--help உடன் உதவியைப் பார்க்கவும் (git <command> --help)

இது git help <command> போலவே செயல்படுகிறது. பெரும்பாலான பயனர்கள் இந்த வடிவத்தை விரும்புகிறார்கள்:

எடுத்துக்காட்டு: Status-க்கான உதவியைப் பார்க்கவும்

git status --help
GIT-STATUS(1)
NAME
    git-status - Show the working tree status
SYNOPSIS
    git status [options] [--] [pathspec...]
DESCRIPTION
    Displays paths that have differences between the index file and the current HEAD commit.
...

இந்த கட்டளை git status-க்கான கையேட்டுப் பக்கத்தைத் திறக்கிறது.

-h உடன் விரைவான சுருக்கத்தைப் பார்க்கவும் (git <command> -h)

கட்டளையின் விருப்பங்களின் குறுகிய சுருக்கத்தை terminal சாளரத்தில் காட்டுகிறது (முழு கையேட்டைத் திறக்காது):

எடுத்துக்காட்டு: Add-க்கான விரைவான உதவி

git add -h
usage: git add [options] [--] ...
    -n, --dry-run         dry run
    -v, --verbose        be verbose
    -i, --interactive    interactive picking
    -p, --patch          select hunks interactively
    -e, --edit           edit current diff and apply
    -u, --update         update tracked files
    -A, --all            add changes from all tracked and untracked files
...

இந்த கட்டளை ஒரு கட்டளையின் கிடைக்கக்கூடிய விருப்பங்களின் சுருக்கமான கண்ணோட்டத்தை உங்களுக்குத் தருகிறது.

அனைத்து Git கட்டளைகளையும் பட்டியலிடவும் (git help --all)

உங்கள் கணினியில் கிடைக்கக்கூடிய ஒவ்வொரு Git கட்டளையையும் பட்டியலிடுகிறது, வகைப்படுத்தப்பட்டது:

⚠️ எச்சரிக்கை:

இது கட்டளைகளின் மிக நீளமான பட்டியலைக் காட்டும்

குறிப்பு:

பட்டியல் காட்சியில் நீங்கள் சிக்கிக் கொண்டால், பட்டியலின் முடிவிற்குச் செல்ல SHIFT + G, பின்னர் காட்சியிலிருந்து வெளியேற q அழுத்தவும்.

வழிகாட்டிகள் மற்றும் கருத்துக்களை பட்டியலிடவும் (git help -g)

ஆழமான கற்றலுக்கான வழிகாட்டிகள் மற்றும் கருத்து தலைப்புகளின் பட்டியலைக் காட்டுகிறது:

எடுத்துக்காட்டு: வழிகாட்டிகள் மற்றும் கருத்துக்களை பட்டியலிடவும்

git help -g
The common Git guides are:
   attributes   Defining attributes per path
   everyday     Everyday Git With 20 Commands Or So
   glossary     A Git glossary of terms
   revisions    Specifying revisions and ranges for Git
...

Git-ன் மேம்பட்ட கருத்துக்கள் மற்றும் சிறந்த நடைமுறைகளைப் பற்றி அறிய இந்த கட்டளை சிறந்தது.

உதவி வழிசெலுத்தல் உதவிக்குறிப்புகள்

கீழே உருட்ட

Space bar அல்லது அம்பு கீழ் விசை

மேலே உருட்ட

b விசை

தேட

/ உடன் தொடங்கி, உங்கள் தேடல் சொல்லைத் தட்டச்சு செய்யவும்

வெளியேற

q விசை

சிக்கல் தீர்வு

உதவிப் பார்வையாளரில் இருந்து எப்படி வெளியேறுவது?

தீர்வு: உதவிப் பக்கத்திலிருந்து வெளியேற q அழுத்தவும்

உதவிப் பக்கம் திறக்கவில்லையா?

தீர்வு: விரைவான சுருக்கத்திற்கு git <command> -h முயற்சிக்கவும்

ஒரு வார்த்தையை எப்படி தேடுவது?

தீர்வு: உதவிப் பார்வையாளரில், / அழுத்தவும், பின்னர் உங்கள் தேடல் சொல்லைத் தட்டச்சு செய்து Enter அழுத்தவும்

சுருக்கம்

✅ நீங்கள் இப்போது கற்றுக்கொண்டவை:

  • Git உதவியைப் பயன்படுத்துவது ஏன் முக்கியமானது
  • குறிப்பிட்ட கட்டளைகளுக்கான முழு ஆவணங்களைப் பார்ப்பது எப்படி
  • விரைவான கட்டளை விருப்ப சுருக்கங்களைப் பார்ப்பது எப்படி
  • அனைத்து கிடைக்கக்கூடிய Git கட்டளைகளைக் கண்டறிவது எப்படி
  • வழிகாட்டிகள் மற்றும் கருத்து ஆவணங்களை அணுகுவது எப்படி
  • உதவிப் பக்கங்களில் திறம்பட வழிசெலுத்துவது எப்படி

அடுத்து என்ன?

இப்போது Git உதவி கட்டளைகளைப் பயன்படுத்தத் தெரிந்து கொண்டீர்கள்! அடுத்த பாடத்தில், Git branches-உடன் வேலை செய்வது எப்படி என்பதைக் கற்றுக்கொள்வோம்.
