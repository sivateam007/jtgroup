GitHub-ல் SSH சேர்த்தல்

உங்கள் கணினியில் SSH விசை ஜோடியை உருவாக்கிய பிறகு, அடுத்த படி உங்கள் பொது விசையை உங்கள் GitHub கணக்கில் சேர்ப்பதாகும். இது GitHub உங்கள் கணினியை அங்கீகரிக்கவும் பாதுகாப்பான இணைப்புகளை அனுமதிக்கவும் உதவுகிறது.

⚠️ முக்கியமானது:

SSH மூலம் push, pull, அல்லது clone செய்ய முயற்சிக்கும் முன் இந்தப் படிகளை முடிக்கவும். இந்தப் பக்கம் உங்கள் SSH விசையை ஏற்கனவே உருவாக்கி உங்கள் SSH முகவரில் சேர்த்துள்ளீர்கள் என்று கருதுகிறது. இல்லையென்றால், Getting Started வழிகாட்டியில் உள்ள SSH அமைப்புப் பகுதிக்குத் திரும்பிச் செல்லவும்.

1

உங்கள் பொது SSH விசையை நகலெடுக்கவும்

முதலில், உங்கள் பொது SSH விசையை நகலெடுக்கவும்:

Windows (Git Bash)-ல்:

clip < ~/.ssh/id_rsa.pub

macOS-ல்:

pbcopy < ~/.ssh/id_rsa.pub

Linux-ல்:

cat ~/.ssh/id_rsa.pub

(பின்னர் கைமுறையாக நகலெடுக்கவும்)

2

GitHub-ல் அமைப்புகளுக்குச் செல்லவும்

GitHub-க்குச் சென்று, மேல் வலது மூலையில் உங்கள் சுயவிவரத்தைக் கிளிக் செய்து, Settings (அமைப்புகள்) என்பதைத் தேர்ந்தெடுக்கவும்:

GitHub சுயவிவர அமைப்புகள்

3

SSH மற்றும் GPG விசைகள் பகுதியைத் தேர்ந்தெடுக்கவும்

பக்கப் பட்டியில், SSH and GPG keys (SSH மற்றும் GPG விசைகள்) என்பதைத் தேர்ந்தெடுத்து New SSH key (புதிய SSH விசை) பொத்தானைக் கிளிக் செய்யவும்:

GitHub SSH மற்றும் GPG விசைகள் பகுதி

4

SSH விசையைச் சேர்க்கவும்

உங்கள் விசைக்கு ஒரு விளக்கமான தலைப்பைக் கொடுக்கவும், உங்கள் பொது SSH விசையை "Key" (விசை) புலத்தில் ஒட்டவும், பின்னர் Add SSH Key (SSH விசையைச் சேர்க்க) பொத்தானைக் கிளிக் செய்யவும்:

GitHub SSH விசை சேர்ப்பு படிவம்

குறிப்பு:

சேர்ப்பை உறுதிப்படுத்த உங்கள் GitHub கடவுச்சொல்லை வழங்க அல்லது 2FA (இரு-காரணி அங்கீகாரம்) பயன்படுத்த அழைக்கப்படலாம்.

5

சேர்க்கப்பட்ட விசையைச் சரிபார்க்கவும்

உங்கள் புதிய SSH விசை பட்டியலிடப்பட்டதை நீங்கள் காண்பீர்கள்:

GitHub-ல் வெற்றிகரமாக SSH விசை சேர்க்கப்பட்டது

✅ வெற்றி!

உங்கள் SSH விசை இப்போது GitHub-ல் சேர்க்கப்பட்டுள்ளது. அடுத்து, உங்கள் SSH இணைப்பைச் சோதித்து உங்கள் GitHub தொலை மூலத்தை SSH பயன்படுத்தி அமைப்பீர்கள்.

விரைவு குறிப்பு

அமைப்புகளுக்குச் செல்லவும்

GitHub அமைப்புகள் பக்கத்திற்குச் செல்லவும்

SSH விசைகள்

SSH மற்றும் GPG விசைகள் பகுதியைத் தேர்ந்தெடுக்கவும்

விசையைச் சேர்க்கவும்

புதிய SSH விசையைச் சேர்க்கவும்

🚀 அடுத்து என்ன?

உங்கள் SSH இணைப்பைச் சோதித்து, உங்கள் GitHub தொலை மூலத்தை SSH பயன்படுத்தி அமைப்பீர்கள்.

இது உங்கள் களஞ்சியங்களுடன் பாதுகாப்பான தொடர்பு கொள்ள உங்களை இயலுமைப்படுத்தும்.
