இப்போது அவற்றை எங்கள் GitHub ஃபோர்க்கில் புஷ் செய்கிறோம்:

GitHub-க்குச் செல்லவும், களஞ்சியத்தில் ஒரு புதிய கமிட் இருப்பதை நாங்கள் காண்கிறோம். மேலும் அசல் களஞ்சியத்திற்கு ஒரு Pull Request-ஐ அனுப்பலாம்:

GitHub ஃபோர்க் Pull Request

அதைக் கிளிக் செய்து ஒரு pull request-ஐ உருவாக்கவும்:

GitHub ஃபோர்க் Pull Request உருவாக்கவும்

நிர்வாகிகளுக்கான விளக்கத்தைச் சேர்ப்பதை நினைவில் கொள்ளுங்கள்.

GitHub ஃபோர்க் Pull Request கருத்து

Pull Request அனுப்பப்பட்டது:

GitHub ஃபோர்க் Pull Request அனுப்பப்பட்டது

2

Pull Requests-ஐ அங்கீகரித்தல்

இப்போது அணுகல் உள்ள எந்த உறுப்பினரும் அசல் களஞ்சியத்தைப் பார்க்கும் போது Pull Request-ஐப் பார்க்க முடியும்:

GitHub புதிய Pull Request

மேலும் அவர்கள் முன்மொழியப்பட்ட மாற்றங்களைப் பார்க்க முடியும்:

GitHub Pull Requests கண்ணோட்டம்

மாற்றங்கள் குறித்து கருத்து தெரிவித்து இணைக்கவும்:

GitHub Pull Request இணைத்தல்

உறுதிப்படுத்தவும்:

GitHub Pull Request இணைப்பை உறுதிப்படுத்தவும்

மேலும் மாற்றங்கள் மாஸ்டருடன் இணைக்கப்பட்டுள்ளன:

GitHub Pull Request இணைக்கப்பட்டது

🎉 வாழ்த்துகள்!

இப்போது நீங்கள் முயற்சிக்கவும்! GitHub-ல் உள்ள களஞ்சியங்களுக்கு உங்கள் சொந்த பங்களிப்புகளைச் செய்ய இப்போது நீங்கள் தயாராக உள்ளீர்கள்.
