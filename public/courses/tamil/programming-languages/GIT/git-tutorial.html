Learn Git - Master version control for your projects

Learn Git

Git என்பது உங்களுக்கு உதவும் ஒரு கருவியாகும்:

  • உங்கள் கோப்புகள் மற்றும் குறியீட்டின் வெவ்வேறு பதிப்புகளை சேமித்து நிர்வகிக்க
  • மற்றவர்களுடன் வேலை செய்ய, மாற்றங்களை கண்காணிக்க, மற்றும் தவறுகளை ரத்து செய்ய

🏁 உதவிக்குறிப்பு:

உங்கள் முன்னேற்றத்தை கண்காணிக்க உள்நுழையவும் - இது இலவசம்.

Where to use Git?

Git உங்கள் கணினியில் வேலை செய்கிறது, ஆனால் GitHub, GitLab, அல்லது Bitbucket போன்ற ஆன்லைன் சேவைகளுடன் உங்கள் வேலையை மற்றவர்களுடன் பகிர்ந்து கொள்ளவும் பயன்படுத்தலாம். இவை ரிமோட் ரிப்போசிடரிகள் என்று அழைக்கப்படுகின்றன.

இந்த டுடோரியலில், உங்கள் சொந்த திட்டங்களுக்கு Git ஐ எவ்வாறு பயன்படுத்துவது மற்றும் ஆன்லைனில் ரிமோட் ரிப்போசிடரிகளுடன் எவ்வாறு இணைப்பது என்பதை நீங்கள் கற்றுக்கொள்வீர்கள்.

Learning by Examples

இந்த டுடோரியலில், Git கட்டளைகளை இப்படி காண்பிப்போம்:

Example

git --version
git version 2.30.2.windows.1

புதிய பயனர்களுக்கு, டெர்மினல் காட்சியைப் பயன்படுத்துவது சற்று சிக்கலானதாகத் தோன்றலாம்.

கவலைப்பட வேண்டாம்! நாங்கள் இதை மிகவும் எளிமையாக வைத்திருப்போம், மேலும் இந்த வழியில் கற்றுக்கொள்வது Git எவ்வாறு செயல்படுகிறது என்பதற்கான நல்ல புரிதலை உங்களுக்கு வழங்கும்.

மேலே உள்ள குறியீட்டில், நீங்கள் கட்டளைகள் (உள்ளீடு) மற்றும் வெளியீட்டைக் காணலாம்.

இது போன்ற வரிகள் நாம் உள்ளிடும் கட்டளைகள்:

Example

git --version

இது போன்ற வரிகள் எங்கள் கட்டளைகளுக்கான வெளியீடு/பதில்:

Example

git version 2.30.2.windows.1

பொதுவாக, $ முன்னால் உள்ள வரிகள் உள்ளீடு.

இவை உங்கள் டெர்மினலில் நகலெடுத்து இயக்கக்கூடிய கட்டளைகள்.

💡 ஆரம்பிக்கும் வழிகாட்டுதலுக்கான உதவிக்குறிப்பு:

தவறுகள் செய்வதைப் பற்றி கவலைப்பட வேண்டாம்!

உங்கள் சொந்த கணினியில் Git ஐப் பயன்படுத்தும் போது, முக்கியமான எதையும் நீங்கள் உடைக்க முடியாது.

சோதனை செய்வது கற்றுக்கொள்வதற்கான ஒரு சிறந்த வழியாகும், மேலும் நீங்கள் செல்லும் போது மாற்றங்களை எப்போதும் ரத்து செய்யலாம் அல்லது மீண்டும் செய்யலாம்.

Change Platform:

டுடோரியல் GitHub, GitLab, அல்லது Bitbucket ஆகியவற்றுக்கான எடுத்துக்காட்டுகளைக் காட்டலாம்.

Git கட்டளைகள் பெரும்பாலும் ஒரே மாதிரியானவை, ஆனால் சில படிகள் (ரிமோட்டுடன் இணைப்பது அல்லது குறியீட்டை தள்ளுவது போன்றவை) நீங்கள் தேர்ந்தெடுக்கும் தளத்தைப் பொறுத்து சற்று வித்தியாசமாகத் தோன்றலாம்.

ஒவ்வொரு தளத்திற்கும் எடுத்துக்காட்டுகளைப் பார்க்க மெனுவைப் பயன்படுத்தவும்.
