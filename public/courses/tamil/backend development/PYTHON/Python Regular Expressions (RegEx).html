Python Regular Expressions (RegEx)

Python இல் வழக்கமான வெளிப்பாடுகளைக் கற்றுக்கொள்ளுங்கள்

Python Regular Expressions

ஒரு RegEx, அல்லது வழக்கமான வெளிப்பாடு, ஒரு தேடல் முறையை உருவாக்கும் எழுத்துக்களின் வரிசையாகும்.

ஒரு சரம் குறிப்பிடப்பட்ட தேடல் முறையைக் கொண்டுள்ளதா எனச் சரிபார்க்க RegEx பயன்படுத்தப்படலாம்.

🔍 RegEx பயன்பாடுகள்:

• தரவு சரிபார்த்தல் (மின்னஞ்சல், தொலைபேசி எண் போன்றவை)
• தரவு பிரித்தெடுத்தல்
• தரவு மாற்றீடு
• சரம் மேன்ச்சிங்

RegEx தொகுதி

Python இல் re என்று ஒரு உள்ளமைக்கப்பட்ட தொகுப்பு உள்ளது, இது வழக்கமான வெளிப்பாடுகளுடன் பணியாற்ற பயன்படுத்தப்படலாம்.

re தொகுதியை இறக்குமதி செய்யவும்:

import re

Example

சரம் "The" உடன் தொடங்கி "Spain" உடன் முடிவடைகிறதா எனப் பார்க்கவும்:

import re

txt = "The rain in Spain"
x = re.search("^The.*Spain$", txt)
print(x)
Output: <re.Match object; span=(0, 17), match='The rain in Spain'>

RegEx செயல்பாடுகள்

re தொகுதி ஒரு சரத்தில் பொருத்தத்தைத் தேட அனுமதிக்கும் செயல்பாடுகளின் தொகுப்பை வழங்குகிறது:

செயல்பாடு விளக்கம்
findall அனைத்து பொருத்தங்களையும் கொண்ட பட்டியலைத் திருப்பித் தருகிறது
search சரத்தில் எங்கேனும் பொருத்தம் இருந்தால் Match பொருளைத் திருப்பித் தருகிறது
split சரம் ஒவ்வொரு பொருத்தத்திலும் பிரிக்கப்பட்ட பட்டியலைத் திருப்பித் தருகிறது
sub ஒன்று அல்லது பல பொருத்தங்களை ஒரு சரத்துடன் மாற்றுகிறது
findall()
அனைத்து பொருத்தங்களையும் கொண்ட பட்டியலைத் திருப்பித் தருகிறது

Example

அனைத்து பொருத்தங்களின் பட்டியலையும் அச்சிடவும்:

import re

txt = "The rain in Spain"
x = re.findall("ai", txt)
print(x)
Output: ['ai', 'ai']

பட்டியல் காணப்படும் வரிசையில் பொருத்தங்களைக் கொண்டுள்ளது.

பொருத்தங்கள் எதுவும் காணப்படவில்லை என்றால், ஒரு காலிபட்டியல் திரும்பப் பெறப்படும்:

import re

txt = "The rain in Spain"
x = re.findall("Portugal", txt)
print(x)
Output: []

மெட்டாகேரக்டர்கள்

மெட்டாகேரக்டர்கள் சிறப்பு அர்த்தத்துடன் கூடிய எழுத்துக்கள்:

எழுத்து விளக்கம் எடுத்துக்காட்டு
[ ] எழுத்துக்களின் தொகுப்பு "[a-m]"
\ சிறப்பு வரிசையைக் குறிக்கிறது (சிறப்பு எழுத்துக்களை எஸ்கேப் செய்யவும் பயன்படுத்தலாம்) "\d"
. எந்த எழுத்தும் (புதிய வரி எழுத்து தவிர) "he..o"
^ இதனுடன் தொடங்குகிறது "^hello"
$ இதனுடன் முடிகிறது "planet$"
* பூஜ்ஜிய அல்லது அதற்கு மேற்பட்ட நிகழ்வுகள் "he.*o"
+ ஒன்று அல்லது அதற்கு மேற்பட்ட நிகழ்வுகள் "he.+o"
? பூஜ்ஜிய அல்லது ஒரு நிகழ்வுகள் "he.?o"
{ } குறிப்பிட்ட எண்ணிக்கையிலான நிகழ்வுகள் "he.{2}o"
| அல்லது "falls|stays"
( ) பிடித்து குழுவாக்குதல் "(abc)"

சிறப்பு வரிசைகள்

ஒரு சிறப்பு வரிசை என்பது பின்வரும் பட்டியலில் உள்ள எழுத்துகளில் ஒன்றைத் தொடர்ந்து வரும் \ ஆகும், மேலும் இது ஒரு சிறப்பு அர்த்தத்தைக் கொண்டுள்ளது:

எழுத்து விளக்கம் எடுத்துக்காட்டு
\A குறிப்பிட்ட எழுத்துக்கள் சரத்தின் தொடக்கத்தில் இருந்தால் பொருத்தத்தைத் திருப்பித் தருகிறது "\AThe"
\b குறிப்பிட்ட எழுத்துக்கள் ஒரு வார்த்தையின் தொடக்கத்தில் அல்லது முடிவில் இருக்கும் இடத்தில் பொருத்தத்தைத் திருப்பித் தருகிறது r"\bain"
\B குறிப்பிட்ட எழுத்துக்கள் உள்ளன, ஆனால் ஒரு வார்த்தையின் தொடக்கத்தில் (அல்லது முடிவில்) இல்லாத இடத்தில் பொருத்தத்தைத் திருப்பித் தருகிறது r"\Bain"
\d சரம் இலக்கங்களைக் கொண்டிருக்கும் இடத்தில் பொருத்தத்தைத் திருப்பித் தருகிறது (0-9 எண்கள்) "\d"
\D சரம் இலக்கங்களைக் கொண்டிருக்காத இடத்தில் பொருத்தத்தைத் திருப்பித் தருகிறது "\D"
\s சரம் வெள்ளை இட எழுத்தைக் கொண்டிருக்கும் இடத்தில் பொருத்தத்தைத் திருப்பித் தருகிறது "\s"
\S சரம் வெள்ளை இட எழுத்தைக் கொண்டிருக்காத இடத்தில் பொருத்தத்தைத் திருப்பித் தருகிறது "\S"
\w சரம் எந்தவொரு வார்த்தை எழுத்தையும் கொண்டிருக்கும் இடத்தில் பொருத்தத்தைத் திருப்பித் தருகிறது (a முதல் Z வரை எழுத்துக்கள், 0 முதல் 9 வரை இலக்கங்கள் மற்றும் அன்டர்ஸ்கோர் _ எழுத்து) "\w"
\W சரம் எந்தவொரு வார்த்தை எழுத்தையும் கொண்டிருக்காத இடத்தில் பொருத்தத்தைத் திருப்பித் தருகிறது "\W"
\Z குறிப்பிட்ட எழுத்துக்கள் சரத்தின் முடிவில் இருந்தால் பொருத்தத்தைத் திருப்பித் தருகிறது "Spain\Z"

செட்கள்

ஒரு செட் என்பது சதுர அடைப்புக்குறிகளுக்குள் உள்ள எழுத்துக்களின் தொகுப்பாகும் [] சிறப்பு அர்த்தத்துடன்:

[arn] → a, r, அல்லது n ஆகியவற்றில் ஒன்று இருக்கும் இடத்தில் பொருத்தம்
[a-n] → a மற்றும் n க்கு இடையில் உள்ள எந்த சிறிய எழுத்துக்கும் பொருத்தம்
[^arn] → a, r, மற்றும் n தவிர வேறு எந்த எழுத்துக்கும் பொருத்தம்
[0123] → 0, 1, 2, அல்லது 3 ஆகியவற்றில் ஏதேனும் ஒன்று இருக்கும் இடத்தில் பொருத்தம்
[0-9] → 0 மற்றும் 9 க்கு இடையில் உள்ள எந்த இலக்கத்திற்கும் பொருத்தம்
[a-zA-Z] → a மற்றும் z க்கு இடையில் உள்ள எந்த எழுத்துக்கும் பொருத்தம், சிறிய எழுத்து அல்லது பெரிய எழுத்து

💡 செட்கள் பற்றி:

செட்களில், +, *, ., |, (), $,{} ஆகியவற்றுக்கு சிறப்பு அர்த்தம் இல்லை, எனவே [+] என்பது: சரத்தில் உள்ள எந்த + எழுத்துக்கும் பொருத்தத்தைத் திருப்பித் தருகிறது.

Match பொருள்

ஒரு Match பொருள் என்பது தேடல் மற்றும் முடிவு பற்றிய தகவல்களைக் கொண்ட ஒரு பொருளாகும்.

⚠️ குறிப்பு:

பொருத்தம் இல்லை என்றால், Match பொருளுக்குப் பதிலாக None மதிப்பு திரும்பப் பெறப்படும்.

Match பொருளுக்கு தேடல் மற்றும் முடிவு பற்றிய தகவல்களைப் பெற பயன்படுத்தப்படும் பண்புகள் மற்றும் முறைகள் உள்ளன:

import re

txt = "The rain in Spain"
x = re.search(r"\bS\w+", txt)

print(x.span())   # Output: (12, 17) - பொருத்தத்தின் தொடக்க மற்றும் முடிவு நிலைகள்
print(x.string)   # Output: The rain in Spain - செயல்பாட்டிற்குள் அனுப்பப்பட்ட சரம்
print(x.group())  # Output: Spain - பொருத்தம் இருந்த சரத்தின் பகுதி

பயிற்சிகள் மூலம் கற்றல்

பின்வரும் குறியீட்டைக் கவனியுங்கள்:

❓ பின்வரும் குறியீட்டின் அச்சிடப்பட்ட முடிவு என்னவாக இருக்கும்?

import re
txt = 'The rain in Spain'
x = re.findall('[a-c]', txt)
print(x)
['a', 'a']
✓ சரி! [a-c] a, b, அல்லது c எழுத்துக்களுக்கு பொருத்தம். 'The rain in Spain' இல் 'a' எழுத்து இரண்டு முறை தோன்றுகிறது
'The rin in Spin'
✗ தவறு! findall() செயல்பாடு பொருத்தங்களின் பட்டியலைத் திருப்பித் தருகிறது, மாற்றப்பட்ட சரம் அல்ல
2
✗ தவறு! findall() பொருத்தங்களின் எண்ணிக்கையை அல்ல, பொருத்தங்களின் பட்டியலைத் திருப்பித் தருகிறது

💡 விளக்கம்:

[a-c] என்பது a, b, அல்லது c எழுத்துக்களுக்கு பொருத்தமாக இருக்கும் ஒரு RegEx செட் ஆகும்.

'The rain in Spain' சரத்தில்:

  • T → பொருத்தமில்லை (a-c வரம்பில் இல்லை)
  • h → பொருத்தமில்லை
  • e → பொருத்தமில்லை
  • ␣ → பொருத்தமில்லை
  • r → பொருத்தமில்லை
  • a → பொருத்தம்!
  • i → பொருத்தமில்லை
  • n → பொருத்தமில்லை
  • ␣ → பொருத்தமில்லை
  • i → பொருத்தமில்லை
  • n → பொருத்தமில்லை
  • ␣ → பொருத்தமில்லை
  • S → பொருத்தமில்லை (பெரிய எழுத்து)
  • p → பொருத்தமில்லை
  • a → பொருத்தம்!
  • i → பொருத்தமில்லை
  • n → பொருத்தமில்லை

எனவே findall() ['a', 'a'] பட்டியலைத் திருப்பித் தருகிறது, ஏனெனில் 'a' எழுத்து இரண்டு முறை தோன்றுகிறது.
