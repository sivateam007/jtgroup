Python Match Statement

பைதான் மேட்ச் அறிக்கையைக் கற்றுக்கொள்ளுங்கள்

Python Match Statement

match அறிக்கை பல்வேறு நிபந்தனைகளின் அடிப்படையில் வெவ்வேறு செயல்களைச் செய்யப் பயன்படுகிறது.

ℹ️ முக்கிய தகவல்:

Python 3.10 மற்றும் அதற்கு மேல் பதிப்புகளில் மட்டுமே match அறிக்கை கிடைக்கும். இது புதிய அம்சமாகும்.

Python Match அறிக்கை

பல if..else அறிக்கைகளை எழுதுவதற்கு பதிலாக, நீங்கள் match அறிக்கையைப் பயன்படுத்தலாம்.

match அறிக்கை செயல்படுத்தப்பட வேண்டிய பல குறியீடு தொகுதிகளில் ஒன்றைத் தேர்ந்தெடுக்கிறது.

தொடரியல்

match expression:
  case x:
    # code block
  case y:
    # code block
  case z:
    # code block

இது எவ்வாறு வேலை செய்கிறது:

  • match வெளிப்பாடு ஒருமுறை மதிப்பீடு செய்யப்படுகிறது
  • வெளிப்பாட்டின் மதிப்பு ஒவ்வொரு case இன் மதிப்புகளுடன் ஒப்பிடப்படுகிறது
  • பொருத்தம் இருந்தால், தொடர்புடைய குறியீடு தொகுதி செயல்படுத்தப்படுகிறது

மேட்ச் எடுத்துக்காட்டு

கீழே உள்ள எடுத்துக்காட்டு வாரத்தின் நாள் எண்ணைப் பயன்படுத்தி வாரத்தின் நாளின் பெயரை அச்சிடுகிறது:

எடுத்துக்காட்டு

day = 4

match day:
  case 1:
    print("Monday")
  case 2:
    print("Tuesday")
  case 3:
    print("Wednesday")
  case 4:
    print("Thursday")
  case 5:
    print("Friday")
  case 6:
    print("Saturday")
  case 7:
    print("Sunday")

💡 உதவிக்குறிப்பு:

match அறிக்கை பாரம்பரிய if-elif-else தொடரை விட சுத்தமான மற்றும் படிக்க எளிதான குறியீட்டை வழங்குகிறது.

இயல்புநிலை மதிப்பு

மற்ற பொருத்தங்கள் இல்லாதபோது ஒரு குறியீடு தொகுதியை செயல்படுத்த விரும்பினால், கடைசி case மதிப்பாக அண்டர்ஸ்கோர் எழுத்து _ ஐப் பயன்படுத்தவும்:

எடுத்துக்காட்டு

day = 4

match day:
  case 6:
    print("Today is Saturday")
  case 7:
    print("Today is Sunday")
  case _:
    print("Looking forward to the Weekend")

_ மதிப்பு எப்போதும் பொருந்தும், எனவே அதை இயல்புநிலை வழக்காக செயல்படுத்த கடைசி வழக்காக வைப்பது முக்கியம்.

மதிப்புகளை இணைத்தல்

ஒரு வழக்கில் ஒன்றுக்கு மேற்பட்ட மதிப்பு பொருத்தத்தைச் சரிபார்க்க, case மதிப்பீட்டில் | குழாய் எழுத்தை அல்லது ஆபரேட்டராகப் பயன்படுத்தவும்:

எடுத்துக்காட்டு

day = 4

match day:
  case 1 | 2 | 3 | 4 | 5:
    print("Today is a weekday")
  case 6 | 7:
    print("I love weekends!")

🔗 முக்கிய குறிப்பு:

| ஆபரேட்டர் பல மதிப்புகளை ஒரே case இல் சரிபார்க்க உதவுகிறது, இது குறியீட்டை சுருக்கமாகவும் படிக்க எளிதாகவும் ஆக்குகிறது.

காவலாளிகளாக If அறிக்கைகள்

கூடுதல் நிபந்தனை-சரிபார்ப்பாக case மதிப்பீட்டில் if அறிக்கைகளைச் சேர்க்கலாம்:

எடுத்துக்காட்டு

month = 5
day = 4

match day:
  case 1 | 2 | 3 | 4 | 5 if month == 4:
    print("A weekday in April")
  case 1 | 2 | 3 | 4 | 5 if month == 5:
    print("A weekday in May")
  case _:
    print("No match")

⚠️ எச்சரிக்கை:

match அறிக்கை பைதானின் புதிய அம்சமாக இருப்பதால், பழைய பைதான் பதிப்புகள் (3.10 க்கு முன்) இதை ஆதரிக்காது. உங்கள் பயன்பாடுகள் பல பைதான் பதிப்புகளில் இயங்க வேண்டும் என்றால் கவனமாகப் பயன்படுத்தவும்.

பயிற்சி

உங்கள் அறிவைச் சரிபார்க்க பின்வரும் பயிற்சியை முயற்சிக்கவும்:

❓ மேட்ச் அறிக்கையில் இயல்புநிலை வழக்கு மதிப்பாக எந்த எழுத்தைப் பயன்படுத்தலாம்?

%
✗ தவறு! % என்பது மாடுலோ ஆபரேட்டருக்கு பயன்படுத்தப்படுகிறது
*
✗ தவறு! * என்பது பெருக்கல் ஆபரேட்டருக்கு பயன்படுத்தப்படுகிறது
_
✓ சரி! _ (அண்டர்ஸ்கோர்) மேட்ச் அறிக்கையில் இயல்புநிலை வழக்கு மதிப்பாக பயன்படுத்தப்படுகிறது
|
✗ தவறு! | என்பது பல மதிப்புகளை இணைக்க அல்லது ஆபரேட்டராக பயன்படுத்தப்படுகிறது

Match vs If-elif-else ஒப்பீடு

Match Statement

நன்மைகள்:

  • சுத்தமான தொடரியல்
  • படிக்க எளிதானது
  • வடிவ பொருத்தத்திற்கு ஏற்றது
  • கட்டமைப்பு சிதைவைக் குறைக்கிறது

குறைபாடுகள்:

  • Python 3.10+ மட்டுமே
  • பழைய குறியீட்டுடன் இணக்கமில்லாதது

If-elif-else

நன்மைகள்:

  • அனைத்து பைதான் பதிப்புகளிலும் உள்ளது
  • பரவலாகப் பயன்படுத்தப்படுகிறது
  • மிகவும் நெகிழ்வானது
  • அனைத்து மேம்பாட்டாளர்களுக்கும் தெரிந்தது

குறைபாடுகள்:

  • நீண்ட குறியீடு
  • படிக்க கடினமாக இருக்கலாம்
  • தவறுகள் செய்ய வாய்ப்பு அதிகம்

சிறந்த நடைமுறைகள்

எப்போதும் இயல்புநிலை வழக்கைச் சேர்க்கவும்:

எல்லா சாத்தியமான உள்ளீடுகளையும் கையாள case _: ஐப் பயன்படுத்தவும்

சிக்கலான நிபந்தனைகளுக்கு காவலாளிகளைப் பயன்படுத்தவும்:

கூடுதல் சரிபார்ப்புகளுக்கு if அறிக்கைகளை case உடன் இணைக்கவும்

மிக நீண்ட match தொகுதிகளைத் தவிர்க்கவும்:

10க்கு மேற்பட்ட case அறிக்கைகள் இருந்தால், மாற்று அணுகுமுறைகளைக் கவனியுங்கள்

மதிப்புகளைக் குழுவாக்க | ஆபரேட்டரைப் பயன்படுத்தவும்:

இதே போன்ற செயல்களைச் செய்யும் மதிப்புகளை ஒன்றாக இணைக்கவும்
