Node.js Get Started

Node.js ஐ நிறுவவும் உங்கள் முதல் சேவையகத்தை உருவாக்கவும் கற்றுக்கொள்ளுங்கள்

Node.js ஐப் பதிவிறக்கவும் மற்றும் நிறுவவும்

  • https://nodejs.org க்குச் செல்லவும்
  • LTS (நீண்ட கால ஆதரவு) பதிப்பைப் பதிவிறக்கவும்
  • நிறுவியை இயக்கவும் மற்றும் வழிமுறைகளைப் பின்பற்றவும்

நிறுவலைச் சரிபார்க்கவும்

உங்கள் டெர்மினல்/கட்டளை வரியைத் திறந்து தட்டச்சு செய்யவும்:

கட்டளைகள்

node --version
npm --version

Node.js மற்றும் npm (Node Package Manager) இரண்டிற்கும் பதிப்பு எண்களை நீங்கள் காண வேண்டும்.

பிரச்சினை தீர்த்தல்

கட்டளைகள் வேலை செய்யவில்லை என்றால்:

  • உங்கள் டெர்மினல்/கட்டளை வரியை மீண்டும் தொடங்கவும்
  • நிறுவலின் போது Node.js உங்கள் கணினியின் PATH க்கு சேர்க்கப்பட்டதா என்பதை உறுதிப்படுத்தவும்
  • Windows இல், உங்கள் கணினியை மீண்டும் தொடங்க வேண்டியிருக்கலாம்

தொடங்குவது எப்படி

Node.js ஐ நிறுவிய பிறகு, வலை உலாவியில் "Hello World!" என்று கூறும் உங்கள் முதல் சேவையகத்தை உருவாக்குவோம்.

myfirst.js என்று ஒரு கோப்பை உருவாக்கி இந்த குறியீட்டைச் சேர்க்கவும்:

myfirst.js

let http = require('http');
http.createServer(function (req, res) {
  res.writeHead(200, {'Content-Type': 'text/html'});
  res.end('Hello World!');
}).listen(8080);

கோப்பை உங்கள் கணினியில் சேமிக்கவும், எடுத்துக்காட்டாக: C:\Users\Your Name\myfirst.js

இந்த குறியீடு ஒரு எளிய வலை சேவையகத்தை உருவாக்குகிறது.

யாராவது உங்கள் கணினியை போர்ட் 8080 இல் பார்வையிடும்போது, அது "Hello World!" ஐக் காண்பிக்கும்.

கட்டளை வரி இடைமுகம்

Node.js கோப்புகள் உங்கள் கணினியின் "கட்டளை வரி இடைமுக" நிரலில் தொடங்கப்பட வேண்டும்.

உங்கள் கணினியில் கட்டளை வரி இடைமுகத்தை எவ்வாறு திறப்பது என்பது இயக்க முறைமையைப் பொறுத்தது.

Windows பயனர்களுக்கு, தொடங்க பொத்தானை அழுத்தி "Command Prompt" ஐத் தேடுங்கள், அல்லது தேடல் புலத்தில் வெறுமனே "cmd" என்று எழுதுங்கள்.

"myfirst.js" கோப்பைக் கொண்ட கோப்புறையில் செல்லவும், கட்டளை வரி இடைமுக சாளரம் இப்படி இருக்க வேண்டும்:

C:\Users\Your Name>_

Node.js கோப்பைத் தொடங்கவும்

நீங்கள் இப்போது உருவாக்கிய கோப்பு எந்த நடவடிக்கையும் நடக்கும் முன் Node.js மூலம் தொடங்கப்பட வேண்டும்.

உங்கள் கட்டளை வரி இடைமுகத்தைத் தொடங்கவும், node myfirst.js என்று எழுதி enter ஐ அழுத்தவும்:

"myfirst.js" ஐத் தொடங்கவும்:

C:\Users\Your Name>node myfirst.js

இப்போது, உங்கள் கணினி ஒரு சேவையகமாக வேலை செய்கிறது!

யாராவது உங்கள் கணினியை போர்ட் 8080 இல் அணுக முயற்சித்தால், அவர்களுக்கு "Hello World!" செய்தி கிடைக்கும்!

உங்கள் இணைய உலாவியைத் தொடங்கவும், மற்றும் முகவரியில் தட்டச்சு செய்யவும்: http://localhost:8080

💡 உதவிக்குறிப்பு:

சேவையகத்தை நிறுத்த, கட்டளை வரி இடைமுகத்தில் Ctrl+C ஐ அழுத்தவும். உங்கள் சேவையகம் இயங்கும் வரை உலாவியில் "Hello World!" காண்பிக்கப்படும்.

பயிற்சி

❓ சிறந்த விருப்பத்தைத் தேர்ந்தெடுக்கவும்:

node filename.js
✓ சரி! Node.js கோப்புகளை இயக்க 'node' கட்டளையைப் பயன்படுத்துகிறோம்
npm filename.js
✗ தவறு! npm தொகுப்பு மேலாளர், Node.js கோப்புகளை இயக்க பயன்படுத்தப்படுவதில்லை
run filename.js
✗ தவறு! Node.js கோப்புகளை இயக்க 'run' கட்டளை பயன்படுத்தப்படுவதில்லை
start filename.js
✗ தவறு! Node.js கோப்புகளை இயக்க 'start' கட்டளை நேரடியாக பயன்படுத்தப்படுவதில்லை
