CSS செவிவழி பாணி தாள்கள் மற்றும் பண்புகள்

செவிவழி பாணி தாள்கள்

செவிவழி பாணி தாள்கள் பயனர் தகவலைப் படிக்காமல் கேட்க செய்ய பேச்சு தொகுப்பு மற்றும் ஒலி விளைவுகளின் கலவையைப் பயன்படுத்துகின்றன.

செவிவழி வழங்கல் பயன்படுத்தப்படலாம்:

  • கண்பார்வையற்றவர்களால்
  • படிக்கக் கற்றுக்கொள்ளும் பயனர்களுக்கு உதவ
  • படிப்பு சிக்கல்கள் உள்ள பயனர்களுக்கு உதவ
  • வீட்டு பொழுதுபோக்குக்காக
  • காரில்
  • அச்சிடுதல் குறைபாடுள்ள சமூகங்களால்

செவிவழி வழங்கல் ஆவணத்தை எளிய உரையாக மாற்றி அதை ஒரு திரை வாசிப்பாளருக்கு (திரையில் உள்ள அனைத்து எழுத்துக்களையும் படிக்கும் நிரல்) வழங்குகிறது.

ஒரு செவிவழி பாணி தாளின் எடுத்துக்காட்டு:

@media aural {
    h1, h2, h3, h4 {
        voice-family: male;
        richness: 80;
        cue-before: url("beep.au")
    }
}

மேலே உள்ள எடுத்துக்காட்டு பேச்சு தொகுப்பி ஒரு ஒலியை இயக்கி, பின்னர் தலைப்புகளை மிகவும் செழிப்பான ஆண் குரலில் பேசும்.

CSS செவிவழி பயிற்சி

உங்கள் CSS செவிவழி பண்புகள் அறிவை சோதிக்க இந்த பயிற்சியை முயற்சிக்கவும்.

❓ ஒரு உறுப்பின் உள்ளடக்கத்தைப் பேசுவதற்கு முன் இயக்கப்பட வேண்டிய ஒலியை குறிப்பிட பயன்படுத்தப்படும் சரியான CSS செவிவழி பண்பு எது?

cue-after
✗ தவறு! cue-after என்பது ஒரு உறுப்பின் உள்ளடக்கத்தைப் பேசிய பிறகு இயக்கப்பட வேண்டிய ஒலியை குறிப்பிடுகிறது
