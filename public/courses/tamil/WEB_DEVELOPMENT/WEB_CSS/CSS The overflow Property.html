CSS The overflow Property

CSS overflow பண்பானது ஒரு பகுதியில் பொருந்த முடியாத அளவுக்கு பெரிய உள்ளடக்கத்திற்கு என்ன நடக்கிறது என்பதைக் கட்டுப்படுத்துகிறது.

ஒரு உறுப்பின் உள்ளடக்கம் மிகவும் பெரியதாக இருந்தால் உள்ளடக்கத்தை வெட்டுவதா அல்லது உருளும் பட்டைகளைச் சேர்க்கவா என்பதை இது குறிப்பிடுகிறது.

overflow பண்பு பின்வரும் மதிப்புகளைக் கொண்டுள்ளது:

  • visible - இயல்புநிலை. overflow வெட்டப்படாது. உள்ளடக்கம் உறுப்பின் பெட்டிக்கு வெளியே ரெண்டர் செய்யப்படுகிறது
  • hidden - overflow வெட்டப்படுகிறது, மீதமுள்ள உள்ளடக்கம் மறைக்கப்படுகிறது
  • scroll - உருளும் பட்டைகள் சேர்க்கப்படுகின்றன. அனைத்து உள்ளடக்கத்தையும் காண பயனர் உருள வேண்டும்
  • auto - scroll போன்றது, ஆனால் தேவைப்படும்போது மட்டுமே உருளும் பட்டைகளைச் சேர்க்கிறது

இங்கே, overflow இல் உருளும் பட்டைகள் சேர்க்கப்படுகின்றன:

CSS overflow: visible

இயல்பாக, overflow காண்பிக்கப்படுகிறது, அதாவது அது வெட்டப்படவில்லை மற்றும் உறுப்பின் பெட்டிக்கு வெளியே ரெண்டர் செய்யப்படுகிறது:

overflow: visible (இயல்புநிலை)
நீங்கள் தளவமைப்பை சிறப்பாகக் கட்டுப்படுத்த விரும்பும்போது overflow பண்பைப் பயன்படுத்தலாம். overflow பண்பானது உள்ளடக்கம் ஒரு உறுப்பின் பெட்டியை விஞ்சினால் என்ன நடக்கும் என்பதைக் குறிப்பிடுகிறது.

Example

div {
  width: 200px;
  height: 65px;
  background-color: coral;
  overflow: visible;
}

CSS overflow: hidden

hidden மதிப்புடன், overflow வெட்டப்படுகிறது, மீதமுள்ள உள்ளடக்கம் மறைக்கப்படுகிறது:

overflow: hidden

Example

  overflow: hidden;
}

CSS overflow: scroll

scroll மதிப்புடன், கிடைமட்ட மற்றும் செங்குத்து உருளும் பட்டைகள் எப்போதும் சேர்க்கப்படும். அனைத்து உள்ளடக்கத்தையும் காண பயனர் உருள வேண்டும்:

div {
  overflow: scroll;
}

CSS overflow-x and overflow-y

overflow-x மற்றும் overflow-y பண்புகள் உள்ளடக்கத்தின் overflow ஐ கிடைமட்டமாக அல்லது செங்குத்தாக (அல்லது இரண்டும்) மாற்ற வேண்டுமா என்பதைக் குறிப்பிடுகின்றன:

  • overflow-x உள்ளடக்கத்தின் இடது/வலது விளிம்புகளுடன் என்ன செய்ய வேண்டும் என்பதைக் குறிப்பிடுகிறது.
  • overflow-y உள்ளடக்கத்தின் மேல்/கீழ் விளிம்புகளுடன் என்ன செய்ய வேண்டும் என்பதைக் குறிப்பிடுகிறது.
overflow-x: hidden (கிடைமட்ட உருளும் பட்டை மறைக்கப்பட்டது)

overflow-y: scroll (செங்குத்து உருளும் பட்டை சேர்க்கப்பட்டது)
நீங்கள் தளவமைப்பை சிறப்பாகக் கட்டுப்படுத்த விரும்பும்போது overflow பண்பைப் பயன்படுத்தலாம். overflow பண்பானது உள்ளடக்கம் ஒரு உறுப்பின் பெட்டியை விஞ்சினால் என்ன நடக்கும் என்பதைக் குறிப்பிடுகிறது. overflow-x மற்றும் overflow-y பண்புகள் உள்ளடக்கத்தின் overflow ஐ கிடைமட்டமாக அல்லது செங்குத்தாக (அல்லது இரண்டும்) மாற்ற வேண்டுமா என்பதைக் குறிப்பிடுகின்றன. overflow-x உள்ளடக்கத்தின் இடது/வலது விளிம்புகளுடன் என்ன செய்ய வேண்டும் என்பதைக் குறிப்பிடுகிறது. overflow-y உள்ளடக்கத்தின் மேல்/கீழ் விளிம்புகளுடன் என்ன செய்ய வேண்டும் என்பதைக் குறிப்பிடுகிறது.

Example

div {
  overflow-x: hidden; /* கிடைமட்ட உருளும் பட்டையை மறைக்கவும் */
  overflow-y: scroll; /* செங்குத்து உருளும் பட்டையைச் சேர்க்கவும் */
}

💡 பயனுள்ள உதவிக்குறிப்புகள்:

1. overflow: hidden படங்கள் அல்லது வீடியோக்களை துண்டிக்காமல் வெட்டுவதற்கு பயனுள்ளதாக இருக்கும்
