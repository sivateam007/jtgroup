CSS Font Style

CSS font-style பண்பு ஒரு உரைக்கான எழுத்துரு பாணியை குறிப்பிடுகிறது.

இந்த பண்பு பின்வரும் மதிப்புகளில் ஒன்றைக் கொண்டிருக்கலாம்:

  • normal - உரை சாதாரணமாக காட்டப்படும்
  • italic - உரை சாய்வு எழுத்துகளில் காட்டப்படும்
  • oblique - உரை "சாய்ந்திருக்கும்" (oblique என்பது italic-க்கு மிகவும் ஒத்திருக்கும்)

எடுத்துக்காட்டு

p.normal {
  font-style: normal;
}

p.italic {
  font-style: italic;
}

p.oblique {
  font-style: oblique;
}

CSS Font Weight

CSS font-weight பண்பு உரையில் உள்ள எழுத்துகள் எவ்வளவு தடிமனாக அல்லது மெல்லியதாக காட்டப்பட வேண்டும் என்பதை குறிப்பிடுகிறது.

இந்த பண்பு பின்வரும் மதிப்புகளில் ஒன்றைக் கொண்டிருக்கலாம்:

  • normal - இது இயல்புநிலை. சாதாரண எழுத்துகளை வரையறுக்கிறது
  • bold - தடிமனான எழுத்துகளை வரையறுக்கிறது
  • bolder - மேலும் தடிமனான எழுத்துகளை வரையறுக்கிறது
  • lighter - மெல்லிய எழுத்துகளை வரையறுக்கிறது
  • 100-900 - மெல்லியதிலிருந்து தடிமனான எழுத்துகளை வரையறுக்கிறது. 400 என்பது normal-க்கு சமம், மற்றும் 700 என்பது bold-க்கு சமம்

எடுத்துக்காட்டு

p.normal {
  font-weight: normal;
}

p.light {
  font-weight: lighter;
}

p.thick {
  font-weight: bold;
}

p.thicker {
  font-weight: 900;
}

CSS Font Variant

CSS font-variant பண்பு ஒரு உரை small-caps எழுத்துருவில் காட்டப்பட வேண்டுமா இல்லையா என்பதை குறிப்பிடுகிறது.

ஒரு small-caps எழுத்துருவில், அனைத்து சிறிய எழுத்துகளும் பெரிய எழுத்துகளாக மாற்றப்படுகின்றன. இருப்பினும், மாற்றப்பட்ட பெரிய எழுத்துகள் உரையில் உள்ள அசல் பெரிய எழுத்துகளை விட சிறிய எழுத்துரு அளவில் தோன்றுகின்றன.

எடுத்துக்காட்டு

p.normal {
  font-variant: normal;
}

p.small {
  font-variant: small-caps;
}
