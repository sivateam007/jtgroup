HEX மதிப்பு

ஒரு ஹெக்ஸாடெசிமல் வண்ணம் பின்வருமாறு குறிப்பிடப்படுகிறது: #RRGGBB.

CSS இல், ஒரு வண்ணம் பின்வரும் வடிவத்தில் ஒரு ஹெக்ஸாடெசிமல் மதிப்பைப் பயன்படுத்தி குறிப்பிடப்படலாம்:

#rrggbb

rr (சிவப்பு), gg (பச்சை) மற்றும் bb (நீலம்) ஆகியவை 00 மற்றும் ff க்கு இடையே உள்ள ஹெக்ஸாடெசிமல் மதிப்புகள் (தசம 0-255 போன்றது).

எடுத்துக்காட்டாக, #ff0000 சிவப்பாக காட்டப்படும், ஏனெனில் சிவப்பு அதன் அதிகபட்ச மதிப்பாக அமைக்கப்பட்டுள்ளது (ff) மற்றும் மற்றவை குறைந்தபட்ச மதிப்பாக அமைக்கப்பட்டுள்ளன (00).

கருப்பு காட்ட, அனைத்து மதிப்புகளையும் 00 ஆக அமைக்கவும், இப்படி: #000000.

வெள்ளை காட்ட, அனைத்து மதிப்புகளையும் ff ஆக அமைக்கவும், இப்படி: #ffffff.

3 இலக்க HEX மதிப்பு

சில நேரங்களில் CSS மூலத்தில் 3-இலக்க ஹெக்ஸ் குறியீட்டைக் காண்பீர்கள்.

3-இலக்க ஹெக்ஸ் குறியீடு சில 6-இலக்க ஹெக்ஸ் குறியீடுகளுக்கான குறுக்குவழி ஆகும்.

3-இலக்க ஹெக்ஸ் குறியீட்டில் பின்வரும் வடிவம் உள்ளது:

#rgb

இங்கு r, g, மற்றும் b ஆகியவை 0 மற்றும் f க்கு இடையே உள்ள மதிப்புகளுடன் சிவப்பு, பச்சை மற்றும் நீலம் கூறுகளைக் குறிக்கின்றன.

3-இலக்க ஹெக்ஸ் குறியீட்டை ஒவ்வொரு கூறுக்கும் இரண்டு மதிப்புகளும் (RR, GG, மற்றும் BB) ஒரே மாதிரியாக இருக்கும்போது மட்டுமே பயன்படுத்த முடியும். எனவே, எங்களிடம் #ff00cc இருந்தால், அதை இப்படி எழுதலாம்: #f0c.

இங்கே ஒரு எடுத்துக்காட்டு:

body {
  background-color: #fc9; /* same as #ffcc99 */
}

h1 {
  color: #f0f; /* same as #ff00ff */
}

p {
  color: #b58; /* same as #bb5588 */
}
