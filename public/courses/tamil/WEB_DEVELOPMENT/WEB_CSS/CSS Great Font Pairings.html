சிறந்த எழுத்துரு இணைவு விதிகள்

சிறந்த எழுத்துரு இணைவுகள் சிறந்த வடிவமைப்பிற்கு அத்தியாவசியமானவை!

🎨 வடிவமைப்பு குறிப்பு:

சிறந்த எழுத்துரு இணைவுகள் வாசிப்புத்திறனை மேம்படுத்துகின்றன, காட்சி படிநிலையை நிறுவுகின்றன மற்றும் பயனர்களுடன் உணர்ச்சிபூர்வமான தொடர்புகளை உருவாக்குகின்றன.

எழுத்துரு இணைவு அடிப்படை விதிகள்

1. நிரப்புதல்: ஒன்றையொன்று நிரப்பும் எழுத்துரு இணைவுகளைக் கண்டறிவது எப்போதும் பாதுகாப்பானது. ஒரு சிறந்த எழுத்துரு சேர்க்கை இசைவுபட வேண்டும், மிகவும் ஒத்ததாகவோ அல்லது மிகவும் வித்தியாசமாகவோ இருக்கக்கூடாது.
2. எழுத்துரு சூப்பர்ஃபேமிலிகளைப் பயன்படுத்துங்கள்: ஒரு எழுத்துரு சூப்பர்ஃபேமிலி என்பது நன்றாக வேலை செய்ய வடிவமைக்கப்பட்ட எழுத்துருக்களின் தொகுப்பாகும். எனவே, ஒரே சூப்பர்ஃபேமிலியில் உள்ள வெவ்வேறு எழுத்துருக்களைப் பயன்படுத்துவது பாதுகாப்பானது.
3. முரண்பாடு முக்கியம்: இரண்டு எழுத்துருக்கள் மிகவும் ஒத்திருந்தால் பெரும்பாலும் முரண்படும். இருப்பினும், சரியான முறையில் செய்யப்படும் முரண்பாடுகள் ஒவ்வொரு எழுத்துருவின் சிறந்ததை வெளிக்கொணர்கின்றன.
4. ஒரே ஒரு முதலாளியை மட்டும் தேர்ந்தெடுக்கவும்: ஒரு எழுத்துரு முதலாளியாக இருக்க வேண்டும். இது உங்கள் பக்கத்தில் உள்ள எழுத்துருக்களுக்கு ஒரு படிநிலையை நிறுவுகிறது. இது அளவு, எடை மற்றும் நிறத்தை மாற்றுவதன் மூலம் அடைய முடியும்.

Georgia மற்றும் Verdana

Georgia மற்றும் Verdana ஒரு உன்னதமான இணைப்பாகும். இது வலைப் பாதுகாப்பான எழுத்துரு தரங்களுக்கும் இணங்குகிறது:

எடுத்துக்காட்டு

தலைப்புகளுக்கு "Georgia" எழுத்துருவையும், உரைக்கு "Verdana" எழுத்துருவையும் பயன்படுத்தவும்:

<style>
body {
  font-family: Verdana, sans-serif;
  font-size: 16px;
}

h1 {
  font-family: Georgia, serif;
  font-size: 60px;
}
</style>

Helvetica மற்றும் Garamond

Helvetica மற்றும் Garamond என்பது வலைப் பாதுகாப்பான எழுத்துருக்களைப் பயன்படுத்தும் மற்றொரு உன்னதமான இணைப்பாகும்:

எடுத்துக்காட்டு

தலைப்புகளுக்கு "Helvetica" எழுத்துருவையும், உரைக்கு "Garamond" எழுத்துருவையும் பயன்படுத்தவும்:

<style>
body {
  font-family: Garamond, serif;
  font-size: 16px;
}

h1 {
  font-family: Helvetica, sans-serif;
  font-size: 60px;
}
</style>

பிரபலமான Google எழுத்துரு இணைவுகள்

HTML இல் நிலையான எழுத்துருக்களைப் பயன்படுத்த விரும்பவில்லை என்றால், Google Fonts ஐப் பயன்படுத்தலாம்.

Google Fonts இலவசமாகப் பயன்படுத்தக்கூடியவை மற்றும் 1000 க்கும் மேற்பட்ட எழுத்துருக்களைத் தேர்ந்தெடுக்கலாம்.

Merriweather மற்றும் Open Sans எடுத்துக்காட்டு

<head>
<link rel="stylesheet" 
href="https://fonts.googleapis.com/css?family=Merriweather|Open+Sans">
<style>
body {
  font-family: 'Open Sans', sans-serif;
}

h1, h2, h3 {
  font-family: 'Merriweather', serif;
}
</style>
</head>

📊 காட்சி படிநிலை:

"Georgia" இங்கு முதலாளி என்பதில் சந்தேகம் இல்லை. இது எழுத்துருக்களுக்கு இடையே தெளிவான காட்சி படிநிலையை நிறுவுகிறது, இது அளவு மற்றும் எழுத்துரு வகை மூலம் அடையப்படுகிறது.

❓ எந்த எழுத்துரு இணைப்பு ஒரு உன்னதமான வலைப் பாதுகாப்பான இணைப்பாகக் கருதப்படுகிறது?

Georgia and Verdana
✓ சரி! Georgia மற்றும் Verdana ஒரு உன்னதமான வலைப் பாதுகாப்பான எழுத்துரு இணைப்பாகும், இது அனைத்து இயக்க முறைமைகள் மற்றும் சாதனங்களிலும் கிடைக்கிறது.
Arial and Times New Roman
✗ தவறு! Arial மற்றும் Times New Roman பொதுவாகப் பயன்படுத்தப்படுகின்றன, ஆனால் Georgia/Verdana வலை வடிவமைப்பில் மிகவும் பிரபலமான உன்னதமான இணைப்பாகக் கருதப்படுகிறது.
Comic Sans and Papyrus
✗ தவறு! Comic Sans மற்றும் Papyrus பொதுவாக தரமற்ற மற்றும் தொழில்முறை அல்லாத வடிவமைப்புகளுக்குப் பயன்படுத்தப்படுகின்றன, வலைப் பாதுகாப்பான உன்னதமான இணைப்புகள் அல்ல.
Courier New and Impact
✗ தவறு! Courier New மற்றும் Impact பொதுவாக சிறப்பு விளைவுகளுக்குப் பயன்படுத்தப்படுகின்றன, ஆனால் முதன்மை உரைக்கான உன்னதமான வலைப் பாதுகாப்பான இணைப்புகள் அல்ல.

எழுத்துரு சூப்பர்ஃபேமிலிகளைப் பற்றி

எடுத்துக்காட்டாக, Lucida சூப்பர்ஃபேமிலியில் பின்வரும் எழுத்துருக்கள் உள்ளன: Lucida Sans, Lucida Serif, Lucida Typewriter Sans, Lucida Typewriter Serif மற்றும் Lucida Math.

ஒரு வலுவான சூப்பர்ஃபேமிலியில் ஒரே எழுத்துருவின் serif மற்றும் sans serif வகைகள் இரண்டும் அடங்கும் (எ.கா. Lucida மற்றும் Lucida Sans).

⚖️ முரண்பாடு பற்றிய குறிப்பு:
