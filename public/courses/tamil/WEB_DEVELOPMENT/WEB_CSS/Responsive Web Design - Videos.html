பதிலளிக்கும் வீடியோக்கள்

Using The width Property

width பண்புத்தொகுப்பு 100% என அமைக்கப்பட்டால், வீடியோ படப்பிடிப்பு பதிலளிக்கும் மற்றும் மேலும் கீழும் அளவிடும்:

Example

video {
  width: 100%;
  height: auto;
}

மேலே உள்ள எடுத்துக்காட்டில், வீடியோ படப்பிடிப்பு அதன் அசல் அளவை விட பெரியதாக அளவிடப்படலாம் என்பதைக் கவனியுங்கள். பல சந்தர்ப்பங்களில், max-width பண்புத்தொகுப்பைப் பயன்படுத்துவது சிறந்த தீர்வாக இருக்கும்.

Using The max-width Property

max-width பண்புத்தொகுப்பு 100% என அமைக்கப்பட்டால், வீடியோ படப்பிடிப்பு தேவைப்பட்டால் குறைக்கப்படும், ஆனால் அதன் அசல் அளவை விட பெரியதாக அளவிடப்படாது:

Example

video {
  max-width: 100%;
  height: auto;
}

எங்கள் எடுத்துக்காட்டு வலைப்பக்கத்தில் ஒரு வீடியோவைச் சேர்க்க விரும்புகிறோம். வீடியோ எப்போதும் கிடைக்கும் அனைத்து இடத்தையும் எடுக்க மறுஅளவிடப்படும்:

Example

video {
  width: 100%;
  height: auto;
}
