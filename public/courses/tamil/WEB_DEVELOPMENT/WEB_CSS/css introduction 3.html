CSS Introduction

CSS அடிப்படைகளை அறிந்துகொள்ளுங்கள்

CSS என்றால் என்ன?

CSS என்பது வலைப்பக்கத்தை அலங்கரிக்க நாம் பயன்படுத்தும் மொழியாகும்.

  • CSS என்பது Cascading Style Sheets என்ற சொற்றொடரின் சுருக்கமாகும்
  • HTML உறுப்புகள் திரையில், காகிதத்தில் அல்லது பிற ஊடகங்களில் எவ்வாறு காட்சிப்படுத்தப்பட வேண்டும் என CSS விவரிக்கிறது
  • CSS நிறைய வேலையை சேமிக்கிறது. இது ஒரே நேரத்தில் பல வலைப்பக்கங்களின் தளவமைப்பை கட்டுப்படுத்த முடியும்
  • வெளிப்புற ஸ்டைல் ஷீட்டுகள் CSS கோப்புகளில் சேமிக்கப்படுகின்றன

CSS டெமோ - ஒரு HTML பக்கம் - பல்வேறு ஸ்டைல்கள்!

இங்கே நான்கு வெவ்வேறு ஸ்டைல் ஷீட்டுகளுடன் காட்டப்படும் ஒரு HTML பக்கத்தைக் காண்பிப்போம். வெவ்வேறு ஸ்டைல்களைக் காண "Stylesheet 1", "Stylesheet 2", "Stylesheet 3", "Stylesheet 4" இணைப்புகளைக் கிளிக் செய்யவும்:

CSS டெமோ பக்கம்

இது CSS இன் சக்தியை நிரூபிக்கும் ஒரு டெமோ பக்கமாகும். மேலே உள்ள பொத்தான்களைக் கிளிக் செய்து, ஒரே உள்ளடக்கத்திற்கு வெவ்வேறு வடிவமைப்புகள் எவ்வாறு பயன்படுத்தப்படலாம் என்பதைக் கவனியுங்கள்.

CSS இன் நன்மைகள்

  • வெவ்வேறு சாதனங்களுக்கு ஏற்ப வடிவமைப்பை மாற்றலாம்
  • பல பக்கங்களின் தோற்றத்தை ஒரே கோப்பில் கட்டுப்படுத்தலாம்
  • வலைப்பக்கத்தின் வாசிப்புத்தன்மையை மேம்படுத்துகிறது
  • வேகமான பக்க ஏற்ற நேரம்

💡 குறிப்பு:

CSS இல்லாமல், வலைப்பக்கங்கள் அனைத்தும் வெறும் உரையாகத் தோன்றும்!

🎨 டெமோ விளக்கம்:

மேலே உள்ள டெமோவில், ஒரே HTML உள்ளடக்கம் வெவ்வேறு CSS ஸ்டைல்களைப் பயன்படுத்தி காட்சிப்படுத்தப்படுகிறது. இது CSS எவ்வாறு உள்ளடக்கத்திலிருந்து வடிவமைப்பைப் பிரிக்கிறது என்பதைக் காட்டுகிறது.

ஏன் CSS பயன்படுத்த வேண்டும்?

CSS உங்கள் வலைப்பக்கங்களுக்கான வடிவமைப்புகளை வரையறுக்க பயன்படுகிறது, இதில் வடிவமைப்பு, தளவமைப்பு மற்றும் வெவ்வேறு சாதனங்கள் மற்றும் திரை அளவுகளுக்கான காட்சி மாறுபாடுகள் அடங்கும்.

வடிவமைப்பு கட்டுப்பாடு

நிறங்கள், எழுத்துருக்கள், இடைவெளிகள் மற்றும் பின்னணிகளை கட்டுப்படுத்தவும்

பதிலளிக்கும் வடிவமைப்பு

வெவ்வேறு சாதனங்களுக்கு தன்னைத் தகவமைத்துக் கொள்ளும் வலைப்பக்கங்களை உருவாக்கவும்

வேகமான வளர்ச்சி

மீண்டும் பயன்படுத்தக்கூடிய ஸ்டைல்களுடன் வேகமாக வலைப்பக்கங்களை உருவாக்கவும்

CSS எடுத்துக்காட்டு

ஒரு அடிப்படை CSS எடுத்துக்காட்டு:

body {
  background-color: lightblue;
}

h1 {
  color: white;
  text-align: center;
}

p {
  font-family: verdana;
  font-size: 20px;
}

📝 CSS தொடரியல்:

CSS தொடரியல் ஒரு தேர்ந்தெடுப்பாளரையும் அதைத் தொடர்ந்து ஒரு அறிவிப்புத் தொகுதியையும் கொண்டுள்ளது. ஒவ்வொரு அறிவிப்பும் ஒரு பண்பு மற்றும் ஒரு மதிப்பைக் கொண்டுள்ளது, காற்புள்ளியால் பிரிக்கப்படுகின்றன.

CSS நிறைய வேலையை சேமிக்கிறது!

CSS வரையறைகள் பொதுவாக வெளிப்புற .css கோப்பில் சேமிக்கப்படுகின்றன.

ஒரு வெளிப்புற ஸ்டைல் ஷீட் கோப்புடன், நீங்கள் ஒரே ஒரு கோப்பை மாற்றியமைப்பதன் மூலம் முழு வலைத்தளத்தின் தோற்றத்தையும் மாற்றலாம்!

ஒருங்கிணைப்பு: ஒரு வலைத்தளம் முழுவதும் சீரான தோற்றத்தை பராமரிக்கவும்
பராமரிப்பு: ஒரு கோப்பை மட்டும் மாற்றியமைப்பதன் மூலம் வலைத்தளத்தை எளிதாக புதுப்பிக்கவும்
செயல்திறன்: கேசிங் மூலம் வேகமான பக்க ஏற்ற நேரங்கள்
பிரிக்கப்பட்ட கவனம்: HTML உள்ளடக்கம் மற்றும் CSS வடிவமைப்பை தனித்தனியாக கையாளவும்

வெளிப்புற CSS கோப்பு

ஒரு வெளிப்புற CSS கோப்பு உரை நீட்டிப்பு ".css" உடன் சேமிக்கப்படுகிறது. இது ஒன்று அல்லது அதற்கு மேற்பட்ட HTML பக்கங்களால் இணைக்கப்படலாம்.

பயிற்சி

❓ CSS ஐ பயன்படுத்துவதன் முக்கிய நன்மை எது?

HTML குறியீட்டை சிக்கலாக்குகிறது
✗ தவறு! CSS உண்மையில் HTML குறியீட்டை எளிமையாக்குகிறது
வலைப்பக்கங்களை மெதுவாக்குகிறது
✗ தவறு! CSS சரியாகப் பயன்படுத்தப்படும் போது வலைப்பக்கங்களை வேகப்படுத்துகிறது
ஒரே நேரத்தில் பல வலைப்பக்கங்களின் தோற்றத்தை கட்டுப்படுத்துகிறது
✓ சரி! CSS நீங்கள் ஒரே ஸ்டைல் ஷீட்டில் மாற்றங்களைச் செய்ய அனுமதிக்கிறது, இது முழு வலைத்தளத்தையும் பாதிக்கிறது
JavaScript ஐ மாற்றுகிறது
✗ தவறு! CSS மற்றும் JavaScript வெவ்வேறு நோக்கங்களுக்காக பயன்படுத்தப்படுகின்றன

ஸ்டைல் ஷீட் விளைவுகள்

CSS வெவ்வேறு வகையான விளைவுகளை வழங்குகிறது:

நிற விளைவுகள்

பின்னணி நிறங்கள், எழுத்து நிறங்கள், சாயல் விளைவுகள் மற்றும் நிற கிரேடியண்டுகள்

எழுத்துரு விளைவுகள்

எழுத்துரு குடும்பங்கள், அளவுகள், எடைகள், வரி உயரங்கள் மற்றும் எழுத்து வடிவங்கள்

வெளிப்புற விளைவுகள்

எல்லைகள், விளிம்புகள், உள்ளீடுகள், நிழல்கள் மற்றும் எல்லை ஆரங்கள்

இடவியல் விளைவுகள்

இடப்பெயர்வுகள், திருப்பங்கள், அளவு மாற்றங்கள், மறைகாட்சிகள் மற்றும் நிலைப்படுத்தல்கள்

/* அனிமேஷன் விளைவு எடுத்துக்காட்டு */
.animated-box {
  animation: bounce 2s infinite;
}

@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-20px); }
}
