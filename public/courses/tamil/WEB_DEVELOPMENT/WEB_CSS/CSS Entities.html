Complete CSS Entity Reference

HTML இல் இவற்றில் ஏதேனும் எழுத்துக்களைக் காண்பிக்க CSS ஐப் பயன்படுத்தினால், கீழே உள்ள அட்டவணையில் காணப்படும் CSS எண்டிட்டியைப் பயன்படுத்தலாம்.

Example

<style>
h2:after {
  content: ' \00A7';
}
</style>

அனைத்து <h2> உறுப்புகளும் இறுதியில் இந்த எழுத்துடன் காண்பிக்கப்படும்:

I will display §

CSS Entities Usage

CSS எண்டிட்டிகளைப் பயன்படுத்தி சிறப்பு எழுத்துக்களைச் சேர்க்கலாம்:

Using CSS content property:
.element:before { content: '\00A9'; /* Copyright symbol */ }

Result: ©

Using CSS in HTML:
<div class="icon">&#x2714;</div> .icon { font-family: 'Arial'; }

Result: ✔

💡 உதவிக்குறிப்பு:

CSS எண்டிட்டிகள் பொதுவாக Unicode ஹெக்ஸாடெசிமல் மதிப்புகளுடன் பயன்படுத்தப்படுகின்றன. எண்டிட்டி மதிப்புக்கு முன் பின்சாய்வு (\) சேர்க்க வேண்டும்.

How to Use CSS Entities

Method 1: In CSS content property

/* Add copyright symbol after element */
.element:after {
  content: '\00A9';
  margin-left: 5px;
}

/* Add arrow before element */
.button:before {
  content: '\2192';
  margin-right: 8px;
}

Method 2: In HTML with CSS

<!-- Using hex code in HTML -->
<span class="icon">&#x2714;</span>

/* CSS for styling */
.icon {
  font-family: 'Arial', sans-serif;
  color: green;
  font-size: 20px;
}

📝 முக்கிய குறிப்புகள்:

1. CSS எண்டிட்டிகள் எப்போதும் பின்சாய்வு (\) உடன் தொடங்குகின்றன

2. ஹெக்ஸாடெசிமல் மதிப்புகள் பயன்படுத்தப்படுகின்றன (உதாரணம்: \00A9)

3. எண்டிட்டிக்குப் பிறகு ஒரு இடம் சேர்க்க வேண்டாம்

4. சில எண்டிட்டிகள் அனைத்து எழுத்துருக்களிலும் ஆதரிக்கப்படுவதில்லை
