CSS Web Safe Fonts

CSS Web Safe Fonts பற்றி கற்றுக்கொள்ளுங்கள்

What are Web Safe Fonts?

Web safe fonts என்பது அனைத்து உலாவிகள் மற்றும் சாதனங்களிலும் உலகளாவியாக நிறுவப்பட்ட எழுத்துருக்கள் ஆகும்.

Fallback Fonts

இருப்பினும், 100% முழுமையான web safe fonts எதுவும் இல்லை. ஒரு எழுத்துரு காணப்படவில்லை அல்லது சரியாக நிறுவப்படவில்லை என்பதற்கான வாய்ப்பு எப்போதும் உள்ளது.

எனவே, எப்போதும் fallback fonts பயன்படுத்துவது மிகவும் முக்கியமானது.

இதன் பொருள் நீங்கள் font-family பண்பில் ஒத்த "பக்கアップ எழுத்துருக்கள்" பட்டியலைச் சேர்க்க வேண்டும். முதல் எழுத்துரு வேலை செய்யாவிட்டால், உலாவி அடுத்த எழுத்துருவை முயற்சிக்கும், பின்னர் அடுத்ததை முயற்சிக்கும், மற்றும் பல. எப்போதும் பொதுவான எழுத்துரு குடும்பப் பெயருடன் பட்டியலை முடிக்கவும்.

எடுத்துக்காட்டு

இங்கே, நாங்கள் மூன்று எழுத்துருக்களை பட்டியலிடுகிறோம்: Tahoma, Verdana, மற்றும் sans-serif. இரண்டாவது மற்றும் மூன்றாவது எழுத்துருக்கள் பக்கアップ எழுத்துருக்கள், முதல் எழுத்துரு கிடைக்காவிட்டால்:

p {
  font-family: Tahoma, Verdana, sans-serif;
}

Web Safe Fonts for HTML and CSS

பின்வரும் பட்டியல் HTML மற்றும் CSS-க்கான சிறந்த web safe fonts ஆகும்:

  • Arial (sans-serif)
  • Verdana (sans-serif)
  • Tahoma (sans-serif)
  • Trebuchet MS (sans-serif)
  • Times New Roman (serif)
  • Georgia (serif)
  • Garamond (serif)
  • Courier New (monospace)
  • Brush Script MT (cursive)

⚠️ குறிப்பு:

உங்கள் வலைத்தளத்தை வெளியிடுவதற்கு முன், எப்போதும் உங்கள் எழுத்துருக்கள் வெவ்வேறு உலாவிகள் மற்றும் சாதனங்களில் எவ்வாறு தோன்றுகின்றன என்பதைச் சரிபார்க்கவும், மற்றும் எப்போதும் fallback fonts பயன்படுத்தவும்!

Arial (sans-serif)

Arial என்பது ஆன்லைன் மற்றும் அச்சிடப்பட்ட ஊடகங்கள் இரண்டிற்கும் மிகவும் பரவலாகப் பயன்படுத்தப்படும் எழுத்துரு ஆகும். Arial என்பது Google Docs-ல் இயல்புநிலை எழுத்துருவாகும்.

Arial என்பது மிகவும் பாதுகாப்பான web fonts-ல் ஒன்றாகும், மற்றும் இது அனைத்து முக்கிய operating systems-ல் கிடைக்கிறது.

Courier New (monospace)

Courier New என்பது மிகவும் பரவலாகப் பயன்படுத்தப்படும் monospace serif எழுத்துரு ஆகும்.
