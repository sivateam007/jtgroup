CSS Text Transformation

CSS text-transform பண்பு ஒரு உறுப்பில் உரையின் மூலதனமாக்கத்தை கட்டுப்படுத்த பயன்படுகிறது.

HTML-ல் உள்ள அசல் உள்ளடக்கத்தை மாற்றாமல், ஒரு உரையை பெரிய எழுத்துகள் அல்லது சிறிய எழுத்துகளாக மாற்றலாம், அல்லது ஒவ்வொரு வார்த்தையின் முதல் எழுத்தை மூலதனமாக்கலாம்.

இந்த பண்பு பின்வரும் மதிப்புகளில் ஒன்றைக் கொண்டிருக்கலாம்:

  • none - மாற்றம் இல்லை. உரை அப்படியே காட்டப்படும்
  • capitalize - ஒவ்வொரு வார்த்தையின் முதல் எழுத்தையும் பெரிய எழுத்தாக மாற்றுகிறது
  • uppercase - அனைத்து எழுத்துகளையும் பெரிய எழுத்துகளாக மாற்றுகிறது
  • lowercase - அனைத்து எழுத்துகளையும் சிறிய எழுத்துகளாக மாற்றுகிறது

எடுத்துக்காட்டு

text-transform பண்பின் நிரூபணம்:

p.uppercase {
  text-transform: uppercase;
}

p.lowercase {
  text-transform: lowercase;
}

p.capitalize {
  text-transform: capitalize;
}
