CSS பால்பேக் எழுத்துருக்களைப் பற்றி அறிந்து கொள்ளுங்கள்

CSS Fallback Fonts

100% முழுமையான வலை பாதுகாப்பான எழுத்துருக்கள் எதுவும் இல்லை. ஒரு எழுத்துரு கிடைக்காது அல்லது சரியாக நிறுவப்படவில்லை என்ற அபாயம் எப்போதும் உள்ளது. எனவே, எப்போதும் பால்பேக் எழுத்துருக்களைப் பயன்படுத்துவது மிகவும் முக்கியமானது.

இதன் பொருள், font-family பண்புகளில் ஒத்த "காப்புப் பிரதி எழுத்துருக்களின்" பட்டியலைச் சேர்க்க வேண்டும். முதல் எழுத்துரு வேலை செய்யாவிட்டால், உலாவி அடுத்ததை முயற்சிக்கும், பின்னர் அடுத்ததை முயற்சிக்கும், இப்படியே தொடரும். எப்போதும் பொதுவான எழுத்துரு குடும்ப பெயருடன் பட்டியலை முடிக்கவும்.
