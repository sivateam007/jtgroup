Jassif Team முக்கிய உதவிக்குறிப்பு:

HTML கருத்துகள் எப்போதும் <!-- உடன் தொடங்கி --> உடன் முடிய வேண்டும். அதிசயக் குறி (!) முக்கியம்!

கருத்துகளுக்கான சிறந்த நடைமுறைகள்

குறிப்பிடத்தக்க குறியீட்டை விளக்கவும்: சிக்கலான தர்க்கங்கள் அல்லது வேலை செய்யாத குறியீட்டை விளக்க கருத்துகளைப் பயன்படுத்தவும்.
பிரிவுகளைக் குறிக்கவும்: உங்கள் HTML கோப்பின் வெவ்வேறு பிரிவுகளைக் குறிக்க கருத்துகளைப் பயன்படுத்தவும்.
தற்காலிக குறியீட்டை மறைக்கவும்: பிழைத்திருத்தம் செய்யும் போது அல்லது மாற்று செயல்பாடுகளை சோதிக்கும் போது குறியீட்டை மறைக்கவும்.
மிகையான கருத்துகளைத் தவிர்க்கவும்: தெளிவான குறியீட்டிற்கு கருத்துகள் தேவையில்லை. தேவையற்ற கருத்துகள் குழப்பத்தை ஏற்படுத்தும்.

Debugging உதவிக்குறிப்பு:

பிழைத்திருத்தம் செய்யும் போது, உங்கள் குறியீட்டின் வெவ்வேறு பகுதிகளை ஒன்றன் பின் ஒன்றாக கருத்து செய்து பிழை எங்குள்ளது என்பதைக் கண்டறியவும். இது பிரச்சனையை குறுகிய நேரத்தில் கண்டறிய உதவும்.
