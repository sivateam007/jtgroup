HTML அட்டவணை - கால்ஸ்பான்

ஒரு கலம் பல நெடுவரிசைகளுக்கு பரவும் வகையில் செய்ய, colspan பண்புக்கூறைப் பயன்படுத்தவும்:

எடுத்துக்காட்டு

<table>
  <tr>
    <th colspan="2">Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>Jill</td>
    <td>Smith</td>
    <td>43</td>
  </tr>
  <tr>
    <td>Eve</td>
    <td>Jackson</td>
    <td>57</td>
  </tr>
</table>
Name Age
Jill Smith 43
Eve Jackson 57

colspan பண்புக்கூறின் மதிப்பு பரவ வேண்டிய நெடுவரிசைகளின் எண்ணிக்கையைக் குறிக்கிறது.

HTML அட்டவணை - ரோஸ்பான்

எடுத்துக்காட்டு

<table>
  <tr>
    <th>Name</th>
    <td>Jill</td>
  </tr>
  <tr>
    <th rowspan="2">Phone</th>
    <td>555-1234</td>
  </tr>
  <tr>
    <td>555-8745</td>
  </tr>
</table>
