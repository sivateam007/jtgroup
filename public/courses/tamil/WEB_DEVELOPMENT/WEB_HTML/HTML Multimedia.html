மல்டிமீடியா என்றால் என்ன?

மல்டிமீடியா பல்வேறு வடிவங்களில் வருகிறது. இது நீங்கள் கேட்கக்கூடிய அல்லது பார்க்கக்கூடிய எதுவும் இருக்கலாம், படங்கள், இசை, ஒலி, வீடியோக்கள், பதிவுகள், திரைப்படங்கள், அனிமேஷன்கள் மற்றும் பல.

🌐 வலைப்பக்கங்கள்:

வலைப்பக்கங்கள் பெரும்பாலும் வெவ்வேறு வகைகள் மற்றும் வடிவங்களின் மல்டிமீடியா உறுப்புகளைக் கொண்டிருக்கின்றன.

உலாவி ஆதரவு

ஆரம்ப உலாவிகள்

முதல் வலை உலாவிகளுக்கு உரை மட்டுமே ஆதரவு இருந்தது, ஒரு நிறத்தில் ஒரு எழுத்துருக்கு மட்டுப்படுத்தப்பட்டது.

நிறங்கள் மற்றும் எழுத்துருக்கள்

பின்னர் நிறங்கள், எழுத்துருக்கள் மற்றும் படங்களை ஆதரிக்கும் உலாவிகள் வந்தன!

மல்டிமீடியா ஆதரவு

இன்று, நவீன உலாவிகள் மல்டிமீடியா உறுப்புகளை முழுமையாக ஆதரிக்கின்றன!

நவீன உலாவிகள் வீடியோ, ஆடியோ மற்றும் அனிமேஷன்களை ஆதரிக்கின்றன

மல்டிமீடியா வடிவங்கள்

மல்டிமீடியா உறுப்புகள் (ஆடியோ அல்லது வீடியோ போன்றவை) ஊடகக் கோப்புகளில் சேமிக்கப்படுகின்றன.

ஒரு கோப்பின் வகையைக் கண்டறிய மிகவும் பொதுவான வழி, கோப்பு நீட்டிப்பைப் பார்ப்பதாகும்.

மல்டிமீடியா கோப்புகளுக்கு வடிவங்கள் மற்றும் வெவ்வேறு நீட்டிப்புகள் உள்ளன: .wav, .mp3, .mp4, .mpg, .wmv, மற்றும் .avi.

பொதுவான வீடியோ வடிவங்கள்

வெளியே பல வீடியோ வடிவங்கள் உள்ளன.

MP4, WebM, மற்றும் Ogg வடிவங்கள் HTML ஆல் ஆதரிக்கப்படுகின்றன.

MP4 வடிவம் YouTube ஆல் பரிந்துரைக்கப்படுகிறது.

வடிவம் கோப்பு விளக்கம் HTML ஆதரவு
MPEG .mpg .mpeg Moving Pictures Expert Group ஆல் உருவாக்கப்பட்டது. வலைத்தளத்தில் முதல் பிரபல வீடியோ வடிவம். ஆதரவு இல்லை
AVI .avi Microsoft ஆல் உருவாக்கப்பட்டது. வீடியோ கேமராக்கள் மற்றும் TV வன்பொருளில் பொதுவாகப் பயன்படுத்தப்படுகிறது. ஆதரவு இல்லை
WMV .wmv Microsoft ஆல் உருவாக்கப்பட்டது. வீடியோ கேமராக்கள் மற்றும் TV வன்பொருளில் பொதுவாகப் பயன்படுத்தப்படுகிறது. ஆதரவு இல்லை
QuickTime .mov Apple ஆல் உருவாக்கப்பட்டது. வீடியோ கேமராக்கள் மற்றும் TV வன்பொருளில் பொதுவாகப் பயன்படுத்தப்படுகிறது. ஆதரவு இல்லை
Flash .swf .flv Macromedia ஆல் உருவாக்கப்பட்டது. வலை உலாவிகளில் விளையாட கூடுதல் கூறு (பிளக்-இன்) தேவைப்படும். ஆதரவு இல்லை
Ogg .ogg Xiph.Org Foundation ஆல் உருவாக்கப்பட்டது. ஆதரவு உள்ளது
WebM .webm Mozilla, Opera, Adobe, மற்றும் Google ஆல் உருவாக்கப்பட்டது. ஆதரவு உள்ளது
MPEG-4 / MP4 .mp4 Moving Pictures Expert Group ஆல் உருவாக்கப்பட்டது. அனைத்து உலாவிகளாலும் ஆதரிக்கப்படுகிறது மற்றும் YouTube ஆல் பரிந்துரைக்கப்படுகிறது. ஆதரவு உள்ளது

📝 குறிப்பு:

MP4, WebM, மற்றும் Ogg வீடியோ மட்டுமே HTML தரநிலையால் ஆதரிக்கப்படுகின்றன.

பொதுவான ஆடியோ வடிவங்கள்

MP3 என்பது சுருக்கப்பட்ட பதிவு செய்யப்பட்ட இசைக்கான சிறந்த வடிவமாகும். MP3 என்ற சொல் டிஜிட்டல் இசையின் ஒத்ததாக மாறியுள்ளது.

உங்கள் வலைத்தளம் பதிவு செய்யப்பட்ட இசையைப் பற்றியதாக இருந்தால், MP3 தேர்வாகும்.

வடிவம் கோப்பு விளக்கம் HTML ஆதரவு
MIDI .mid .midi அனைத்து மின்னணு இசை சாதனங்களுக்கான முக்கிய வடிவம். MIDI கோப்புகள் ஒலியைக் கொண்டிருக்கவில்லை, ஆனால் மின்னணுவால் வாசிக்கக்கூடிய டிஜிட்டல் குறிப்புகளைக் கொண்டுள்ளன. ஆதரவு இல்லை
WMA .wma Microsoft ஆல் உருவாக்கப்பட்டது. Windows கணினிகளில் நன்றாக விளையாடுகிறது. ஆதரவு இல்லை
AAC .aac Apple ஆல் iTunes க்கான இயல்புநிலை வடிவமாக உருவாக்கப்பட்டது. ஆதரவு இல்லை
WAV .wav IBM மற்றும் Microsoft ஆல் உருவாக்கப்பட்டது. ஆதரவு உள்ளது
Ogg .ogg Xiph.Org Foundation ஆல் உருவாக்கப்பட்டது. ஆதரவு உள்ளது
MP3 .mp3 இசை பிளேயர்களுக்கான மிகவும் பிரபலமான வடிவம். நல்ல சுருக்கத்தை (சிறிய கோப்புகள்) உயர் தரத்துடன் இணைக்கிறது. ஆதரவு உள்ளது
MP4 .mp4 MP4 ஒரு வீடியோ வடிவம், ஆனால் ஆடியோவிற்கும் பயன்படுத்தலாம். ஆதரவு உள்ளது

📝 குறிப்பு:

MP3, WAV, மற்றும் Ogg ஆடியோ மட்டுமே HTML தரநிலையால் ஆதரிக்கப்படுகின்றன.

🎵 MP3 பற்றி:

MP3 கோப்புகள் உண்மையில் MPEG கோப்புகளின் ஒலி பகுதியாகும். MP3 என்பது இசை பிளேயர்களுக்கான மிகவும் பிரபலமான வடிவமாகும். நல்ல சுருக்கத்தை (சிறிய கோப்புகள்) உயர் தரத்துடன் இணைக்கிறது. அனைத்து உலாவிகளாலும் ஆதரிக்கப்படுகிறது.
