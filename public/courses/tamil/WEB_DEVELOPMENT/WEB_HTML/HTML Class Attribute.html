HTML class Attribute

HTML class பண்புக்கூறைக் கற்றுக்கொள்ளுங்கள்

HTML class Attribute

HTML class பண்புக்கூறு ஒரு HTML உறுப்புக்கான வகுப்பைக் குறிப்பிட பயன்படுகிறது.

பல HTML உறுப்புகள் ஒரே வகுப்பைப் பகிர்ந்து கொள்ளலாம்.

🎯 class பண்புக்கூறு:

class பண்புக்கூறு பெரும்பாலும் ஒரு பாணித் தாளில் உள்ள வகுப்புப் பெயரைச் சுட்டிக்காட்ட பயன்படுகிறது. குறிப்பிட்ட வகுப்புப் பெயருடன் உறுப்புகளை அணுகவும் கையாளவும் JavaScript மூலமும் பயன்படுத்தப்படலாம்.

class பண்புக்கூறு - எடுத்துக்காட்டுகள்

பின்வரும் எடுத்துக்காட்டில் "city" என்ற மதிப்புடன் class பண்புக்கூறுடன் மூன்று <div> உறுப்புகள் உள்ளன. மூன்று <div> உறுப்புகளும் head பிரிவில் உள்ள .city பாணி வரையறைக்கு ஏற்ப சமமாகப் பாணியிடப்படும்:

Example

<!DOCTYPE html>
<html>
<head>
<style>
.city {
  background-color: tomato;
  color: white;
  border: 2px solid black;
  margin: 20px;
  padding: 20px;
}
</style>
</head>
<body>

<div class="city">
  <h2>London</h2>
  <p>London is the capital of England.</p>
</div>

<div class="city">
  <h2>Paris</h2>
  <p>Paris is the capital of France.</p>
</div>

<div class="city">
  <h2>Tokyo</h2>
  <p>Tokyo is the capital of Japan.</p>
</div>

</body>
</html>

💡 முடிவு:

London

London is the capital of England.

Paris

Paris is the capital of France.

Tokyo

Tokyo is the capital of Japan.

பின்வரும் எடுத்துக்காட்டில் "note" என்ற மதிப்புடன் class பண்புக்கூறுடன் இரண்டு <span> உறுப்புகள் உள்ளன. இரண்டு <span> உறுப்புகளும் head பிரிவில் உள்ள .note பாணி வரையறைக்கு ஏற்ப சமமாகப் பாணியிடப்படும்:

Example

<!DOCTYPE html>
<html>
<head>
<style>
.note {
  font-size: 120%;
  color: red;
}
</style>
</head>
<body>

<h1>My <span class="note">Important</span> Heading</h1>
<p>This is some <span class="note">important</span> text.</p>

</body>
</html>

💡 முடிவு:

My Important Heading

This is some important text.

⚠️ குறிப்பு:

வகுப்புப் பெயர் வழக்கு உணர்திறன் கொண்டது!

class="city" மற்றும் class="City" வெவ்வேறு வகுப்புகளாகக் கருதப்படுகின்றன!

Class க்கான தொடரியல்

ஒரு வகுப்பை உருவாக்க; ஒரு காலம் (.) எழுத்தை எழுதவும், அதைத் தொடர்ந்து ஒரு வகுப்புப் பெயர். பின்னர், சுருள் அடைப்புக்குள் {} CSS பண்புகளை வரையறுக்கவும்:

Example

<!DOCTYPE html>
<html>
<head>
<style>
.city {
  background-color: tomato;
  color: white;
  padding: 10px;
}
</style>
</head>
<body>

<h2 class="city">London</h2>
<p>London is the capital of England.</p>

<h2 class="city">Paris</h2>
<p>Paris is the capital of France.</p>

<h2 class="city">Tokyo</h2>
<p>Tokyo is the capital of Japan.</p>

</body>
</html>

📝 உதவிக்குறிப்பு:

class பண்புக்கூறு எந்த HTML உறுப்பிலும் பயன்படுத்தப்படலாம்.

பல வகுப்புகள்

HTML உறுப்புகள் ஒன்றுக்கு மேற்பட்ட வகுப்புகளுக்குச் சொந்தமானதாக இருக்கலாம்.

பல வகுப்புகளை வரையறுக்க, வகுப்புப் பெயர்களை ஒரு இடைவெளியுடன் பிரிக்கவும், எ.கா. <div class="city main">. உறுப்பு குறிப்பிடப்பட்ட அனைத்து வகுப்புகளுக்கும் ஏற்ப பாணியிடப்படும்.

பின்வரும் எடுத்துக்காட்டில், முதல் <h2> உறுப்பு city வகுப்பு மற்றும் main வகுப்பு இரண்டிற்கும் சொந்தமானது, மேலும் இரண்டு வகுப்புகளிலிருந்தும் CSS பாணிகளைப் பெறும்:

Example

<h2 class="city main">London</h2>
<h2 class="city">Paris</h2>
<h2 class="city">Tokyo</h2>

💡 முடிவு:

London

Paris

Tokyo

வெவ்வேறு உறுப்புகள் ஒரே வகுப்பைப் பகிர்ந்து கொள்ளலாம்

வெவ்வேறு HTML உறுப்புகள் ஒரே வகுப்புப் பெயரைச் சுட்டிக்காட்டலாம்.

பின்வரும் எடுத்துக்காட்டில், <h2> மற்றும் <p> இரண்டும் "city" வகுப்பைச் சுட்டிக்காட்டுகின்றன மேலும் ஒரே பாணியைப் பகிர்ந்து கொள்ளும்:

Example

<h2 class="city">Paris</h2>
<p class="city">Paris is the capital of France</p>

💡 முடிவு:

Paris

Paris is the capital of France

JavaScript இல் class பண்புக்கூறின் பயன்பாடு

வகுப்புப் பெயரைக் குறிப்பிட்ட உறுப்புகளுக்கு சில பணிகளைச் செய்ய JavaScript மூலமும் பயன்படுத்தலாம்.

JavaScript குறிப்பிட்ட வகுப்புப் பெயருடன் உறுப்புகளை getElementsByClassName() முறையுடன் அணுகலாம்:

Example

<script>
function myFunction() {
  var x = document.getElementsByClassName("city");
  for (var i = 0; i < x.length; i++) {
    x[i].style.display = "none";
  }
}
</script>

ℹ️ தகவல்:

மேலே உள்ள எடுத்துக்காட்டில் உள்ள குறியீட்டை நீங்கள் புரிந்து கொள்ளவில்லை என்றால் கவலைப்பட வேண்டாம்.

எங்கள் HTML JavaScript அத்தியாயத்தில் JavaScript பற்றி மேலும் அறியலாம், அல்லது எங்கள் JavaScript டுடோரியலைப் படிக்கலாம்.

  • குறிப்பிட்ட உறுப்புகளைத் தேர்ந்தெடுக்கவும் அணுகவும் CSS மற்றும் JavaScript மூலம் வகுப்புகள் பயன்படுத்தப்படுகின்றன

  • JavaScript குறிப்பிட்ட வகுப்புப் பெயருடன் உறுப்புகளை getElementsByClassName() முறையுடன் அணுகலாம்
