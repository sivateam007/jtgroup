HTML RGB and RGBA Colors

ஒரு RGB வண்ண மதிப்பு RED, GREEN, மற்றும் BLUE ஒளி மூலங்களைக் குறிக்கிறது.

ஒரு RGBA வண்ண மதிப்பு என்பது ஆல்பா சேனலுடன் (வெளிப்படைத்தன்மை) RGB இன் நீட்டிப்பாகும்.

RGB Colors
Red + Green + Blue
RGBA Colors
RGB + Alpha (Opacity)

RGB Color Values

HTML இல், ஒரு வண்ணத்தை பின்வரும் சூத்திரத்தைப் பயன்படுத்தி RGB மதிப்பாக குறிப்பிடலாம்:

rgb(red, green, blue)

RGB கலவை சோதனை

கீழே உள்ள RGB மதிப்புகளை கலந்து சோதனை செய்யுங்கள்:

rgb(255, 99, 71)
RED 255
GREEN 99
BLUE 71

sk சோதனை:

சிலிண்டர்களை நகர்த்துவதன் மூலம் வெவ்வேறு வண்ணங்களை உருவாக்க முயற்சிக்கவும். 0 முதல் 255 வரையிலான மதிப்புகள் ஒவ்வொரு வண்ணத்தின் செறிவையும் கட்டுப்படுத்துகின்றன.

சாம்பல் நிறத்தின் நிழல்கள்

சாம்பல் நிறத்தின் நிழல்கள் பெரும்பாலும் மூன்று அளவுருக்களுக்கும் சமமான மதிப்புகளைப் பயன்படுத்தி வரையறுக்கப்படுகின்றன:

rgb(60, 60, 60)
rgb(100, 100, 100)
rgb(140, 140, 140)
rgb(180, 180, 180)
rgb(200, 200, 200)
rgb(240, 240, 240)

sk விதி:

சாம்பல் நிறங்களுக்கு சிவப்பு, பச்சை மற்றும் நீலம் அனைத்தும் ஒரே மதிப்பைக் கொண்டிருக்க வேண்டும். மதிப்பு குறைவாக இருந்தால் கருப்பு நிறத்திற்கு அருகில், அதிகமாக இருந்தால் வெள்ளை நிறத்திற்கு அருகில்.

RGBA Color Values

RGBA வண்ண மதிப்புகள் ஆல்பா சேனலுடன் RGB வண்ண மதிப்புகளின் நீட்டிப்பாகும் - இது ஒரு வண்ணத்திற்கான வெளிப்படைத்தன்மையை குறிப்பிடுகிறது.

ஒரு RGBA வண்ண மதிப்பு இவ்வாறு குறிப்பிடப்படுகிறது:

rgba(red, green, blue, alpha)

ஆல்பா அளவுரு 0.0 (முழுமையாக வெளிப்படையானது) மற்றும் 1.0 (வெளிப்படையானது அல்ல) க்கு இடையே உள்ள ஒரு எண்ணாகும்:

rgba(255, 99, 71, 0)
முழு வெளிப்படைத்தன்மை
rgba(255, 99, 71, 0.2)
rgba(255, 99, 71, 0.4)
rgba(255, 99, 71, 0.6)
rgba(255, 99, 71, 0.8)
rgba(255, 99, 71, 1)
வெளிப்படைத்தன்மை இல்லை

RGBA கலவை சோதனை

கீழே உள்ள RGBA மதிப்புகளை கலந்து சோதனை செய்யுங்கள்:

rgba(255, 99, 71, 0.5)
RED 255
GREEN 99
BLUE 71
ALPHA 0.5

sk வெளிப்படைத்தன்மை:

ஆல்பா மதிப்பு 0.0 என்பது முழுமையாக வெளிப்படையானது (கண்ணுக்குப் புலப்படாதது), 0.5 என்பது 50% வெளிப்படைத்தன்மை, 1.0 என்பது வெளிப்படைத்தன்மை இல்லை (முழுமையானது).

sk RGB குறிப்பு:

rgb(0, 0, 0) = கருப்பு (எல்லா வண்ணங்களும் 0)
rgb(255, 0, 0) = சிவப்பு (சிவப்பு அதிகபட்சம் 255, பச்சை மற்றும் நீலம் 0)
rgb(0, 255, 0) = பச்சை (பச்சை அதிகபட்சம் 255, சிவப்பு மற்றும் நீலம் 0)
rgb(0, 0, 255) = நீலம் (நீலம் அதிகபட்சம் 255, சிவப்பு மற்றும் பச்சை 0)

RGB vs RGBA ஒப்பீடு

அம்சம் RGB RGBA
முழுப் பெயர் Red Green Blue Red Green Blue Alpha
சூத்திரம் rgb(r, g, b) rgba(r, g, b, a)
மதிப்பு வரம்பு 0-255 (மூன்றும்) 0-255 (r,g,b), 0.0-1.0 (a)
வெளிப்படைத்தன்மை இல்லை (முழுமையானது) ஆம் (0.0-1.0)
பயன்பாடு திட வண்ணங்கள் வெளிப்படையான வண்ணங்கள்
எடுத்துக்காட்டு rgb(255, 99, 71) rgba(255, 99, 71, 0.5)
