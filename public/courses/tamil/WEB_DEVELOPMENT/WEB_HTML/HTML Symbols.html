HTML Symbols

HTML சின்னங்கள் மற்றும் சிறப்பு எழுத்துகளைக் கற்றுக்கொள்ளுங்கள்

HTML Symbol Entities

உங்கள் விசைப்பலகையில் இல்லாத சின்னங்கள் அல்லது எழுத்துக்களை HTML இல் நிறுவனங்களைப் பயன்படுத்தி சேர்க்கலாம்.

அத்தகைய சின்னங்களை HTML பக்கத்தில் சேர்க்க, நிறுவனப் பெயர் அல்லது நிறுவன எண்ணை (தசம அல்லது ஹெக்ஸாடெசிமல் குறிப்பு) பயன்படுத்தலாம்:

Example

யூரோ அடையாளத்தைக் காண்பிக்கவும்:

<p>I will display &euro;</p>
<p>I will display &#8364;</p>
<p>I will display &#x20AC;</p>

இவ்வாறு காட்சிப்படுத்தப்படும்:

I will display €

I will display €

I will display €

Char Number Entity Description
© &#169; &copy; பதிப்புரிமை
® &#174; &reg; பதிவுசெய்யப்பட்ட வர்த்தக முத்திரை
€ &#8364; &euro; யூரோ அடையாளம்
™ &#8482; &trade; வர்த்தக முத்திரை
← &#8592; &larr; இடது அம்பு
↑ &#8593; &uarr; மேல் அம்பு
→ &#8594; &rarr; வலது அம்பு
↓ &#8595; &darr; கீழ் அம்பு
♠ &#9824; &spades; சீட்டுக்கட்டில் சூட்டு
♣ &#9827; &clubs; சீட்டுக்கட்டில் கிளப்
♥ &#9829; &hearts; சீட்டுக்கட்டில் ஹார்ட்
♦ &#9830; &diams; சீட்டுக்கட்டில் டயமண்ட்

மேலும் அறிக:

  • முழு நாணயக் குறிப்பு
  • முழு அம்புகள் குறிப்பு
  • முழு சின்னங்கள் குறிப்பு
