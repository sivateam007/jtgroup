எச்சரிக்கை!

தரவுத்தளத்தை நீக்குவதற்கு முன் கவனமாக இருங்கள். ஒரு தரவுத்தளத்தை நீக்குவது தரவுத்தளத்தில் சேமிக்கப்பட்டுள்ள முழு தகவலையும் இழப்பதற்கு வழிவகுக்கும்!

SQL DROP DATABASE அறிக்கை

DROP DATABASE அறிக்கை ஏற்கனவே உள்ள SQL தரவுத்தளத்தை நீக்க பயன்படுகிறது.

தரவுத்தள நீக்கம் பணிப்பாய்வு

தரவுத்தளம் நீக்கப்பட்டது

DROP DATABASE தொடரியல்

DROP DATABASE databasename;

💡 உதவிக்குறிப்பு:

எந்த தரவுத்தளத்தையும் நீக்குவதற்கு முன்பு உங்களுக்கு நிர்வாக அனுமதி உள்ளது என்பதை உறுதிப்படுத்திக் கொள்ளுங்கள். ஒரு தரவுத்தளம் நீக்கப்பட்ட பிறகு, பின்வரும் SQL கட்டளையுடன் தரவுத்தளங்களின் பட்டியலில் அது இல்லை என்பதைச் சரிபார்க்கலாம்: SHOW DATABASES;

DROP DATABASE எடுத்துக்காட்டு

பின்வரும் SQL அறிக்கை ஏற்கனவே உள்ள "testDB" தரவுத்தளத்தை நீக்குகிறது:

எடுத்துக்காட்டு

DROP DATABASE testDB;

தற்காலிக தரவுத்தளம்

சோதனை அல்லது மேம்பாட்டு தரவுத்தளங்களை நீக்குதல்

DROP DATABASE TempTestDB;

பழைய தரவுத்தளம்

காலாவதியான தரவுத்தளங்களை நீக்குதல்

DROP DATABASE OldBackupDB;

மறுசீரமைப்பு

மறுசீரமைப்புக்கு முன் தரவுத்தளங்களை நீக்குதல்

DROP DATABASE DevelopmentDB;

வெவ்வேறு தரவுத்தள அமைப்புகள்

பாதுகாப்பு நடவடிக்கைகள்

காப்புப்பிரதி

நீக்குவதற்கு முன் எப்போதும் காப்புப்பிரதி எடுக்கவும்

-- Always backup first
BACKUP DATABASE CompanyDB 
TO DISK = 'C:\backup\CompanyDB.bak';

இரட்டை சரிபார்ப்பு

தரவுத்தளப் பெயரை இரண்டு முறை சரிபார்க்கவும்

-- Verify database name
SELECT name FROM sys.databases 
WHERE name = 'CompanyDB';

அனுமதிகள்

நீக்குவதற்கு முன் செயலில் உள்ள பயனர்களைச் சரிபார்க்கவும்

-- Check active connections
SELECT * FROM sys.dm_exec_sessions 
WHERE database_id = DB_ID('CompanyDB');
