SQL பயிற்சி

SQL கற்றுக்கொள்ளுங்கள்

SQL என்பது தரவுத்தளங்களில் தரவுகளை சேமிப்பதற்கும், கையாள்வதற்கும், மீட்டெடுப்பதற்கும் பயன்படும் ஒரு நிலையான மொழியாகும்.

எங்கள் Jassif Team SQL பயிற்சி உங்களுக்கு SQL-ஐ எவ்வாறு பயன்படுத்துவது என்பதைக் கற்பிக்கும்: MySQL, SQL Server, MS Access, Oracle, Sybase, Informix, Postgres, மற்றும் பிற தரவுத்தள முறைமைகளில்.

🏁 குறிப்பு:

உங்கள் முன்னேற்றத்தைக் கண்காணிக்க உள்நுழையுங்கள் - இது இலவசம்.

SQL பயிற்சிகள்

இந்த Jassif Team பயிற்சியில் பல அத்தியாயங்கள் ஒரு பயிற்சியுடன் முடிவடைகின்றன, அங்கு நீங்கள் உங்கள் அறிவு நிலையைச் சரிபார்க்கலாம்.

நடைமுறை அனுபவம்

நிஜ உலக SQL பிரச்சனைகளைத் தீர்க்க பயிற்சி பெறுங்கள்

அறிவு சோதனை

ஒவ்வொரு அத்தியாயத்தின் முடிவிலும் உங்கள் புரிதலைச் சோதிக்கவும்

ஆன்லைன் எடிட்டர்

உங்கள் உலாவியிலேயே SQL குறியீட்டை எழுதி சோதிக்கவும்

முன்னேற்ற கண்காணிப்பு

உங்கள் கற்றலின் முன்னேற்றத்தைக் கண்காணித்து மேம்படுத்துங்கள்

விரைவு குறிப்பு

SELECT

தரவுத்தளத்திலிருந்து தரவுகளைப் பெறுக

SELECT * FROM table_name;

UPDATE

தரவுத்தளத்தில் தரவுகளை மாற்றுக

UPDATE table_name SET column = value;

INSERT

தரவுத்தளத்தில் புதிய தரவுகளைச் சேர்க்க

INSERT INTO table_name VALUES (...);

DELETE

தரவுத்தளத்திலிருந்து தரவுகளை நீக்கு

DELETE FROM table_name;
