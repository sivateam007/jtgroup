SQL என்றால் என்ன?

  • SQL என்பது Structured Query Language என்பதன் சுருக்கமாகும்
  • SQL உங்களை தரவுத்தளங்களை அணுகவும் கையாளவும் அனுமதிக்கிறது
  • SQL 1986-ல் American National Standards Institute (ANSI) மற்றும் 1987-ல் International Organization for Standardization (ISO) நிறுவனத்தின் நிலையான மொழியாக ஆனது

SQL ஒரு நிலையானது - ஆனால்....

SQL ஒரு ANSI/ISO நிலையானது என்றாலும், SQL மொழியின் வெவ்வேறு பதிப்புகள் உள்ளன.

இருப்பினும், ANSI தரத்துடன் இசைவாக இருக்க, அவை அனைத்தும் குறைந்தபட்சம் முக்கிய கட்டளைகளை (SELECT, UPDATE, DELETE, INSERT, WHERE போன்றவை) ஒரே மாதிரியாக ஆதரிக்கின்றன.

💡 குறிப்பு:

பெரும்பாலான SQL தரவுத்தள நிரல்களும் SQL தரத்திற்கு கூடுதலாக அவற்றின் சொந்த சொத்துரிமை நீட்டிப்புகளைக் கொண்டுள்ளன!

RDBMS

RDBMS என்பது Relational Database Management System என்பதன் சுருக்கமாகும்.

RDBMS என்பது SQL-இன் அடிப்படையாகும், மேலும் MS SQL Server, IBM DB2, Oracle, MySQL, மற்றும் Microsoft Access போன்ற அனைத்து நவீன தரவுத்தள முறைமைகளுக்கும் அடிப்படையாகும்.

RDBMS-ல் உள்ள தரவு அட்டவணைகள் என்ற தரவுத்தள பொருள்களில் சேமிக்கப்படுகிறது. ஒரு அட்டவணை என்பது தொடர்புடைய தரவு உள்ளீடுகளின் தொகுப்பாகும், மேலும் இது நெடுவரிசைகள் மற்றும் வரிசைகளைக் கொண்டுள்ளது.

உதாரணம்: "Customers" அட்டவணையைப் பாருங்கள்

SELECT * FROM Customers;

📊 அட்டவணை கட்டமைப்பு:

ஒவ்வொரு அட்டவணையும் fields என்ற சிறிய நிறுவனங்களாகப் பிரிக்கப்பட்டுள்ளது. Customers அட்டவணையில் உள்ள fields கள் CustomerID, CustomerName, ContactName, Address, City, PostalCode மற்றும் Country ஆகியவற்றைக் கொண்டுள்ளன. ஒரு field என்பது அட்டவணையில் உள்ள ஒரு நெடுவரிசையாகும், இது அட்டவணையில் உள்ள ஒவ்வொரு பதிவையும் பற்றிய குறிப்பிட்ட தகவலைப் பராமரிக்க வடிவமைக்கப்பட்டுள்ளது.

ஒரு பதிவு, row என்றும் அழைக்கப்படுகிறது, இது அட்டவணையில் உள்ள ஒவ்வொரு தனிப்பட்ட உள்ளீடாகும். எடுத்துக்காட்டாக, மேலே உள்ள Customers அட்டவணையில் 91 பதிவுகள் உள்ளன. ஒரு பதிவு என்பது அட்டவணையில் உள்ள ஒரு கிடைமட்ட நிறுவனமாகும்.

ஒரு நெடுவரிசை என்பது அட்டவணையில் உள்ள ஒரு செங்குத்து நிறுவனமாகும், இது அட்டவணையில் உள்ள ஒரு குறிப்பிட்ட field உடன் தொடர்புடைய அனைத்து தகவல்களையும் கொண்டுள்ளது.
