தரவுத்தள செயல்பாடுகளுக்கான SQL அறிக்கைகள் மற்றும் கட்டளைகள்

SQL அறிக்கைகள்

தரவுத்தளத்தில் நீங்கள் செய்ய வேண்டிய பெரும்பாலான செயல்கள் SQL அறிக்கைகளுடன் செய்யப்படுகின்றன.

SQL அறிக்கைகள் புரிந்து கொள்ள எளிதான முக்கிய சொற்களைக் கொண்டுள்ளன.

பின்வரும் SQL அறிக்கை "Customers" என்ற அட்டவணையிலிருந்து அனைத்து பதிவுகளையும் திரும்பப் பெறுகிறது:

உதாரணம்: Customers அட்டவணையிலிருந்து அனைத்து பதிவுகளையும் தேர்ந்தெடுக்கவும்

SELECT * FROM Customers;

இந்த பயிற்சியில் வெவ்வேறான SQL அறிக்கைகள் பற்றி நாங்கள் உங்களுக்கு கற்பிப்போம்.

தரவுத்தள அட்டவணைகள்

ஒரு தரவுத்தளம் பெரும்பாலும் ஒன்று அல்லது அதற்கு மேற்பட்ட அட்டவணைகளைக் கொண்டிருக்கும். ஒவ்வொரு அட்டவணையும் ஒரு பெயரால் அடையாளம் காணப்படுகிறது (எ.கா. "Customers" அல்லது "Orders"), மேலும் தரவுகளுடன் கூடிய பதிவுகளை (வரிசைகள்) கொண்டிருக்கும்.

இந்த பயிற்சியில் நன்கு அறியப்பட்ட Northwind மாதிரி தரவுத்தளத்தைப் பயன்படுத்துவோம் (MS Access மற்றும் MS SQL Server-ல் சேர்க்கப்பட்டுள்ளது).

மேலே உள்ள அட்டவணையில் ஐந்து பதிவுகள் (ஒவ்வொரு வாடிக்கையாளருக்கும் ஒன்று) மற்றும் ஏழு நெடுவரிசைகள் (CustomerID, CustomerName, ContactName, Address, City, PostalCode, and Country) உள்ளன.

நினைவில் கொள்ளுங்கள்...

💡 முக்கிய குறிப்பு:

SQL முக்கிய சொற்கள் case sensitive அல்ல: select என்பது SELECT போன்றதே

இந்த பயிற்சியில் அனைத்து SQL முக்கிய சொற்களையும் upper-case-ல் எழுதுவோம்.

SQL அறிக்கைகளுக்குப் பிறகு அரைப்புள்ளி?

சில தரவுத்தள முறைமைகள் ஒவ்வொரு SQL அறிக்கையின் முடிவிலும் ஒரு அரைப்புள்ளி தேவைப்படுகின்றன.

சர்வருக்கு அதே அழைப்பில் ஒன்றுக்கு மேற்பட்ட SQL அறிக்கையை இயக்க அனுமதிக்கும் தரவுத்தள முறைமைகளில், ஒவ்வொரு SQL அறிக்கையையும் பிரிக்க அரைப்புள்ளியானது நிலையான வழியாகும்.

இந்த பயிற்சியில், ஒவ்வொரு SQL அறிக்கையின் முடிவிலும் அரைப்புள்ளியைப் பயன்படுத்துவோம்.
