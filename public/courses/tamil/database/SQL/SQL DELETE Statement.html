SQL DELETE அறிக்கை

DELETE அறிக்கை ஒரு அட்டவணையில் உள்ள தற்போதைய பதிவுகளை நீக்க பயன்படுகிறது.

DELETE தொடரியல்

DELETE FROM table_name 
WHERE condition;

⚠️ குறிப்பு:

அட்டவணையில் பதிவுகளை நீக்கும்போது கவனமாக இருங்கள்! DELETE அறிக்கையில் WHERE விதியைக் கவனியுங்கள். எந்தப் பதிவு(கள்) நீக்கப்பட வேண்டும் என்பதை WHERE விதி குறிப்பிடுகிறது. நீங்கள் WHERE விதியைத் தவிர்த்தால், அட்டவணையில் உள்ள அனைத்து பதிவுகளும் நீக்கப்படும்!

SQL DELETE உதாரணம்

பின்வரும் SQL அறிக்கை "Customers" அட்டவணையிலிருந்து "Alfreds Futterkiste" வாடிக்கையாளரை நீக்குகிறது:

உதாரணம்

DELETE FROM Customers 
WHERE CustomerName='Alfreds Futterkiste';

அனைத்து பதிவுகளையும் நீக்கவும்

அட்டவணையை நீக்காமல் அட்டவணையில் உள்ள அனைத்து வரிசைகளையும் நீக்க முடியும். இதன் பொருள் அட்டவணை கட்டமைப்பு, பண்புக்கூறுகள் மற்றும் குறியீடுகள் அப்படியே இருக்கும்:

தொடரியல்

DELETE FROM table_name;

பின்வரும் SQL அறிக்கை "Customers" அட்டவணையில் உள்ள அனைத்து வரிசைகளையும் நீக்குகிறது, ஆனால் அட்டவணையை நீக்காது:

உதாரணம்

DELETE FROM Customers;

🚨 முக்கியமான எச்சரிக்கை:

WHERE விதி இல்லாமல் DELETE அறிக்கையை இயக்கும்போது மிகவும் கவனமாக இருங்கள். இது அட்டவணையில் உள்ள அனைத்து தரவையும் நிரந்தரமாக நீக்கிவிடும்!

அட்டவணையை முழுமையாக நீக்க, DROP TABLE அறிக்கையைப் பயன்படுத்தவும்:

உதாரணம்

Customers அட்டவணையை நீக்க:

DROP TABLE Customers;
