MySQL COUNT(), AVG() and SUM() Functions

MySQL இல் COUNT(), AVG() மற்றும் SUM() செயல்பாடுகளைப் பயன்படுத்தி தரவுகளை கணக்கிட கற்றுக்கொள்ளுங்கள்

MySQL COUNT(), AVG() மற்றும் SUM() செயல்பாடுகள்

COUNT() செயல்பாடு ஒரு குறிப்பிட்ட அளவுகோலுடன் பொருந்தும் வரிசைகளின் எண்ணிக்கையை வழங்குகிறது.

AVG() செயல்பாடு ஒரு எண் நிரலின் சராசரி மதிப்பை வழங்குகிறது.

SUM() செயல்பாடு ஒரு எண் நிரலின் மொத்த தொகையை வழங்குகிறது.

SUM() செயல்பாடு

COUNT() செயல்பாடு

COUNT() செயல்பாடு ஒரு குறிப்பிட்ட அளவுகோலுடன் பொருந்தும் வரிசைகளின் எண்ணிக்கையை வழங்குகிறது.

COUNT() தொடரியல்

SELECT COUNT(column_name)
FROM table_name
WHERE condition;

💡 குறிப்பு:

AVG() தொடரியல்

SELECT AVG(column_name)

SUM() தொடரியல்

SELECT SUM(column_name)
FROM table_name
WHERE condition;
