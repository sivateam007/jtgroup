HTML Iframes

ஒரு HTML iframe ஒரு வலைப்பக்கத்திற்குள் ஒரு வலைப்பக்கத்தைக் காட்ட பயன்படுகிறது.

மேலே உள்ள iframe HTML Tutorial.html பக்கத்தைக் காட்டுகிறது

HTML Iframe Syntax

HTML <iframe> குறிச்சொல் ஒரு இன்லைன் பிரேமைக் குறிப்பிடுகிறது.

ஒரு இன்லைன் பிரேம் தற்போதைய HTML ஆவணத்திற்குள் மற்றொரு ஆவணத்தை உட்பொருத்த பயன்படுகிறது.

Syntax

<iframe src="url" title="description"></iframe>

உதவிக்குறிப்பு:

<iframe> க்கு எப்போதும் title பண்புக்கூறைச் சேர்ப்பது நல்ல பயிற்சியாகும். iframe இன் உள்ளடக்கம் என்ன என்பதைத் திரையில் படிப்பவர்களால் படிக்க இது பயன்படுத்தப்படுகிறது.

Iframe - Set Height and Width

iframe இன் அளவைக் குறிப்பிட height மற்றும் width பண்புக்கூறுகளைப் பயன்படுத்தவும்.

height மற்றும் width இயல்பாக பிக்சல்களில் குறிப்பிடப்படுகின்றன:

Example

<iframe src="demo_iframe.htm" height="200" width="300" title="Iframe Example"></iframe>

அல்லது நீங்கள் style பண்புக்கூறைச் சேர்த்து CSS height மற்றும் width பண்புக்கூறுகளைப் பயன்படுத்தலாம்:

Example

<iframe src="demo_iframe.htm" style="height:200px;width:300px;" title="Iframe Example"></iframe>

Iframe - Remove the Border

இயல்பாக, ஒரு iframe க்கு சுற்றிலும் ஒரு எல்லை உள்ளது.

எல்லையை அகற்ற, style பண்புக்கூறைச் சேர்த்து CSS border பண்புக்கூறைப் பயன்படுத்தவும்:

Example

<iframe src="demo_iframe.htm" style="border:none;" title="Iframe Example"></iframe>

CSS உடன், iframe இன் எல்லையின் அளவு, பாணி மற்றும் நிறத்தையும் மாற்றலாம்:

Example

<iframe src="demo_iframe.htm" style="border:2px solid red;" title="Iframe Example"></iframe>

Iframe - Target for a Link

ஒரு iframe ஒரு இணைப்பிற்கான இலக்கு பிரேமாக பயன்படுத்தப்படலாம்.

இணைப்பின் target பண்புக்கூறு iframe இன் name பண்புக்கூறைக் குறிப்பிட வேண்டும்:

Example

<iframe src="demo_iframe.htm" name="iframe_a" title="Iframe Example"></iframe>

<p><a href="https://www.jassifteam.com" target="iframe_a">JassifTeam.com</a></p>

Chapter Summary

  • HTML <iframe> குறிச்சொல் ஒரு இன்லைன் பிரேமைக் குறிப்பிடுகிறது
  • src பண்புக்கூறு உட்பொருத்த வேண்டிய பக்கத்தின் URL ஐ வரையறுக்கிறது
  • எப்போதும் title பண்புக்கூறைச் சேர்க்கவும் (திரையில் படிப்பவர்களுக்காக)
  • height மற்றும் width பண்புக்கூறுகள் iframe இன் அளவைக் குறிப்பிடுகின்றன
  • iframe சுற்றிலும் உள்ள எல்லையை அகற்ற border:none; பயன்படுத்தவும்

Exercise

❓ In which IFRAME attribute can we specify an URL?

href
✗ தவறு! href பண்புக்கூறு இணைப்புகளுக்குப் பயன்படுத்தப்படுகிறது, iframes க்கு அல்ல.
src
✓ சரி! src பண்புக்கூறில் iframe இல் காட்ட வேண்டிய பக்கத்தின் URL ஐக் குறிப்பிடுகிறோம்.
url
✗ தவறு! url என்பது HTML இல் செல்லுபடியாகும் பண்புக்கூறு அல்ல. iframes க்கு src பயன்படுத்தப்படுகிறது.
