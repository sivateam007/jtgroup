HTML அறிமுகம்

HTML என்பது வலைப்பக்கங்களை உருவாக்குவதற்கான நிலையான மார்க்அப் மொழியாகும்.

HTML என்றால் என்ன?

  • HTML என்பது ஹைப்பர் டெக்ஸ்ட் மார்க்அப் லாங்குவேஜ் (Hyper Text Markup Language) என்பதன் சுருக்கமாகும்
  • HTML என்பது வலைப்பக்கங்களை உருவாக்குவதற்கான நிலையான மார்க்அப் மொழியாகும்
  • HTML ஒரு வலைப்பக்கத்தின் கட்டமைப்பை விவரிக்கிறது
  • HTML தொடர் உறுப்புகளால் (elements) உருவாக்கப்பட்டது
  • HTML உறுப்புகள் உள்ளடக்கத்தை எவ்வாறு காட்சிப்படுத்துவது என்பதை உலாவிக்கு (browser) கூறுகின்றன
  • HTML உறுப்புகள் உள்ளடக்கத்தின் பகுதிகளை "இது தலைப்பு", "இது பத்தி", "இது இணைப்பு" போன்றவற்றை லேபிளிடுகின்றன

எளிய HTML ஆவணம்

எடுத்துக்காட்டு

<!DOCTYPE html>
<html>
<head>
<title>Page Title</title>
</head>
<body>

<h1>My First Heading</h1>
<p>My first paragraph.</p>

</body>
</html>

எடுத்துக்காட்டு விளக்கம்

  • <!DOCTYPE html> அறிவிப்பு இந்த ஆவணம் ஒரு HTML5 ஆவணம் என்பதை வரையறுக்கிறது
  • <html> உறுப்பு ஒரு HTML பக்கத்தின் மூல உறுப்பு (root element) ஆகும்
  • <head> உறுப்பு HTML பக்கத்தைப் பற்றிய மெட்டா தகவல்களைக் கொண்டுள்ளது
  • <title> உறுப்பு HTML பக்கத்திற்கான தலைப்பைக் குறிப்பிடுகிறது (இது உலாவியின் தலைப்புப் பட்டையில் அல்லது பக்கத்தின் தாவலில் காட்டப்படும்)
  • <body> உறுப்பு ஆவணத்தின் உடலை வரையறுக்கிறது, மேலும் தலைப்புகள், பத்திகள், படங்கள், ஹைப்பர்லிங்குகள், அட்டவணைகள், பட்டியல்கள் போன்ற அனைத்து தெரியும் உள்ளடக்கங்களுக்கும் ஒரு கொள்கலனாகும்
  • <h1> உறுப்பு ஒரு பெரிய தலைப்பை வரையறுக்கிறது
  • <p> உறுப்பு ஒரு பத்தியை வரையறுக்கிறது

HTML உறுப்பு என்றால் என்ன?

ஒரு HTML உறுப்பு ஒரு தொடக்கக் குறி (start tag), சில உள்ளடக்கம் மற்றும் ஒரு முடிவுக் குறி (end tag) ஆகியவற்றால் வரையறுக்கப்படுகிறது:

<tagname> Content goes here... </tagname>

HTML உறுப்பு என்பது தொடக்கக் குறியிலிருந்து முடிவுக் குறி வரை உள்ள அனைத்தும்:

<h1>My First Heading</h1>
<p>My first paragraph.</p>
தொடக்கக் குறி உறுப்பு உள்ளடக்கம் முடிவுக் குறி
<h1> My First Heading </h1>
<p> My first paragraph. </p>
<br> உள்ளடக்கம் இல்லை முடிவுக் குறி இல்லை

⚠️ கவனிக்க:

சில HTML உறுப்புகளுக்கு உள்ளடக்கம் இல்லை (உதாரணமாக <br> உறுப்பு). இந்த உறுப்புகள் "காலியான உறுப்புகள்" (empty elements) என்று அழைக்கப்படுகின்றன. காலியான உறுப்புகளுக்கு முடிவுக் குறி இல்லை!

வலை உலாவிகள்

ஒரு வலை உலாவியின் (Chrome, Edge, Firefox, Safari) நோக்கம் HTML ஆவணங்களை வாசித்து அவற்றை சரியாகக் காட்சிப்படுத்துவதாகும்.

ஒரு உலாவி HTML குறிகளை காட்சிப்படுத்தாது, ஆனால் ஆவணத்தை எவ்வாறு காட்சிப்படுத்துவது என்பதை தீர்மானிக்க அவற்றைப் பயன்படுத்துகிறது:

👁️ உலாவியில் காண்க

HTML பக்க கட்டமைப்பு

கீழே ஒரு HTML பக்க கட்டமைப்பின் காட்சிப்படுத்தல் உள்ளது:

<html>
<head>
<title>Page title</title>
</head>
<body>
<h1>This is a heading</h1>
<p>This is a paragraph.</p>
<p>This is another paragraph.</p>
</body>
</html>

📝 குறிப்பு:

<body> பிரிவுக்குள் உள்ள உள்ளடக்கம் ஒரு உலாவியில் காட்சிப்படுத்தப்படும். <title> உறுப்புக்குள் உள்ள உள்ளடக்கம் உலாவியின் தலைப்புப் பட்டையில் அல்லது பக்கத்தின் தாவலில் காட்டப்படும்.

HTML வரலாறு

உலகளாவிய வலையின் ஆரம்ப நாட்களிலிருந்தே, HTML இன் பல பதிப்புகள் உள்ளன:

ஆண்டு பதிப்பு

1991 டிம் பெர்னர்ஸ்-லீ HTML ஐ கண்டுபிடித்தார்
1993 டேவ் ராகெட் HTML+ வரைவை உருவாக்கினார்

1999 W3C பரிந்துரை: HTML 4.01
