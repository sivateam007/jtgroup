HTML Entities

HTML எழுத்து நிறுவனங்களைக் கற்றுக்கொள்ளுங்கள்

HTML Entities

HTML இல் முன்பதிவு செய்யப்பட்ட எழுத்துக்கள் நிறுவனங்களுடன் மாற்றப்பட வேண்டும்:

< (குறைவானது) = &lt;

> (அதிகமானது) = &gt;

HTML Character Entities

சில எழுத்துக்கள் HTML இல் முன்பதிவு செய்யப்பட்டுள்ளன.

உங்கள் HTML உரையில் குறைவான (<) அல்லது அதிகமான (>) அடையாளங்களைப் பயன்படுத்தினால், உலாவி அவற்றை குறிச்சொற்களுடன் கலக்கலாம்.

முன்பதிவு செய்யப்பட்ட HTML எழுத்துக்களைக் காண்பிக்க நிறுவனப் பெயர்கள் அல்லது நிறுவன எண்களைப் பயன்படுத்தலாம்.

நிறுவனப் பெயர்கள் இப்படி இருக்கும்:

&entity_name;

நிறுவன எண்கள் இப்படி இருக்கும்:

&#entity_number;

குறைவான அடையாளத்தை (<) காண்பிக்க நாம் எழுத வேண்டும்: &lt; அல்லது &#60;

நிறுவன எண்களை விட நிறுவனப் பெயர்களை நினைவில் கொள்வது எளிது.

Non-breaking Space

பொதுவாகப் பயன்படுத்தப்படும் HTML நிறுவனம் கெடாத இடைவெளி: &nbsp;

கெடாத இடைவெளி என்பது புதிய வரியில் உடைக்காத ஒரு இடைவெளியாகும்.

கெடாத இடைவெளியால் பிரிக்கப்பட்ட இரண்டு சொற்கள் ஒன்றாக ஒட்டிக்கொள்ளும் (புதிய வரியில் உடையாது). வார்த்தைகளை உடைப்பது சீர்குலையும் போது இது பயனுள்ளதாக இருக்கும்.

எடுத்துக்காட்டுகள்:

  • § 10
  • 10 km/h
  • 10 PM

கெடாத இடைவெளியின் மற்றொரு பொதுவான பயன்பாடு, HTML பக்கங்களில் உலாவிகள் இடைவெளிகளை துண்டிக்காமல் தடுப்பதாகும்.

உங்கள் உரையில் 10 இடைவெளிகளை எழுதினால், உலாவி அவற்றில் 9ஐ நீக்கிவிடும். உங்கள் உரையில் உண்மையான இடைவெளிகளைச் சேர்க்க, நீங்கள் &nbsp; எழுத்து நிறுவனத்தைப் பயன்படுத்தலாம்.

கெடாத இடைவெளி (&nbsp;) ஒரு இடைவெளியை வரையறுக்கப் பயன்படுகிறது, இது புதிய வரியில் உடைக்காது.

Combining Diacritical Marks

ஒரு மேற்குறி குறி என்பது ஒரு எழுத்துடன் சேர்க்கப்பட்ட "கிளிஃப்" ஆகும்.

கல்லறை ( ̀) மற்றும் கடுமை ( ́) போன்ற சில மேற்குறி குறிகள் உச்சரிப்புகள் என்று அழைக்கப்படுகின்றன.

பக்கத்தில் பயன்படுத்தப்படும் எழுத்துத் தொகுப்பில் (குறியாக்கம்) இல்லாத ஒரு எழுத்தை உருவாக்க, மேற்குறி குறிகளை எழுத்து-எண் எழுத்துகளுடன் இணைந்து பயன்படுத்தலாம்.

சில எடுத்துக்காட்டுகள் இங்கே:
