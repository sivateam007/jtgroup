CSS Tutorial

CSS ஐக் கற்றுக்கொள்ளுங்கள்

CSS டுடோரியல்

CSS என்பது HTML ஆவணத்தை ஸ்டைல் செய்ய பயன்படும் மொழியாகும்.

HTML உறுப்புகள் எவ்வாறு காட்சிப்படுத்தப்பட வேண்டும் என்பதை CSS விவரிக்கிறது.

இந்த டுடோரியல் உங்களுக்கு CSS ஐ அடிப்படை முதல் மேம்பட்ட நிலை வரை கற்பிக்கும்.

🏁 உதவிக்குறிப்பு:

உங்கள் முன்னேற்றத்தைக் கண்காணிக்க உள்நுழையவும்.

ஒவ்வொரு அத்தியாயத்திலும் எடுத்துக்காட்டுகள்

இந்த CSS டுடோரியலில் 700 க்கும் மேற்பட்ட CSS எடுத்துக்காட்டுகள் உள்ளன.

எங்கள் ஆன்லைன் எடிட்டருடன், நீங்கள் CSS ஐத் திருத்தலாம் மற்றும் முடிவைக் காண பொத்தானைக் கிளிக் செய்யலாம்.

CSS எடுத்துக்காட்டு

body {
  background-color: lightblue;
}

h1 {
  color: white;
  text-align: center;
}

p {
  font-family: verdana;
  font-size: 20px;
}

இது எவ்வாறு செயல்படுகிறது என்பதைப் பார்க்க "Try it Yourself" பொத்தானைக் கிளிக் செய்யவும்.

CSS எடுத்துக்காட்டுகள்

700 க்கும் மேற்பட்ட எடுத்துக்காட்டுகளிலிருந்து கற்றுக்கொள்ளுங்கள்! எங்கள் எடிட்டருடன், நீங்கள் CSS ஐத் திருத்தலாம் மற்றும் முடிவைக் காண பொத்தானைக் கிளிக் செய்யலாம்.

மெனுவைப் பயன்படுத்தவும்

மெனுவில் பட்டியலிடப்பட்டுள்ள வரிசையில் இந்த டுடோரியலைப் படிக்க பரிந்துரைக்கிறோம்.

உங்களிடம் பெரிய திரை இருந்தால், மெனு எப்போதும் இடது பக்கத்தில் இருக்கும்.

உங்களிடம் சிறிய திரை இருந்தால், மேல் மெனு அடையாளத்தைக் கிளிக் செய்வதன் மூலம் ☰ மெனுவைத் திறக்கவும்.

CSS டெம்ப்ளேட்டுகள்

உங்கள் பயன்பாட்டிற்காக சில பதிலளிக்கும் Jassif Team CSS டெம்ப்ளேட்டுகளை நாங்கள் உருவாக்கியுள்ளோம்.

உங்கள் அனைத்து திட்டங்களிலும் அவற்றை மாற்றியமைக்க, சேமிக்க, பகிர்ந்து கொள்ளவும் பயன்படுத்தவும் நீங்கள் சுதந்திரமாக உள்ளீர்கள்.

CSS பயிற்சிகள்

இந்த டுடோரியலில் உள்ள பல அத்தியாயங்கள் உங்கள் அறிவு நிலையைச் சரிபார்க்கக்கூடிய பயிற்சியுடன் முடிகின்றன.

❓ பயிற்சி:

<div> உறுப்புக்கு பச்சை பின்புற நிறத்தை அமைக்க சரியான பண்புத்தொகுப்பை இழுத்து விடவும்.

div {
  : green;
}
color
✗ தவறு! color என்பது உரை நிறத்தை அமைக்கிறது, பின்புற நிறத்தை அல்ல
background-color
✓ சரி! background-color பின்புற நிறத்தை அமைக்கப் பயன்படுகிறது
border-color
✗ தவறு! border-color எல்லை நிறத்தை அமைக்கிறது
font-color
✗ தவறு! font-color என்பது CSS இல் பயன்படுத்தப்படாத ஒரு பண்புத்தொகுப்பு
