Exercise

❓ CSS column-count பண்பின் நோக்கம் என்ன?

பல நெடுவரிசை அமைப்பில் ஒவ்வொரு நெடுவரிசையின் அகலத்தையும் அமைக்க
✗ தவறு! அகலத்தை அமைப்பது column-width பண்பு
ஒரு உறுப்பு எத்தனை நெடுவரிசைகளாக பிரிக்கப்பட வேண்டும் என்பதைக் குறிப்பிட
✓ சரி! column-count பண்பு நெடுவரிசைகளின் எண்ணிக்கையைக் குறிப்பிடுகிறது
நெடுவரிசைகளுக்கு இடையே உள்ள இடத்தை வரையறுக்க
✗ தவறு! இடைவெளியை வரையறுப்பது column-gap பண்பு
நெடுவரிசைகளுக்கு இடையே ஒரு விதியைச் சேர்க்க
✗ தவறு! விதியைச் சேர்க்க column-rule பண்புகள்

CSS Multi-columns Properties

பின்வரும் அட்டவணை அனைத்து பல நெடுவரிசை பண்புகளையும் பட்டியலிடுகிறது:

Property Description
column-count ஒரு உறுப்பு எத்தனை நெடுவரிசைகளாக பிரிக்கப்பட வேண்டும் என்பதைக் குறிப்பிடுகிறது
column-fill நெடுவரிசைகளை எவ்வாறு நிரப்புவது என்பதைக் குறிப்பிடுகிறது
column-gap நெடுவரிசைகளுக்கு இடையே உள்ள இடைவெளியைக் குறிப்பிடுகிறது
column-rule அனைத்து column-rule-* பண்புகளையும் அமைக்க ஒரு சுருக்கெழுத்து பண்பு
column-rule-color நெடுவரிசைகளுக்கு இடையே உள்ள விதியின் நிறத்தைக் குறிப்பிடுகிறது
column-rule-style நெடுவரிசைகளுக்கு இடையே உள்ள விதியின் பாணியைக் குறிப்பிடுகிறது
column-rule-width நெடுவரிசைகளுக்கு இடையே உள்ள விதியின் அகலத்தைக் குறிப்பிடுகிறது
column-span ஒரு உறுப்பு எத்தனை நெடுவரிசைகளில் பரவ வேண்டும் என்பதைக் குறிப்பிடுகிறது
column-width நெடுவரிசைகளுக்கு ஒரு பரிந்துரைக்கப்பட்ட, உகந்த அகலத்தைக் குறிப்பிடுகிறது
columns column-width மற்றும் column-count ஐ அமைக்க ஒரு சுருக்கெழுத்து பண்பு
