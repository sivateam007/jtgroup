மேலும் எடுத்துக்காட்டுகள்

அனைத்து மேல் எல்லை பண்புகளும் ஒரே அறிவிப்பில்

மேல் எல்லைக்கான அனைத்து பண்புகளையும் ஒரே அறிவிப்பில் அமைக்கும் சுருக்கப்பண்பை இந்த எடுத்துக்காட்டு நிரூபிக்கிறது.

கீழ் எல்லையின் பாணியை அமைக்கவும்

கீழ் எல்லையின் பாணியை எவ்வாறு அமைப்பது என்பதை இந்த எடுத்துக்காட்டு நிரூபிக்கிறது.

இடது எல்லையின் அகலத்தை அமைக்கவும்

இடது எல்லையின் அகலத்தை எவ்வாறு அமைப்பது என்பதை இந்த எடுத்துக்காட்டு நிரூபிக்கிறது.

நான்கு எல்லைகளின் நிறத்தை அமைக்கவும்

நான்கு எல்லைகளின் நிறத்தை எவ்வாறு அமைப்பது என்பதை இந்த எடுத்துக்காட்டு நிரூபிக்கிறது. இதற்கு ஒன்று முதல் நான்கு வரை நிறங்கள் இருக்கலாம்.

வலது எல்லையின் நிறத்தை அமைக்கவும்

வலது எல்லையின் நிறத்தை எவ்வாறு அமைப்பது என்பதை இந்த எடுத்துக்காட்டு நிரூபிக்கிறது.

பயிற்சி

❓ வட்டமான மூலைகளைக் கொண்ட ஒரு உறுப்பை உருவாக்க சரியான பண்பு மற்றும் மதிப்பை இழுத்து விடவும்.

p {
  border: 2px solid red;
  : ;
}
border-style: rounded;
✗ தவறு! border-style பண்புக்கு rounded என்பது ஒரு செல்லுபடியாகும் மதிப்பு அல்ல
border-color: red;
✗ தவறு! border-color பண்பு எல்லையின் நிறத்தை மட்டுமே மாற்றுகிறது, வட்டமான மூலைகளை உருவாக்காது
border-radius: 10px;
✓ சரி! border-radius பண்பு வட்டமான எல்லைகளை உருவாக்க பயன்படுகிறது
border-width: 10px;
✗ தவறு! border-width பண்பு எல்லையின் அகலத்தை மட்டுமே மாற்றுகிறது, வட்டமான மூலைகளை உருவாக்காது

பண்பு விளக்கம்
border அனைத்து எல்லை பண்புகளையும் ஒரே அறிவிப்பில் அமைக்கிறது
border-bottom அனைத்து கீழ் எல்லை பண்புகளையும் ஒரே அறிவிப்பில் அமைக்கிறது
border-bottom-color கீழ் எல்லையின் நிறத்தை அமைக்கிறது

border-bottom-width கீழ் எல்லையின் அகலத்தை அமைக்கிறது
border-color நான்கு எல்லைகளின் நிறத்தை அமைக்கிறது
border-left அனைத்து இடது எல்லை பண்புகளையும் ஒரே அறிவிப்பில் அமைக்கிறது
border-left-color இடது எல்லையின் நிறத்தை அமைக்கிறது
border-left-style இடது எல்லையின் பாணியை அமைக்கிறது
border-left-width இடது எல்லையின் அகலத்தை அமைக்கிறது
border-radius வட்டமான மூலைகளுக்கான அனைத்து border-*-radius பண்புகளையும் அமைக்கிறது
border-right அனைத்து வலது எல்லை பண்புகளையும் ஒரே அறிவிப்பில் அமைக்கிறது
border-right-color வலது எல்லையின் நிறத்தை அமைக்கிறது
border-right-style வலது எல்லையின் பாணியை அமைக்கிறது
border-right-width வலது எல்லையின் அகலத்தை அமைக்கிறது
border-style நான்கு எல்லைகளின் பாணியை அமைக்கிறது
border-top அனைத்து மேல் எல்லை பண்புகளையும் ஒரே அறிவிப்பில் அமைக்கிறது
border-top-color மேல் எல்லையின் நிறத்தை அமைக்கிறது
border-top-style மேல் எல்லையின் பாணியை அமைக்கிறது
border-top-width மேல் எல்லையின் அகலத்தை அமைக்கிறது
